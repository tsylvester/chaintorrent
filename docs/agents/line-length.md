# Line length, line wrapping, and line breaks
- Do not hard wrap the document at some arbitrary width.
- Do not write lines longer than 1000 chars. 
- If you are using more than 1000 chars in one line, you have too much content for a single line. 
- You cannot read lines that are longer than 2000 characters. Do not write long lines, you will not be able to read them later. 
- If you are reading a document and encounter a line longer than 1000 chars, propose recomposing the line into shorter, more focused lines. 
- If you are reading a document and encounter a line longer than 2000 chars, insert a linebreak at a convenient location, read the elements, and recompose the line into shorter, more focused lines. 
- Do not create arbitrary, meaningless, or confusing line breaks in long lines. You were given a process for recomposing long lines, follow it as written.
