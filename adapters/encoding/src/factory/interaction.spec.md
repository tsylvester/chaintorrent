# `factory` — interaction spec

Branch contract for the `factory` module of the `encoding` crate: `create_encoding`, the encoding family's construction point, which selects the concrete the configuration names, admits it against the encoding identifier the hash-card or configuration requires, and hands it to a consumer generic over the family's encoder and decoder traits. Each branch states condition, decision, dependency call, and the exact return outcome.

## `create_encoding<C: IEncodingConsumer>(deps: &CreateEncodingDeps<C>, params: CreateEncodingParams, payload: CreateEncodingPayload) -> CreateEncodingReturn<C::Output>`

The decision is a `match` on `params.concrete`, one arm per `EncodingConcrete` variant, exhaustive so a variant with no arm fails to compile. `params.concrete` selects and `params.identifier` admits; `payload` carries nothing and is not read.

### `EncodingConcrete::Abi`

| Branch | Condition | Decision | Dependency call | Outcome |
|---|---|---|---|---|
| unsupported identifier | `AbiEncoding::DECLARATION.identifier` is not `params.identifier` | equality, read before any construction | none | `Err(CreateEncodingErrorReturn::UnsupportedEncodingIdentifier)`; nothing is constructed and the consumer is not called |
| admitted | `AbiEncoding::DECLARATION.identifier` is `params.identifier` | the check passes | `AbiEncoding::try_new(AbiEncodingConstructorParams)` exactly once, its success destructured irrefutably because its error arm is uninhabited, then `deps.consumer.consume_encoding(ConsumeEncodingParams, ConsumeEncodingPayload { adapter })` exactly once | `Ok(CreateEncodingSuccessReturn { output })` holding the consumer's output; the consumer reads the concrete's declaration through `E::DECLARATION` |

`CreateEncodingErrorReturn::Abi` carries the constructor's uninhabited error type in the return union, so no branch produces it.

### `EncodingConcrete::Mock` — under `#[cfg(any(test, feature = "mocks"))]`

| Branch | Condition | Decision | Dependency call | Outcome |
|---|---|---|---|---|
| unsupported identifier | `MockIEncoderAdapter::DECLARATION.identifier` is not `params.identifier` | equality, read before any construction | none | `Err(CreateEncodingErrorReturn::UnsupportedEncodingIdentifier)`; the consumer is not called |
| admitted | `MockIEncoderAdapter::DECLARATION.identifier` is `params.identifier` | the check passes | `deps.consumer.consume_encoding(ConsumeEncodingParams, ConsumeEncodingPayload { adapter })` exactly once with the mock concrete by value, which has no constructor and so no constructor error | `Ok(CreateEncodingSuccessReturn { output })` holding the consumer's output |

The mock concrete declares `EncodingIdentifier::Mock`, so a mock selection paired with another concrete's identifier takes the unsupported-identifier branch.

## Integration: own entries and callee dispositions

### Own entries

- **Every concrete is handed to the consumer under the identifier it declares.** Condition: `create_encoding` is called with the selection of a concrete and the identifier that concrete declares. Outcome: `Ok(CreateEncodingSuccessReturn { output })` with `output.declaration` the declaration the consumer read through `E::DECLARATION`, whose identifier is the identifier required and whose interface version is `ENCODING_INTERFACE_VERSION`. Variation: each case of the declared set and the mock selection, whose declared identifiers differ, so a hand-over of a concrete other than the selected one returns another identifier. Edge that must survive the composition: every concrete the factory admits declares the interface version the consumer is written against.
- **Every concrete is refused under an identifier it does not declare.** Condition: `create_encoding` is called with the selection of a concrete and an identifier that concrete does not declare. Outcome: `Err(CreateEncodingErrorReturn::UnsupportedEncodingIdentifier)`. Variation: each case paired with the declared identifier of every other case whose declared identifier differs from its own, so an admission that compares against a constant or ignores the selection admits a pairing it must refuse. Edge that must survive the composition: the refusal is decided by the selected concrete's own declaration.
- **Every concrete decodes what it encodes.** Condition: `create_encoding` is called with the selection of a concrete and the identifier it declares, and the consumer encodes a field list through the concrete under the official description and decodes the bytes. Outcome: `output.round_trip` an `Ok(DecodeSuccessReturn { described })` whose `described` equals the field list encoded. Variation: each case of the declared set and the mock selection, whose byte forms differ, and a field list that differs from the builder's default in every value, so a concrete whose decode returns the default field list, or any value its bytes do not hold, fails. Edge that must survive the composition: the concrete the factory constructs is the one whose `encode` and `decode` the consumer calls.
- **Every concrete refuses a description that emits the wrong count.** Condition: `create_encoding` is called with the selection of a concrete and the identifier it declares, and the consumer encodes a field list one value short of the description's `FIELDS`. Outcome: `output.encoded` equal to `Err(EncodeErrorReturn::FieldCount { expected, actual })`, no bytes written. Variation: each case of the declared set and the mock selection, so a concrete that encodes a field list of the wrong count fails. Edge that must survive the composition: the refusal is the family's own error, naming the description's declared count and the emitted count.
- **Every concrete refuses a description that emits the wrong kind.** Condition: `create_encoding` is called with the selection of a concrete and the identifier it declares, and the consumer encodes a field list whose value at index `0` is not the kind the description's `FIELDS` names there. Outcome: `output.encoded` equal to `Err(EncodeErrorReturn::FieldKind { index, expected, actual })`, no bytes written. Variation: each case of the declared set and the mock selection, so a concrete that encodes a field list of the wrong kind fails. Edge that must survive the composition: the refusal names the index, the kind declared there, and the kind emitted.
- **Every concrete refuses bytes past a complete encoding.** Condition: `create_encoding` is called with the selection of a concrete and the identifier it declares, and the consumer decodes the bytes the concrete wrote for a field list followed by one extra byte. Outcome: `output.trailing_bytes` equal to `Err(DecodeErrorReturn::NonCanonical)`. Variation: each case of the declared set and the mock selection, so a concrete that accepts bytes past a complete encoding fails. Edge that must survive the composition: the extra byte is refused though the bytes before it are a complete encoding.
- **Every concrete refuses bytes that end inside an encoding.** Condition: `create_encoding` is called with the selection of a concrete and the identifier it declares, and the consumer decodes the bytes the concrete wrote for a field list with the last byte removed. Outcome: `output.truncated_bytes` an `Err` of `DecodeErrorReturn`. Variation: each case of the declared set and the mock selection, so a concrete that accepts bytes ending inside a field fails. Edge that must survive the composition: the refusal is returned though every byte present is a byte the concrete wrote.
- **Every concrete returns the description's refusal unchanged.** Condition: `create_encoding` is called with the selection of a concrete and the identifier it declares, and the consumer encodes a field list the official description refuses and decodes the bytes. Outcome: `output.round_trip` equal to `Err(DecodeErrorReturn::Description(error))` with `error` the description's refusal. Variation: each case of the declared set and the mock selection, whose byte forms differ, so a concrete that maps, drops, or replaces the description's refusal fails. Edge that must survive the composition: the refusal arrives whole in the family's `Description` variant whatever the concrete's byte form.
- **Every concrete declaring the Ethereum ABI identifier encodes the reference fields to the reference vector.** Condition: `create_encoding` is called with the selection of a concrete that declares `EncodingIdentifier::EthereumAbiV1` and that identifier, and the consumer encodes the reference fields of the official description. Outcome: `output.encoded` an `Ok(EncodeSuccessReturn { bytes })` with `bytes` the known-answer vector authored from the ABI specification. Variation: the reference fields hold one value of each kind, distinct in every kind, a byte string and a text before the static items, so a swapped field, a wrong word width, or a misplaced tail changes the bytes. Edge that must survive the composition: the concrete the factory constructs is the one whose `encode` the consumer calls.
- **Every concrete declaring the Ethereum ABI identifier decodes the reference vector to the reference fields.** Condition: `create_encoding` is called with the selection of a concrete that declares `EncodingIdentifier::EthereumAbiV1` and that identifier, and the consumer decodes the reference vector under the official description. Outcome: `output.decoded` an `Ok(DecodeSuccessReturn { described })` with `described` equal to the reference fields. Variation: the same reference fields, so a field read from the wrong word or tail yields a refusal or an unequal field list. Edge that must survive the composition: the canonical re-encoding of the described fields equals the vector.
- **Every concrete names every canonical field kind.** Condition: `create_encoding` is called with the selection of a concrete and the identifier it declares, and the consumer asks the concrete for the name of each kind of the official description's `FIELDS`. Outcome: `output.type_names` holding one `EncodingTypeName` per kind in order, no two equal. Variation: each case of the declared set and the mock selection, whose names differ, so a concrete that names two kinds alike, or names a kind another concrete's way, fails. Edge that must survive the composition: the names are read from the concrete the factory constructs and from no table of the consumer's.
- **Every concrete declaring the Ethereum ABI identifier names every kind by its ABI type.** Condition: `create_encoding` is called with the selection of a concrete that declares `EncodingIdentifier::EthereumAbiV1` and that identifier, and the consumer asks for the name of each kind of the official description's `FIELDS`. Outcome: `output.type_names` equal, in order, to `string`, `bytes`, `bytes32`, `uint16`, `uint32`, `uint64`, `bytes20`, and `uint256`. Variation: the official description's field kinds, one of each kind, so a swapped or missing name changes the list. Edge that must survive the composition: the fixed twenty-byte kind is `bytes20` and never `address`.

### Callee dispositions

No callee entry: the `abi` concrete's spec declares no own entries — its callees are `alloy`, a vendor library, and the contract methods of the description its caller hands it — so nothing is absorbed or carried here.

### Private surface

The chain of real functions `create_encoding`, the selected concrete's constructor where it has one, and the concrete's `encode` and `decode` as the consumer calls them, with the consumer's read of the concrete's `E::DECLARATION`; the outer-edge collaborators mocked are the consumer, replaced by the official `MockIEncodingConsumer`, and the description it carries, replaced by the official `MockIEncodingContract`; the cases are the declared set and the mock selection; the observable result is the output or the refusal `create_encoding` returns. Every own entry is proven here.

### Public surface

An outside caller invokes `create_encoding` with `CreateEncodingDeps` built over the official consumer mock carrying a description, the described value, and the bytes it operates on, a `CreateEncodingParams` taken from the declared set, or from the declared set paired with an identifier no declared concrete declares, and a `CreateEncodingPayload`, and observes the output or the refusal it returns. The entries proven are the own entries above.
