# factory interactions

`create_commitment` is the hashing family's construction point: it hands the concrete `params.concrete` names and the `params.identifier` the hash-card requires to `deps.admit_hashing_composition` before it constructs anything, then constructs the admitted concrete and returns it behind `Box<dyn ICommitmentAdapter>`. It reads no hash-card and no configuration — the composition resolver passes both as typed values — and it does not hash; every commitment operation is the concrete's. A member's declaration is read through `lookup_hashing_declaration`, never from the adapter.

## `create_commitment`

`create_commitment(deps: &CreateCommitmentDeps, params: CreateCommitmentParams, payload: CreateCommitmentPayload) -> CreateCommitmentReturn`

The function first calls `deps.admit_hashing_composition` with `AdmitHashingCompositionDeps { lookup_hashing_declaration: deps.lookup_hashing_declaration }`, `AdmitHashingCompositionParams { concrete: params.concrete, identifier: params.identifier }`, and `AdmitHashingCompositionPayload`, built by struct literals, before any construction. The decision is a `match` on the admission's return, then a `match` on `params.concrete`, one arm per `CommitmentConcrete` variant, exhaustive so a variant with no arm fails to compile.

| Branch | Condition | Decision | Dependency call | Outcome |
|---|---|---|---|---|
| composition refused | the admission returns `Err(error)` | the admission's own comparison, which this function repeats nowhere | `deps.admit_hashing_composition` exactly once | `Err(CreateCommitmentErrorReturn::Composition(error))`, the error carried unchanged, with no concrete's `try_new` called. No input and no failure mode of the official mocks reaches this branch, since the real admission and `mock_admit_hashing_composition` admit every member for the identifier it declares and `CommitmentSchemeIdentifier` holds one real variant, so the unit block `create_commitment_returns_the_composition_refusal_unchanged` reaches it through a production-typed `AdmitHashingCompositionFn` its deps carry |
| `Blake3Bao` arm, composition admitted | the admission returned `Ok` and `params.concrete` is `CommitmentConcrete::Blake3Bao` | the arm of the selected member | the concrete's `try_new` with its fieldless constructor params, exactly once, its success destructured irrefutably because its error arm is uninhabited | `Ok(CreateCommitmentSuccessReturn { adapter: Box::new(commitment) })`; the unit tests name no concrete, so the private integration blocks over `COMMITMENT_CONCRETES` prove this arm |

`Mock` arm, under `#[cfg(any(test, feature = "mocks"))]`, composition admitted: `params.concrete` is `CommitmentConcrete::Mock(failure_mode)`; dependency call the mock concrete's `try_new` with `MockICommitmentAdapterConstructorParams { failure_mode }`, the failure mode the selection carries, exactly once, its success destructured irrefutably; the outcome is `Ok(CreateCommitmentSuccessReturn { adapter: Box::new(mock) })`, whose adapter answers under the failure mode.

`CreateCommitmentErrorReturn::Blake3Bao` and `CreateCommitmentErrorReturn::Mock` carry the constructors' uninhabited error type `Infallible` in the return union, so no branch produces them.

`params.concrete` selects and, with `params.identifier`, is handed to the composition admission; `deps` carry the admission and the lookup handle; `payload` carries nothing and is not read.

## Shared terms

- `L` is the `chunk_length` of the declaration `lookup_hashing_declaration` returns for the case's selection.
- The reference content is `reference_content(REFERENCE_CONTENT_LENGTH)`.
- Its chunk count is `REFERENCE_CONTENT_LENGTH` as a `u64` divided by `L`, rounded up.
- Chunk `i` is the content's bytes from `i × L` to the lesser of `(i + 1) × L` and the content's length.

## Integration: callee dispositions

The entries of `hashing/blake3_bao` and `hashing/admit_hashing_composition` that this node's chains reach, each dispositioned as stated.

- `commit_under_a_key_leaves_the_borrowed_key_intact` (`hashing/blake3_bao`): absorbed; proven by `every_concrete_leaves_the_borrowed_key_intact` in this module's private integration test `integration_test.rs`, which runs the entry through `create_commitment` over the declared set and the mock selection.
- `committed_outboard_verifies_its_content` (`hashing/blake3_bao`): absorbed; proven by `every_concrete_verifies_the_content_it_committed` in `integration_test.rs`, restated in this node's terms: the changed byte is at offset `2 × L`, the first byte of chunk 2 under each concrete's declared chunk length, and the outcome for the changed content is `Err(VerifyErrorReturn::ChunkMismatch { chunk_index: 2 })`.
- `extracted_paths_verify_every_chunk` (`hashing/blake3_bao`): absorbed; proven by `every_concrete_verifies_every_chunk_with_its_extracted_path` in `integration_test.rs`, restated in this node's terms: the indexes are every index below the reference content's chunk count under each concrete's declared chunk length.
- `a_challenge_response_verifies_against_the_root` (`hashing/blake3_bao`): absorbed; proven by `every_concrete_answers_a_challenge_with_a_response_that_verifies` in `integration_test.rs`, restated in this node's terms: the altered outboard has one byte inverted in each of the two child values the root's parent node records, so the challenged chunk's topmost sibling is altered whichever side of the root's split the chunk lies on.
- `keyed_paths_verify_only_under_their_key` (`hashing/blake3_bao`): absorbed; proven by `every_concrete_verifies_a_keyed_path_only_under_its_key` in this module's private integration test `integration_test.rs`, which runs the entry through `create_commitment` over the declared set and the mock selection.
- `every_declared_member_declares_itself_through_the_public_surface` (`hashing/admit_hashing_composition`): absorbed; proven by `every_concrete_is_constructed_under_the_identifier_it_declares` in `integration_test.rs`, restated in this node's terms: `create_commitment` called with each member's selection and the identifier the real lookup returns for it passes the real composition admission and constructs the member; its route is that member's interface-held declaration constant, the `match` arm of the selected member, the injected `lookup_hashing_declaration`, `admit_hashing_composition`, and `create_commitment`; the outer-edge collaborators are none.

## Integration: own entries

The three entries proven inside the crate take a private integration block of the same name in `integration_test.rs`; the entry the published vector and the independent oracle decide takes a public integration block of the same name in `tests/factory_integration_test.rs`.

- `every_concrete_is_constructed_under_the_identifier_it_declares`: condition `create_commitment` is called with deps holding the real `admit_hashing_composition` and the real `lookup_hashing_declaration`, the selection of a concrete, and the identifier the real lookup returns for that selection, and the adapter commits the reference content unkeyed; outcome `Ok(CreateCommitmentSuccessReturn { adapter })` whose commit returns an outboard of `OUTBOARD_HEADER_LENGTH + OUTBOARD_PARENT_LENGTH × (chunk count − 1)` bytes, the chunk count read from the case's `L`; variation each member of `COMMITMENT_CONCRETES` and the mock selection, whose declared chunk lengths differ, so a factory that constructs a concrete other than the selected one returns an outboard of another length; edge that must survive the composition: the identifier the factory admits against is read through the lookup from the selected member's own declaration.
- `every_concrete_returns_its_own_error_when_a_content_length_cannot_be_represented`: condition the adapter `create_commitment` returns for the mock selection under the failure mode `ContentLengthUnrepresentable` commits the reference content unkeyed; outcome `Err(CommitErrorReturn::Mock(MockICommitmentAdapterErrorReturn::ContentLengthUnrepresentable { length }))` with `length` equal to `REFERENCE_CONTENT_LENGTH`; variation the mock selection under that failure mode, the case that reaches this arm, since a `usize` byte length fits a `u64` on every supported target and no input takes it for a real concrete; edge that must survive the composition: the failure mode the configuration names is the failure mode of the concrete the factory constructs, and the concrete's own error arrives whole in the family's error union.
- `every_concrete_returns_its_own_error_when_an_offset_cannot_be_represented`: condition the adapter `create_commitment` returns for the mock selection under the failure mode `OffsetUnrepresentable` commits the reference content unkeyed; outcome `Err(CommitErrorReturn::Mock(MockICommitmentAdapterErrorReturn::OffsetUnrepresentable { offset }))` with `offset` equal to `REFERENCE_CONTENT_LENGTH` as a `u64`, the content's length, since `commit`'s payload carries no chunk index; variation the mock selection under that failure mode, the case that reaches this arm; edge that must survive the composition: as the entry above.
- `every_concrete_declaring_the_blake3_bao_identifier_commits_the_reference_content_to_the_bao_hash_and_outboard`: condition `create_commitment` is called with the selection of a member of `COMMITMENT_CONCRETES` whose declaration the real lookup returns with the identifier `CommitmentSchemeIdentifier::Blake3BaoV1`, that identifier, and deps holding the real admission and lookup, and the adapter commits the reference content unkeyed; outcome `Ok(CommitSuccessReturn { root, outboard })` with `root.as_bytes()` equal to bao's published 3073-byte hash `5ba075072daba2470558a171e3769fba057dc3f12375c60892bdbe73348d9fd1` and `outboard.bytes` equal to `expected_outboard` over the reference content unkeyed; variation each member of the declared set whose looked-up identifier is `Blake3BaoV1`; edge that must survive the composition: the concrete the factory constructs commits, through the family's trait object, to the values the published vector and the independent oracle state.

## Integration: private surface

The chain of real functions is `create_commitment`, `admit_hashing_composition`, `lookup_hashing_declaration`, the selected concrete's `try_new`, and `commit`, `verify`, `extract_path`, `verify_chunk`, `challenge`, and `respond` as called on the returned adapter, with `Secret::expose` of `domain` running for real; the cases are `COMMITMENT_CONCRETES` and the mock selection; no outer-edge collaborator is mocked — `blake3`, `bao`, `zeroize`, and `domain` run as themselves; the observable result is the `Result` `create_commitment` returns, each method's return, and the borrowed key's bytes after the call; the entries proven are `every_concrete_is_constructed_under_the_identifier_it_declares`, `every_concrete_returns_its_own_error_when_a_content_length_cannot_be_represented`, `every_concrete_returns_its_own_error_when_an_offset_cannot_be_represented`, `every_concrete_leaves_the_borrowed_key_intact`, `every_concrete_verifies_the_content_it_committed`, `every_concrete_verifies_every_chunk_with_its_extracted_path`, `every_concrete_answers_a_challenge_with_a_response_that_verifies`, and `every_concrete_verifies_a_keyed_path_only_under_its_key`.

## Integration: public surface

An outside caller invokes `create_commitment` with a `CreateCommitmentDeps` holding the crate root's `admit_hashing_composition` and `lookup_hashing_declaration`, a `CreateCommitmentParams` naming a member of `COMMITMENT_CONCRETES` and the identifier the crate root's `lookup_hashing_declaration` returns for it, and a `CreateCommitmentPayload`, calls `commit` on the returned adapter with `CommitParams` and `CommitPayload`, and observes the root's bytes and the outboard's bytes; the entry proven is `every_concrete_declaring_the_blake3_bao_identifier_commits_the_reference_content_to_the_bao_hash_and_outboard`; its route is the public call, the crate root's `admit_hashing_composition`, the crate root's `lookup_hashing_declaration`, the selected concrete's constructor, and `commit`; the outcomes of a `Mock(failure_mode)` selection and of a refusal returned by a caller-supplied admission function, each observable through the public call under the `mocks` feature, are properties of this function alone and are proven by `every_concrete_returns_its_own_error_when_a_content_length_cannot_be_represented`, `every_concrete_returns_its_own_error_when_an_offset_cannot_be_represented`, and `create_commitment_returns_the_composition_refusal_unchanged`, and the outcomes of the returned adapter's other methods are the absorbed entries proven in `factory/integration_test.rs`, so none of these is a public entry.
