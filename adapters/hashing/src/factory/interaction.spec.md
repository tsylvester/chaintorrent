# factory interactions

`create_commitment` is the hashing family's construction point: it hands the concrete `params.concrete` names and the `params.identifier` the hash-card requires to `deps.admit_hashing_composition` before it constructs anything, then calls `deps.lookup_hashing_declaration` for `params.concrete`, constructs the admitted concrete, and hands the concrete and the returned declaration to the consumer `deps.consumer` holds, returning the consumer's output. It reads no hash-card and no configuration — the composition resolver passes both as typed values — and it does not hash; every commitment operation is the concrete's. A member's declaration is read through `lookup_hashing_declaration`, never from the adapter.

## `create_commitment`

`create_commitment<C: ICommitmentConsumer>(deps: &CreateCommitmentDeps<C>, params: CreateCommitmentParams, payload: CreateCommitmentPayload) -> CreateCommitmentReturn<C::Output>`

The function first calls `deps.admit_hashing_composition` with `AdmitHashingCompositionDeps { lookup_hashing_declaration: deps.lookup_hashing_declaration }`, `AdmitHashingCompositionParams { concrete: params.concrete, identifier: params.identifier }`, and `AdmitHashingCompositionPayload`, built by struct literals, before any construction. The decision is a `match` on the admission's return, on `Ok` a call of `deps.lookup_hashing_declaration` for `params.concrete`, then a `match` on `params.concrete`, one arm per `CommitmentConcrete` variant, exhaustive so a variant with no arm fails to compile.

| Branch | Condition | Decision | Dependency call | Outcome |
|---|---|---|---|---|
| composition refused | the admission returns `Err(error)` | the admission's own comparison, which this function repeats nowhere | `deps.admit_hashing_composition` exactly once | `Err(CreateCommitmentErrorReturn::Composition(error))`, the error carried unchanged, with no declaration lookup, no concrete's `try_new` called, and no consumer call beyond the admission's own internal lookup. No input and no failure mode of the official mocks reaches this branch, since the real admission and `mock_admit_hashing_composition` admit every member for the identifier it declares and `CommitmentSchemeIdentifier` holds one real variant, so the unit block `create_commitment_returns_the_composition_refusal_unchanged` reaches it through a production-typed `AdmitHashingCompositionFn` its deps carry |
| `Blake3Bao` arm, composition admitted | the admission returned `Ok` and `params.concrete` is `CommitmentConcrete::Blake3Bao` | the arm of the selected member | `deps.lookup_hashing_declaration` for `params.concrete`, exactly once, its success destructured irrefutably to the `declaration` it returns, then the concrete's `try_new` with its fieldless constructor params, exactly once, its success destructured irrefutably because its error arm is uninhabited, then `deps.consumer.consume_commitment(ConsumeCommitmentParams, ConsumeCommitmentPayload { adapter, declaration })`, exactly once | `Ok(CreateCommitmentSuccessReturn { output })` carrying the consumer's output; the unit tests name no concrete, so the private integration blocks over `COMMITMENT_CONCRETES` prove this arm |

`Mock` arm, under `#[cfg(any(test, feature = "mocks"))]`, composition admitted: `params.concrete` is `CommitmentConcrete::Mock(failure_mode)`; dependency call `deps.lookup_hashing_declaration` for `params.concrete`, exactly once, its success destructured irrefutably to the `declaration` it returns, then the mock concrete's `try_new` with `MockICommitmentAdapterConstructorParams { failure_mode }`, the failure mode the selection carries, exactly once, its success destructured irrefutably, then `deps.consumer.consume_commitment(ConsumeCommitmentParams, ConsumeCommitmentPayload { adapter, declaration })`, exactly once; the outcome is `Ok(CreateCommitmentSuccessReturn { output })` carrying the consumer's output, the adapter the consumer receives answering under the failure mode.

`CreateCommitmentErrorReturn::Blake3Bao` and `CreateCommitmentErrorReturn::Mock` carry the constructors' uninhabited error type `Infallible` in the return union, so no branch produces them.

`params.concrete` selects and, with `params.identifier`, is handed to the composition admission; `deps` carry the consumer, the admission, and the lookup handle the admission's deps are built from and the declaration is read through; `payload` carries nothing and is not read.

## Shared terms

- `L` is the `chunk_length` of the declaration `lookup_hashing_declaration` returns for the case's selection.
- The reference content is `reference_content(REFERENCE_CONTENT_LENGTH)`.
- Its chunk count is `REFERENCE_CONTENT_LENGTH` as a `u64` divided by `L`, rounded up.
- Chunk `i` is the content's bytes from `i × L` to the lesser of `(i + 1) × L` and the content's length.

## Integration: callee dispositions

- `commit_under_a_key_leaves_the_borrowed_key_intact` (`hashing/blake3_bao`): absorbed; proven by `every_concrete_leaves_the_borrowed_key_intact` in this module's private integration test `integration_test.rs`, which runs the entry through `create_commitment` over the declared set and the mock selection.

- `keyed_paths_verify_only_under_their_key` (`hashing/blake3_bao`): absorbed; proven by `every_concrete_verifies_a_keyed_path_only_under_its_key` in this module's private integration test `integration_test.rs`, which runs the entry through `create_commitment` over the declared set and the mock selection.

## Integration: own entries

The three entries proven inside the crate take a private integration block of the same name in `integration_test.rs`; the entry the published vector and the independent oracle decide takes a public integration block of the same name in `tests/factory_integration_test.rs`.

- `every_concrete_is_constructed_under_the_identifier_it_declares`: condition `create_commitment` is called with deps holding the real `admit_hashing_composition`, the real `lookup_hashing_declaration`, and a consumer whose `consume_commitment` calls `commit` on the adapter it receives with the reference content unkeyed and returns the `CommitReturn` it observes, the selection of a concrete, and the identifier the real lookup returns for that selection; outcome `Ok(CreateCommitmentSuccessReturn { output })` whose `output` observes an outboard of `OUTBOARD_HEADER_LENGTH + OUTBOARD_PARENT_LENGTH × (chunk count − 1)` bytes, the chunk count read from the case's `L`; variation each member of `COMMITMENT_CONCRETES` and the mock selection, whose declared chunk lengths differ, so a factory that constructs a concrete other than the selected one returns an outboard of another length; edge that must survive the composition: the identifier the factory admits against is read through the lookup from the selected member's own declaration.
- `every_concrete_returns_its_own_error_when_a_content_length_cannot_be_represented`: condition `create_commitment` is called with the mock selection under the failure mode `ContentLengthUnrepresentable` and a consumer whose `consume_commitment` calls `commit` on the adapter it receives with the reference content unkeyed and returns the `CommitReturn` it observes; outcome `Ok(CreateCommitmentSuccessReturn { output })` whose `output` observes `Err(CommitErrorReturn::Mock(MockICommitmentAdapterErrorReturn::ContentLengthUnrepresentable { length }))` with `length` equal to `REFERENCE_CONTENT_LENGTH`; variation the mock selection under that failure mode, the case that reaches this arm, since a `usize` byte length fits a `u64` on every supported target and no input takes it for a real concrete; edge that must survive the composition: the failure mode the configuration names is the failure mode of the concrete the factory constructs, and the concrete's own error arrives whole in the family's error union.
- `every_concrete_returns_its_own_error_when_an_offset_cannot_be_represented`: condition `create_commitment` is called with the mock selection under the failure mode `OffsetUnrepresentable` and a consumer whose `consume_commitment` calls `commit` on the adapter it receives with the reference content unkeyed and returns the `CommitReturn` it observes; outcome `Ok(CreateCommitmentSuccessReturn { output })` whose `output` observes `Err(CommitErrorReturn::Mock(MockICommitmentAdapterErrorReturn::OffsetUnrepresentable { offset }))` with `offset` equal to `REFERENCE_CONTENT_LENGTH` as a `u64`, the content's length, since `commit`'s payload carries no chunk index; variation the mock selection under that failure mode, the case that reaches this arm; edge that must survive the composition: as the entry above.

## Integration: private surface

The chain of real functions is `create_commitment`, `admit_hashing_composition`, `lookup_hashing_declaration`, the selected concrete's `try_new`, and `ICommitmentConsumer::consume_commitment` calling `commit`, `verify`, `extract_path`, `verify_chunk`, `challenge`, and `respond` on the adapter it receives, with `Secret::expose` of `domain` running for real; the cases are `COMMITMENT_CONCRETES` and the mock selection; no outer-edge collaborator is mocked — `blake3`, `bao`, `zeroize`, and `domain` run as themselves; the observable result is the `Result` `create_commitment` returns carrying the consumer's `output`, each method's return the consumer observes, and the borrowed key's bytes after the call; the entries proven are `every_concrete_is_constructed_under_the_identifier_it_declares`, `every_concrete_returns_its_own_error_when_a_content_length_cannot_be_represented`, `every_concrete_returns_its_own_error_when_an_offset_cannot_be_represented`, and the absorbed entries.

## Integration: public surface

An outside caller invokes `create_commitment` with a `CreateCommitmentDeps` holding a caller-supplied `ICommitmentConsumer` and the crate root's `admit_hashing_composition` and `lookup_hashing_declaration`, a `CreateCommitmentParams` naming a member of `COMMITMENT_CONCRETES` and the identifier the crate root's `lookup_hashing_declaration` returns for it, and a `CreateCommitmentPayload`, and observes through the consumer's `output` the `CommitReturn` its `consume_commitment` returns from calling `commit` on the adapter it receives with `CommitParams` and `CommitPayload`, the root's bytes and the outboard's bytes; the entry proven is `every_concrete_declaring_the_blake3_bao_identifier_commits_the_reference_content_to_the_bao_hash_and_outboard`; its route is the public call, the crate root's `admit_hashing_composition`, the crate root's `lookup_hashing_declaration`, the selected concrete's constructor, `ICommitmentConsumer::consume_commitment`, and `commit`; the outcomes of a `Mock(failure_mode)` selection and of a refusal returned by a caller-supplied admission function, each observable through the public call under the `mocks` feature, are properties of this function alone and are proven by `every_concrete_returns_its_own_error_when_a_content_length_cannot_be_represented`, `every_concrete_returns_its_own_error_when_an_offset_cannot_be_represented`, and `create_commitment_returns_the_composition_refusal_unchanged`, and the outcomes of the adapter's other methods called inside the consumer are the absorbed entries proven in `factory/integration_test.rs`, so none of these is a public entry.
