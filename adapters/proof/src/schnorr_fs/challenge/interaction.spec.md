# `schnorr_fs/challenge` — interaction spec

Branch contract for the `challenge` function of the `schnorr_fs` concrete of the `proof` crate: the Fiat–Shamir challenge of the delivery proof, the injected hash-to-scalar adapter's mapping, under the proof's domain tag `SCHNORR_FS_CHALLENGE_TAG`, of the injected encoder's encoding of a mint or transfer transcript through that transcript's own pairing-borrowing description. Each branch states condition, decision, dependency call, and the exact return outcome.

The trusted form: the transcript arrives as a typed `ChallengeTranscript` from `proof/schnorr_fs`, so no entry guard exists and `payload` is not `unknown`.

## `challenge<S: ISampleUniformScalar + Clone, E: IEncoderAdapter, P: IPairingAdapter<Scalar = S>, F: IChainForms>(deps: &ChallengeDeps<'_, P, E>, params: ChallengeParams, payload: ChallengePayload<'_, P, F>) -> ChallengeReturn<S>`

The challenge tag is constructed once in `SchnorrFsDeliveryProof::try_new` from `SCHNORR_FS_CHALLENGE_TAG` and borrowed in `ChallengeDeps`; each challenge call uses that admitted tag without constructing a new one.

| Branch | Condition | Decision | Dependency call | Outcome |
|---|---|---|---|---|
| encode mint transcript | `payload.transcript` is `ChallengeTranscript::Mint(statement)` | none | `MintStatementDescription::<P, F>::try_new(MintStatementDescriptionConstructorParams { pairing: deps.pairing })`, unpacked irrefutably, then `deps.encoder.encode(EncodeParams { description: &description }, statement)`, once | `Err(ChallengeErrorReturn::Encoding(error))` on refusal, the refusal unchanged; otherwise yields the encoding's `bytes` |
| encode transfer transcript | `payload.transcript` is `ChallengeTranscript::Transfer(statement)` | none | `TransferStatementDescription::<P, F>::try_new(TransferStatementDescriptionConstructorParams { pairing: deps.pairing })`, unpacked irrefutably, then `deps.encoder.encode(EncodeParams { description: &description }, statement)`, once | `Err(ChallengeErrorReturn::Encoding(error))` on refusal, the refusal unchanged; otherwise yields the encoding's `bytes` |
| hash refused | `deps.hash_to_scalar.hash_to_scalar(…)` returns `Err(error)` | none | `deps.hash_to_scalar.hash_to_scalar(HashToScalarParams { tag: deps.tag }, HashToScalarPayload { message: &bytes })`, once, after the encoding | `Err(ChallengeErrorReturn::HashToScalar(error))`, the refusal unchanged; the keccak256 concrete refuses no tag this function holds and no scalar type whose uniform length is at least its digest's, which every current scalar type is, so only the family's declared `Mock(SamplingRefused)` concrete reaches this branch and `challenge_returns_the_hash_to_scalar_refusal_unchanged` proves it |
| computed | the hash returns `Ok(success)` | none | as above | `Ok(ChallengeSuccessReturn { challenge: success.scalar })` |

## Ordering and invariants

- The already-admitted tag is borrowed, then the matching pairing-borrowing description is constructed, then encoding is attempted, then hashing; an encoding refusal prevents the hash call; the transcript is borrowed and unchanged.
- `params` carries no control and is not read.
- For a given encoder and hash-to-scalar adapter, the challenge is a function of the transcript alone: the mapping under `SCHNORR_FS_CHALLENGE_TAG` of the transcript's encoding through its own description, which the contract recomputes from the same fields.

## Integration: callee dispositions

Each `hash-to-scalar/factory` entry whose route this node's function extends is absorbed and restated in this node's terms; no outer-edge collaborator is on any route.

- `hash-to-scalar/factory` entry `every_concrete_declaring_the_keccak256_identifier_hashes_the_context_the_encoding_factory_encodes_to_the_oracle`: absorbed — proven by `the_mint_challenge_is_the_tagged_hash_of_the_mint_transcripts_encoding` and `the_transfer_challenge_is_the_tagged_hash_of_the_transfer_transcripts_encoding` in `integration_test.rs`, restated in this node's terms as: the scalar `challenge` returns for a transcript equals the oracle scalar of the bytes the encoder returned, under the proof's tag.
- `hash-to-scalar/factory` entry `an admitted tag reads back through the crate root`: absorbed — proven by `the_mint_challenge_is_the_tagged_hash_of_the_mint_transcripts_encoding` and `the_transfer_challenge_is_the_tagged_hash_of_the_transfer_transcripts_encoding`, whose oracle reads the tag's `as_bytes()` and equals the scalar the adapter produced from the tag `deps.tag` carried.

## Integration: own entries

Each entry is proven by the private integration block of the same name in `integration_test.rs`.

- `the_mint_challenge_is_the_tagged_hash_of_the_mint_transcripts_encoding`: condition `challenge` is called over `ChallengeTranscript::Mint(&statement)`, `statement` from `build_mint_statement` over the pairing the case consumer received, with the encoder and the hash-to-scalar adapter the case consumer received, and `deps.tag` the admitted `SCHNORR_FS_CHALLENGE_TAG`; outcome `Ok(ChallengeSuccessReturn { challenge })` whose encoding through the pairing's `encode_scalar` equals the encoding of the scalar the received scalar type samples from `expected_uniform_bytes(&tag, &bytes, S::UNIFORM_BYTES_LENGTH)`, `bytes` the received encoder's `encode` of the statement under `MintStatementDescription`; variation every member of `DECLARED_ENCODING_SELECTIONS`, each over every member of `PAIRING_CONCRETES`, of `CHAIN_FORMS_CONCRETES`, and of the cases of `DECLARED_HASH_TO_SCALAR_SELECTIONS` that declare `HashToScalarIdentifier::Keccak256V1`, and each of `MintPurpose::Mint` and `MintPurpose::Replacement`, the statement's values distinct at every position; edge that must survive the composition: the bytes hashed are the encoding of the whole statement through the mint description, hashed under the proof's tag, and reduced through the received scalar type.
- `the_transfer_challenge_is_the_tagged_hash_of_the_transfer_transcripts_encoding`: condition `challenge` is called over `ChallengeTranscript::Transfer(&statement)`, `statement` from `build_transfer_statement` over the pairing the consumer received, with the same collaborators; outcome `Ok(ChallengeSuccessReturn { challenge })` whose encoding through the pairing's `encode_scalar` equals the encoding of the scalar the received scalar type samples from `expected_uniform_bytes(&tag, &bytes, S::UNIFORM_BYTES_LENGTH)`, `bytes` the received encoder's `encode` of the statement under `TransferStatementDescription`; variation the same declared sets and each of `TransferPurpose::Transfer` and `TransferPurpose::Grant`, the statement's values distinct at every position; edge that must survive the composition: the bytes hashed are the encoding of the whole statement through the transfer description, and the sale's and the grant's challenges are each the tagged hash of their own encoding.
- `a_transcript_differing_in_one_field_yields_another_challenge`: condition `challenge` is called over a statement that differs from a baseline statement in one field; outcome the encoding of `challenge` equals the encoding of the oracle scalar of the variant's encoding and differs from the encoding of the oracle scalar of the baseline's encoding; variation each field of `MintStatement` and of `TransferStatement` overridden alone with a value from that field's own builder distinct from the default, over the same declared sets; edge that must survive the composition: no field of either transcript is absent from the bytes hashed, so a proof is valid for exactly one settlement.
- `the_challenge_tag_is_admitted_as_a_domain_tag`: condition `DomainTag::try_new` is called over `SCHNORR_FS_CHALLENGE_TAG`; outcome `Ok(tag)` with `tag.as_bytes()` equal to `SCHNORR_FS_CHALLENGE_TAG`; variation the proof's tag constant against the hash-to-scalar family's admission, so a constant that is empty, exceeds the one-byte length prefix, holds a byte outside `0x20` through `0x7E`, or has a space at either edge fails; edge that must survive the composition: the tag the concrete's declaration carries and the generate family mirrors is a tag the family admits.
