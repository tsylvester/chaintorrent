# `transfer_statement` — interaction spec

Branch contract for the `transfer_statement` module of the `proof` crate: the transfer transcript under delivery-statement version one — serving sale and grant, the purpose field telling them apart — and its canonical description, which flattens the transcript to canonical fields — each chain form through its own `ICanonicalField`, each group element through the selected pairing's precompile encoding — and rebuilds it only from fields that satisfy every kind, domain, form, and group check in ascending index. Each branch states condition, decision, dependency call, and the exact return outcome.

## `TransferStatementDescription::try_new(params: TransferStatementDescriptionConstructorParams<'_, P>) -> TransferStatementDescriptionTryNewReturn<'_, P, F>`

| Branch | Condition | Decision | Dependency call | Outcome |
|---|---|---|---|---|
| construct | any params | none | none | `Ok(TransferStatementDescription { pairing, forms: PhantomData })`, `pairing` the supplied `&P` stored unchanged |

The error arm has no branch: `Infallible` is uninhabited.

## `IEncodingContract` for `TransferStatementDescription<'_, P, F>`

`Described` is `TransferStatement<P, F>`; `FromFieldsErrorReturn` is `TransferStatementFromFieldsErrorReturn`; `FIELDS` is, in index order: `FixedBytes32`, `Unsigned16`, `<F::ChainIdentifier as ICanonicalField>::KIND`, `<F::Identity as ICanonicalField>::KIND`, `FixedBytes32`, `FixedBytes32`, `<F::Entitlement as ICanonicalField>::KIND`, `<F::Entitlement as ICanonicalField>::KIND`, `<F::Interval as ICanonicalField>::KIND`, `<F::Interval as ICanonicalField>::KIND`, `Unsigned16`, `<F::Identity as ICanonicalField>::KIND`, `<F::Identity as ICanonicalField>::KIND`, `Bytes` ×12, `Unsigned64`, `Bytes` ×6.

## `to_fields(&self, params: ToFieldsParams, payload: &TransferStatement<P, F>) -> ToFieldsReturn`

| Branch | Condition | Decision | Dependency call | Outcome |
|---|---|---|---|---|
| encoded | any | the declared field order and kinds | index `0`: `FixedBytes32(*suite_identifier.identifier())`; `1`: `Unsigned16(suite_identifier.version())`; `2`, `3`, `6`, `7`, `8`, `9`, `11`, `12`: each form's `to_field(ToFieldParams, &form)`, the field's value moved out; `4`: `FixedBytes32(*asset_root.as_bytes())`; `5`: `FixedBytes32(*parameter_set_identifier.as_bytes())`; `10`: `Unsigned16(purpose.code())`; `13`–`24` and `26`–`31`: `self.pairing.encode_g1` over each `P::G1` field and `encode_g2` over each `P::G2` field, each encoded wrapper's `as_ref()` bytes copied into `CanonicalFieldValue::Bytes`; `25`: `Unsigned64(expiry)` | `Ok(ToFieldsSuccessReturn { fields })` with `fields.values` the 32 values in transcript order |

Fields `13`–`24` encode `seller_keys.pk1` (G1), `seller_keys.pk2` (G2), `buyer_keys.pk1` (G1), `buyer_keys.pk2` (G2), `old_envelope.c1` (G1), `old_envelope.c2` (G1), `old_envelope.d1` (G2), `old_envelope.d2` (G2), `new_envelope.c1` (G1), `new_envelope.c2` (G1), `new_envelope.d1` (G2), `new_envelope.d2` (G2); fields `26`–`31` encode `first_messages.pk1` (G1), `first_messages.c1` (G1), `first_messages.c2` (G1), `first_messages.pk2` (G2), `first_messages.d1` (G2), `first_messages.d2` (G2). Every `to_field` and `encode_*` return is `Result<_, Infallible>`; each unpack is irrefutable. `params` carries no control.

| Branch | Condition | Decision | Dependency call | Outcome |
|---|---|---|---|---|
| wrong count | `payload.values` does not convert into `[CanonicalFieldValue; TRANSFER_STATEMENT_FIELD_COUNT]` | `TryFrom<Vec<CanonicalFieldValue>>` for the array, which returns the vector on failure | none | `Err(FieldCount { expected: TRANSFER_STATEMENT_FIELD_COUNT, actual })`, `actual` the returned vector's length |

| form refused | the count matches and the form at index `2`, `3`, `6`, `7`, `8`, `9`, `11`, or `12` returns `Err(error)` from its `from_field` | that form's `from_field(FromFieldParams, value)`, the value moved in, once per form field, in ascending index | `F::ChainIdentifier::from_field` at `2`; `F::Identity::from_field` at `3`, `11`, `12`; `F::Entitlement::from_field` at `6`, `7`; `F::Interval::from_field` at `8`, `9` | `Err(ChainIdentifier { index, error })` for `2`, `Identity { index, error }` for `3`, `11`, `12`, `Entitlement { index, error }` for `6`, `7`, `Interval { index, error }` for `8`, `9`, the refusal unchanged |
| suite identifier refused | fields `0` and `1` are of their kinds and `SuiteIdentifier::try_new` over them returns `Err(error)` | the constructor runs once, after field `1` is read | `SuiteIdentifier::try_new(SuiteIdentifierConstructorParams { identifier, version })` | `Err(SuiteIdentifier(error))`, the refusal unchanged |
| asset root refused | field `4` is `FixedBytes32` and the constructor returns `Err(error)` | the constructor runs once, when its field is read | `Root::try_new(RootConstructorParams { bytes })` | `Err(AssetRoot(error))`, the refusal unchanged |
| parameter-set digest refused | field `5` is `FixedBytes32` and the constructor returns `Err(error)` | the constructor runs once, when its field is read | `ParameterSetIdentifier::try_new(ParameterSetIdentifierConstructorParams { bytes })` | `Err(ParameterSetIdentifier(error))`, the refusal unchanged |
| purpose refused | field `10` is `Unsigned16` and `TransferPurpose::try_from(code)` rejects it | any code except transfer or grant fails — `TransferPurpose` already fixes the relation, so a mint-relation wire code is refused here before a trusted statement is built | `TransferPurpose::try_from(code)` | `Err(PurposeCode { index: 10, code })` |
| invalid group encoding | every prior check passes and a `Bytes` field at index `13`–`24` or `26`–`31` refuses to decode | decode in ascending index, first refusal decides | `self.pairing.decode_g1(DecodeG1Params, &bytes)` for `13`, `15`, `17`, `18`, `21`, `22`, `26`, `27`, `28`; `decode_g2(DecodeG2Params, &bytes)` for `14`, `16`, `19`, `20`, `23`, `24`, `29`, `30`, `31` | `Err(InvalidG1 { index, error })` or `Err(InvalidG2 { index, error })`, `error` the decoder's refusal unchanged |

## Ordering and invariants

- The count check precedes every field read; the fields are read in ascending index, each field's kind check, form reconstruction, or domain construction completing before the next field is read — the suite identifier is constructed once field `1` is read, the asset root once `4` is read, the digest once `5`, the purpose once `10`, and group decoding begins only after every earlier check.
- The lowest failing index decides; the same payload always yields the same outcome.
- `params` carries no control and is not read.
- A reconstructed transfer statement contains only group elements admitted by the selected pairing's decoders and a `TransferPurpose`; a round trip preserves the exact canonical field order and values.

## Integration: own entries

Each entry is proven by the public integration block of the same name in `tests/transfer_statement_integration_test.rs`.

- `a_transfer_statement_survives_the_encoding_round_trip`: condition a statement from `build_transfer_statement` over the pairing the consumer received, handed with its `TransferStatementDescription` to the received encoder's `encode` and the bytes returned handed to `decode` with the same description; outcome `Ok(DecodeSuccessReturn { described })` whose every field equals the original's — the forms, the domain values, the purpose, and the expiry by equality, and the group elements through the pairing's `encode_g1` and `encode_g2`; variation every member of `DECLARED_ENCODING_SELECTIONS`, each over every member of `PAIRING_CONCRETES` and of `CHAIN_FORMS_CONCRETES`, and each of `TransferPurpose::Transfer` and `TransferPurpose::Grant`, the statement's values distinct at every position so that a swap of same-kind fields fails; edge that must survive the composition: the declared field kinds are the kinds the encoder admits, and the group elements the real decoder admits are the elements the real encoder emitted.
