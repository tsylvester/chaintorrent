# factory interactions

`create_hash_to_scalar` is the hash-to-scalar family's construction point: it constructs the member `params.concrete` names and returns it behind `Box<dyn IHashToScalarAdapter<S>>` for the scalar type `S` the caller names. It reads no hash-card and no configuration, builds no selection, and reads no declaration — the composition resolver passes the typed `HashToScalarConcrete` that `admit_hash_to_scalar_selection` returned as `concrete` — and it does not hash; hashing is the concrete's.

## `create_hash_to_scalar`

`create_hash_to_scalar<S: ISampleUniformScalar + Clone>(deps: &CreateHashToScalarDeps, params: CreateHashToScalarParams, payload: CreateHashToScalarPayload) -> CreateHashToScalarReturn<S>`

The decision is a `match` on `params.concrete`, one arm per `HashToScalarConcrete` variant, exhaustive so a variant with no arm fails to compile.

| Branch | Condition | Dependency call | Outcome |
|---|---|---|---|
| `Keccak256` | `params.concrete` is `HashToScalarConcrete::Keccak256` | the concrete's `try_new` with its fieldless constructor params, exactly once, its success destructured irrefutably because its error arm is uninhabited | `Ok(CreateHashToScalarSuccessReturn { adapter: Box::new(hasher) })`; no official mock selects this arm, since a mock selection is the `Mock` arm's, and the private integration test element `factory/integration_test.rs` proves it through `every_admitted_selection_is_constructed_into_an_adapter_that_hashes` and the absorbed oracle entries |

`Mock` arm, under `#[cfg(any(test, feature = "mocks"))]`: condition `params.concrete` is `HashToScalarConcrete::Mock(failure_mode)`; the dependency call is the mock concrete's `try_new` with `MockIHashToScalarAdapterConstructorParams { failure_mode }`, the failure mode the selection carries, exactly once, its success destructured irrefutably because its error arm is uninhabited; the outcome is `Ok(CreateHashToScalarSuccessReturn { adapter: Box::new(mock) })`, whose adapter hashes under the failure mode; the unit test element proves the arm constructs under each failure mode, and the failure mode's effect on the adapter is observable only through a call on the adapter, which the private integration test element proves through `every_concrete_returns_the_sampling_bound_refusal_whole`.

`CreateHashToScalarErrorReturn::Keccak256` and `CreateHashToScalarErrorReturn::Mock` carry the constructors' uninhabited error type in the return union, so no branch produces them.

`params.concrete` selects the member; `S` fixes the scalar type the returned adapter produces; `deps` and `payload` carry nothing and are not read.

## Integration: own entries

The first two entries are proven by the private integration block of the same name in `factory/integration_test.rs`, the last two by the public integration block of the same name in `tests/factory_integration_test.rs`.

- `every_admitted_selection_is_constructed_into_an_adapter_that_hashes`: condition `create_hash_to_scalar` is called with the selection of each member of `HASH_TO_SCALAR_CONCRETES` and with the selection of the family's mock member under `MockIHashToScalarAdapterFailureMode::Succeeds`, and the adapter hashes the default tag and message; outcome `Ok(CreateHashToScalarSuccessReturn { adapter })` whose `hash_to_scalar` yields `Ok`; variation every member of the declared set and the mock member, over every member of `PAIRING_CONCRETES`, so a factory that refuses a selection the family declares, or constructs no adapter for it, yields a result this entry rejects; edge that must survive the composition: every selection the family declares is constructible through the factory alone, with no identifier supplied beside it.
- `every_concrete_returns_the_sampling_bound_refusal_whole`: condition the adapter `create_hash_to_scalar` returns for `HashToScalarConcrete::Mock(MockIHashToScalarAdapterFailureMode::SamplingRefused)` hashes a tag and a message; outcome `Err(HashToScalarErrorReturn::Sampling(SampleUniformScalarErrorReturn::WrongLength { expected: S::UNIFORM_BYTES_LENGTH, actual: 0 }))`; variation the mock selection under that failure mode over every member of `PAIRING_CONCRETES`, the case that reaches this arm, since no input takes it for a real concrete, whose sampler receives exactly its bound; edge that must survive the composition: the failure mode the configuration names is the failure mode of the concrete the factory constructs, and the sampling refusal arrives whole in the family's `Sampling` flavor.
- `every_concrete_declaring_the_keccak256_identifier_hashes_the_reference_inputs_to_the_oracle`: condition `create_hash_to_scalar` is called with the selection of a member whose declaration, read through `lookup_hash_to_scalar_declaration`, carries `HashToScalarIdentifier::Keccak256V1`, and the adapter hashes the tag `REFERENCE_TAG` built by `DomainTag::try_new` over `REFERENCE_MESSAGE`; outcome the encoding of the returned scalar equals the encoding of the scalar the received scalar type samples from `expected_uniform_bytes(&tag, REFERENCE_MESSAGE, S::UNIFORM_BYTES_LENGTH)`; variation each case of the declared set that declares the identifier over every member of `PAIRING_CONCRETES`, each with its own scalar type; edge that must survive the composition: the concrete the factory constructs hashes, through the family's trait object and the crate root alone, to the scalar the independent oracle states.
- `every_concrete_declaring_the_keccak256_identifier_hashes_the_context_the_encoding_factory_encodes_to_the_oracle`: condition `create_hash_to_scalar` is called with the selection of a member whose declaration, read through `lookup_hash_to_scalar_declaration`, carries `HashToScalarIdentifier::Keccak256V1`, and the adapter hashes `REFERENCE_TAG` over the bytes `create_encoding` returns for a value of the family's mock description; outcome the encoding of the returned scalar equals the encoding of the scalar the received scalar type samples from `expected_uniform_bytes(&tag, bytes, S::UNIFORM_BYTES_LENGTH)`, `bytes` the bytes the encoding returned; variation each case of the declared set that declares the identifier over each case of `DECLARED_ENCODING_SELECTIONS` that declares `EncodingIdentifier::EthereumAbiV1` and every member of `PAIRING_CONCRETES`, so a hash that frames the message by the reference message's shape, or reads other bytes than the encoding returned, yields a scalar the oracle does not state; edge that must survive the composition: the bytes the encoding family produces are hashed as returned.

## Integration: private surface

The chain of real functions `create_pairing`, the arm's concrete through its `try_new`, `lookup_hash_to_scalar_declaration` for each member's declared identifier, `create_hash_to_scalar`, the selected concrete's `try_new` and `hash_to_scalar` as called on the returned adapter, `DomainTag::try_new` through `build_domain_tag`, the received scalar's `sample_from_uniform_bytes`, and the received adapter's `encode_scalar`, with `Secret::expose` and the `Secret` drop of `domain` running for real; the cases are the members of `HASH_TO_SCALAR_CONCRETES` and the mock selection over every member of `PAIRING_CONCRETES`; no outer-edge collaborator is mocked, `sha3`, `zeroize`, and `domain` running as themselves; the observable result is the `Result` `create_hash_to_scalar` returns, the result `hash_to_scalar` returns, and the encoded scalar bytes read through `Secret::expose`; the entries proven are `every_admitted_selection_is_constructed_into_an_adapter_that_hashes`, `every_concrete_returns_the_sampling_bound_refusal_whole`, and the absorbed entries above.
