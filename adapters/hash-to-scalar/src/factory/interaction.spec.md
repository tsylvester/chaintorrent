# factory interactions

`create_hash_to_scalar` is the hash-to-scalar family's construction point: it reads the `HashToScalarDeclaration` of the member `params.concrete` names through the `LookupHashToScalarDeclarationFn` its deps carry, before construction, constructs that member for the scalar type `S` the caller names, and hands the concrete and that declaration to a caller-supplied `IHashToScalarConsumer<S>`, whose output it returns; it never returns `Box<dyn IHashToScalarAdapter<S>>` or any trait object. It reads no hash-card and no configuration, builds no selection, and admits none — the composition resolver passes the typed `HashToScalarConcrete` that `admit_hash_to_scalar_selection` returned as `concrete` — and it does not hash; hashing is the concrete's.

## `create_hash_to_scalar`

`create_hash_to_scalar<S: ISampleUniformScalar + Clone, C: IHashToScalarConsumer<S>>(deps: &CreateHashToScalarDeps<C>, params: CreateHashToScalarParams, payload: CreateHashToScalarPayload) -> CreateHashToScalarReturn<C::Output>`

The function first calls `(deps.lookup)` for `params.concrete` before any construction, binding `declaration`, its `Ok` destructured irrefutably because the lookup's error arm is uninhabited. The decision is a `match` on `params.concrete`, one arm per `HashToScalarConcrete` variant, exhaustive so a variant with no arm fails to compile.

| Branch | Condition | Dependency call | Outcome |
|---|---|---|---|
| `Keccak256` | `params.concrete` is `HashToScalarConcrete::Keccak256` | `deps.lookup` for `params.concrete`, exactly once, then the concrete's `try_new` with its fieldless constructor params, exactly once, its success destructured irrefutably because its error arm is uninhabited, then `deps.consumer.consume_hash_to_scalar(ConsumeHashToScalarParams, ConsumeHashToScalarPayload { adapter, declaration })`, exactly once | `Ok(CreateHashToScalarSuccessReturn { output })` carrying the consumer's output; no official mock selects this arm, since a mock selection is the `Mock` arm's, and the private integration test element `factory/integration_test.rs` proves it through `every_admitted_selection_is_constructed_into_an_adapter_that_hashes` and the absorbed oracle entries |

`Mock` arm, under `#[cfg(any(test, feature = "mocks"))]`: condition `params.concrete` is `HashToScalarConcrete::Mock(failure_mode)`; the dependency call is `deps.lookup` for `params.concrete`, exactly once, then the mock concrete's `try_new` with `MockIHashToScalarAdapterConstructorParams { failure_mode }`, the failure mode the selection carries, exactly once, its success destructured irrefutably because its error arm is uninhabited, then `deps.consumer.consume_hash_to_scalar(ConsumeHashToScalarParams, ConsumeHashToScalarPayload { adapter, declaration })`, exactly once; the outcome is `Ok(CreateHashToScalarSuccessReturn { output })` carrying the consumer's output, the adapter the consumer receives hashing under the failure mode; the unit test element proves the arm constructs under each failure mode, and the failure mode's effect on the adapter is observable only through a call on the adapter, which the private integration test element proves through `every_concrete_returns_the_sampling_bound_refusal_whole`.

`CreateHashToScalarErrorReturn::Keccak256` and `CreateHashToScalarErrorReturn::Mock` carry the constructors' uninhabited error type in the return union, so no branch produces them.

`params.concrete` selects the member; `S` fixes the scalar type the adapter the consumer receives produces; `deps` carry the consumer and the lookup handle the declaration is read through; `payload` carries nothing and is not read.

## Integration: own entries

The first two entries are proven by the private integration block of the same name in `factory/integration_test.rs`, the last two by the public integration block of the same name in `tests/factory_integration_test.rs`.

- `every_admitted_selection_is_constructed_into_an_adapter_that_hashes`: condition `create_hash_to_scalar` is called with the selection of each member of `HASH_TO_SCALAR_CONCRETES` and with the selection of the family's mock member under `MockIHashToScalarAdapterFailureMode::Succeeds`, deps holding the real `lookup_hash_to_scalar_declaration`, and a consumer whose `consume_hash_to_scalar` calls `hash_to_scalar` on the adapter it receives over the default tag and message and returns what it observes; outcome `Ok(CreateHashToScalarSuccessReturn { output })` whose `output` observes `hash_to_scalar` yielding `Ok`; variation every member of the declared set and the mock member, over every member of `PAIRING_CONCRETES`, so a factory that refuses a selection the family declares, or constructs no adapter for it, yields a result this entry rejects; edge that must survive the composition: every selection the family declares is constructible through the factory alone, with no identifier supplied beside it.
- `every_concrete_returns_the_sampling_bound_refusal_whole`: condition `create_hash_to_scalar` is called for `HashToScalarConcrete::Mock(MockIHashToScalarAdapterFailureMode::SamplingRefused)` with a consumer whose `consume_hash_to_scalar` calls `hash_to_scalar` on the adapter it receives over a tag and a message and returns its return; outcome `Ok(CreateHashToScalarSuccessReturn { output })` whose `output` is `Err(HashToScalarErrorReturn::Sampling(SampleUniformScalarErrorReturn::WrongLength { expected: S::UNIFORM_BYTES_LENGTH, actual: 0 }))`; variation the mock selection under that failure mode over every member of `PAIRING_CONCRETES`, the case that reaches this arm, since no input takes it for a real concrete, whose sampler receives exactly its bound; edge that must survive the composition: the failure mode the configuration names is the failure mode of the concrete the factory constructs, and the sampling refusal arrives whole in the family's `Sampling` flavor.
- `every_concrete_declaring_the_keccak256_identifier_hashes_the_reference_inputs_to_the_oracle`: condition `create_hash_to_scalar` is called with the selection of a member whose declaration, read through `lookup_hash_to_scalar_declaration`, carries `HashToScalarIdentifier::Keccak256V1`, and a consumer whose `consume_hash_to_scalar` builds the tag `REFERENCE_TAG` by `DomainTag::try_new`, calls `hash_to_scalar` on the adapter it receives over `REFERENCE_MESSAGE`, samples the oracle's uniform input through `S`, and returns the two encodings; outcome `Ok(CreateHashToScalarSuccessReturn { output })` whose `output` observes the encoding of the returned scalar equal to the encoding of the scalar the received scalar type samples from `expected_uniform_bytes(&tag, REFERENCE_MESSAGE, S::UNIFORM_BYTES_LENGTH)`; variation each case of the declared set that declares the identifier over every member of `PAIRING_CONCRETES`, each with its own scalar type; edge that must survive the composition: the concrete the factory hands the consumer hashes, through the family's trait and the crate root alone, to the scalar the independent oracle states.
