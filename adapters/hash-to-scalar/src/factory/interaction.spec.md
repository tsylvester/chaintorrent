# factory interactions

`create_hash_to_scalar` is the hash-to-scalar family's construction point: it selects the concrete `params.concrete` names, admits it only when its `DECLARATION.identifier` is the `params.identifier` the hash-card requires, and returns it behind `Box<dyn IHashToScalarAdapter<S>>` for the scalar type `S` the caller names; the adapter reports its declaration. It reads no hash-card and no configuration — the composition resolver passes both as typed values — and it does not hash; hashing is the concrete's.

## `create_hash_to_scalar`

`create_hash_to_scalar<S: ISampleUniformScalar + Clone>(deps: &CreateHashToScalarDeps, params: CreateHashToScalarParams, payload: CreateHashToScalarPayload) -> CreateHashToScalarReturn<S>`

The decision is a `match` on `params.concrete`, one arm per `HashToScalarConcrete` variant, exhaustive so a variant with no arm fails to compile. Within each arm:

| Branch | Condition | Decision | Dependency call | Outcome |
|---|---|---|---|---|
| unsupported identifier | the named concrete's `DECLARATION.identifier` is not `params.identifier` | equality, read before any construction | none | `Err(CreateHashToScalarErrorReturn::UnsupportedHashToScalarIdentifier)`; nothing is constructed. Under the `mocks` feature the mock concrete declares `HashToScalarIdentifier::Mock`, so a real concrete's selection paired with `Mock`, and the mock selection paired with another concrete's identifier, take this branch |
| admitted | the named concrete's declared identifier is `params.identifier` | the equality above | the concrete's `try_new` with its fieldless constructor params, exactly once, its success destructured irrefutably because its error arm is uninhabited | `Ok(CreateHashToScalarSuccessReturn { adapter: Box::new(hasher) })`, whose boxed adapter reports the concrete's `DECLARATION` |

`Mock` arm, under `#[cfg(any(test, feature = "mocks"))]`: the same admission over `MockIHashToScalarAdapter::DECLARATION.identifier`; the dependency call is the mock concrete's `try_new` with `MockIHashToScalarAdapterConstructorParams { failure_mode }`, the failure mode the selection carries, exactly once, its success destructured irrefutably because its error arm is uninhabited; the outcome is `Ok(CreateHashToScalarSuccessReturn { adapter: Box::new(mock) })`, whose adapter reports `HashToScalarIdentifier::Mock` and hashes under the failure mode.

`CreateHashToScalarErrorReturn::Keccak256` and `CreateHashToScalarErrorReturn::Mock` carry the constructors' uninhabited error type in the return union, so no branch produces them.

`params.concrete` selects and `params.identifier` admits; `S` fixes the scalar type the returned adapter produces; `deps` and `payload` carry nothing and are not read.

## Integration: callee dispositions

The entries of `hash-to-scalar/keccak256` and `hash-to-scalar/domain_tag` that this node's routes reach, each dispositioned as stated.

- `hash_to_scalar_matches_the_oracle_for_the_reference_tag_and_message` (`hash-to-scalar/keccak256`): absorbed — proven by `every_concrete_declaring_the_keccak256_identifier_matches_the_oracle_for_the_reference_tag_and_message` in the private integration test element `factory/integration_test.rs`, which runs the entry through `create_hash_to_scalar` over each case of the declared set that declares `HashToScalarIdentifier::Keccak256V1`; in this node's terms the encoding of the scalar the returned adapter yields for `REFERENCE_TAG` and `REFERENCE_MESSAGE` equals the encoding of the scalar the received scalar type samples from `expected_uniform_bytes(&tag, REFERENCE_MESSAGE, S::UNIFORM_BYTES_LENGTH)`.
- `hash_to_scalar_matches_the_oracle_for_the_empty_message` (`hash-to-scalar/keccak256`): absorbed — proven by `every_concrete_declaring_the_keccak256_identifier_matches_the_oracle_for_the_empty_message` in `factory/integration_test.rs`, which runs the entry through `create_hash_to_scalar` over the same cases with `REFERENCE_TAG` and `EMPTY_MESSAGE` under `expected_uniform_bytes`.
- `hash_to_scalar_binds_the_tag_length` (`hash-to-scalar/keccak256`): absorbed — proven by `every_concrete_declaring_the_keccak256_identifier_binds_the_tag_length` in `factory/integration_test.rs`, which runs the entry through `create_hash_to_scalar` over the same cases with `BINDING_LONGER_TAG` and `BINDING_SHORTER_MESSAGE` under `expected_uniform_bytes`.
- `hash_to_scalar_separates_domains` (`hash-to-scalar/keccak256`): absorbed — proven by `every_concrete_declaring_the_keccak256_identifier_separates_domains` in `factory/integration_test.rs`, which runs the entry through `create_hash_to_scalar` over the same cases with `OTHER_TAG` and `REFERENCE_MESSAGE` under `expected_uniform_bytes`.

## Integration: own entries

The first three entries are proven by the private integration block of the same name in `factory/integration_test.rs`, the last two by the public integration block of the same name in `tests/factory_integration_test.rs`.

- `every_concrete_is_constructed_under_the_identifier_it_declares`: condition `create_hash_to_scalar` is called with the selection of a concrete and the identifier that concrete declares; outcome `Ok(CreateHashToScalarSuccessReturn { adapter })` with `adapter.declaration()` reporting the identifier required and the interface version `HASH_TO_SCALAR_INTERFACE_VERSION`; variation each case of the declared set and the mock selection, whose declared identifiers differ, so a construction of a concrete other than the selected one reports another identifier; edge that must survive the composition: every concrete the factory admits declares the interface version the family's consumers are written against.
- `every_concrete_is_refused_under_an_identifier_it_does_not_declare`: condition `create_hash_to_scalar` is called with the selection of a concrete and an identifier that concrete does not declare; outcome `Err(CreateHashToScalarErrorReturn::UnsupportedHashToScalarIdentifier)`; variation each case paired with the declared identifier of every other case whose declared identifier differs from its own, so an admission that compares against a constant or ignores the selection admits a pairing it must refuse; edge that must survive the composition: the refusal is decided by the selected concrete's own declaration.
- `every_concrete_returns_the_sampling_bound_refusal_whole`: condition the adapter `create_hash_to_scalar` returns for `HashToScalarConcrete::Mock(MockIHashToScalarAdapterFailureMode::SamplingRefused)` hashes a tag and a message; outcome `Err(HashToScalarErrorReturn::Sampling(SampleUniformScalarErrorReturn::WrongLength { expected: S::UNIFORM_BYTES_LENGTH, actual: 0 }))`; variation the mock selection under that failure mode over every member of `PAIRING_CONCRETES`, the case that reaches this arm, since no input takes it for a real concrete, whose sampler receives exactly its bound; edge that must survive the composition: the failure mode the configuration names is the failure mode of the concrete the factory constructs, and the sampling refusal arrives whole in the family's `Sampling` flavor.
- `every_concrete_declaring_the_keccak256_identifier_hashes_the_reference_inputs_to_the_oracle`: condition `create_hash_to_scalar` is called with the selection of a concrete that declares `HashToScalarIdentifier::Keccak256V1` and that identifier, and the adapter hashes the tag `REFERENCE_TAG` built by `DomainTag::try_new` over `REFERENCE_MESSAGE`; outcome the encoding of the returned scalar equals the encoding of the scalar the received scalar type samples from `expected_uniform_bytes(&tag, REFERENCE_MESSAGE, S::UNIFORM_BYTES_LENGTH)`; variation each case of the declared set that declares the identifier over every member of `PAIRING_CONCRETES`, each with its own scalar type; edge that must survive the composition: the concrete the factory constructs hashes, through the family's trait object and the crate root alone, to the scalar the independent oracle states.
- `every_concrete_declaring_the_keccak256_identifier_hashes_the_context_the_encoding_factory_encodes_to_the_oracle`: condition `create_hash_to_scalar` is called with the selection of a concrete that declares `HashToScalarIdentifier::Keccak256V1` and that identifier, and the adapter hashes `REFERENCE_TAG` over the bytes `create_encoding` returns for a value of the family's mock description; outcome the encoding of the returned scalar equals the encoding of the scalar the received scalar type samples from `expected_uniform_bytes(&tag, bytes, S::UNIFORM_BYTES_LENGTH)`, `bytes` the bytes the encoding returned; variation each case of the declared set that declares the identifier over each case of `DECLARED_ENCODING_SELECTIONS` that declares `EncodingIdentifier::EthereumAbiV1` and every member of `PAIRING_CONCRETES`, so a hash that frames the message by the reference message's shape, or reads other bytes than the encoding returned, yields a scalar the oracle does not state; edge that must survive the composition: the bytes the encoding family produces are hashed as returned.

## Integration: private surface

The chain of real functions `run_create_hash_to_scalar_case` and `create_pairing`, the arm's concrete through its `try_new`, `create_hash_to_scalar`, the selected concrete's `try_new`, `declaration` and `hash_to_scalar` as called on the returned adapter, `DomainTag::try_new` through `build_domain_tag`, the received scalar's `sample_from_uniform_bytes`, and the received adapter's `encode_scalar`, with `Secret::expose` and the `Secret` drop of `domain` running for real; the cases are the declared set and the mock selection over every member of `PAIRING_CONCRETES`; no outer-edge collaborator is mocked — `sha3`, `zeroize`, and `domain` run as themselves; the observable result is the `Result` `create_hash_to_scalar` returns, the declaration, the error `hash_to_scalar` returns, and the encoded scalar bytes read through `Secret::expose`; the entries proven are `every_concrete_is_constructed_under_the_identifier_it_declares`, `every_concrete_is_refused_under_an_identifier_it_does_not_declare`, `every_concrete_returns_the_sampling_bound_refusal_whole`, and the absorbed entries above.

## Integration: public surface

An outside caller invokes `run_create_hash_to_scalar_case` with `CreateHashToScalarCaseDeps` holding a case consumer it writes and a `CreateHashToScalarCaseParams` selecting the pairing concrete, whose case consumer invokes `create_hash_to_scalar` with `CreateHashToScalarDeps`, a `CreateHashToScalarParams` taken from `DECLARED_HASH_TO_SCALAR_SELECTIONS`, and a `CreateHashToScalarPayload`, for the scalar type the received pairing supplies, builds the tag with `DomainTag::try_new` and the message from a fixture or from `create_encoding` over the official consumer mock, calls `hash_to_scalar` on the returned adapter, and observes the scalar through the pairing adapter's `encode_scalar` and the tag through `DomainTag::as_bytes`; the entries proven are `every_concrete_declaring_the_keccak256_identifier_hashes_the_reference_inputs_to_the_oracle`, `every_concrete_declaring_the_keccak256_identifier_hashes_the_context_the_encoding_factory_encodes_to_the_oracle`, and the carried `domain_tag` entries dispositioned above.
