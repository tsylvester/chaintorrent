# `create_chain_forms` — interaction spec

Branch contract for the `create_chain_forms` module of the `chain` crate: the family's forms construction point — it selects the forms concrete `params.concrete` names, admits it only when its declared identifier is `params.identifier` and the encoder the caller lends declares the encoding identifier the concrete's declaration requires, constructs it over that encoder, and hands it to the consumer in `deps`, which is generic over `IChainForms` and never names the concrete. Each branch states condition, decision, dependency call, and the exact return outcome.

## `create_chain_forms<C: IChainFormsConsumer, E: IEncoderAdapter>(deps: &CreateChainFormsDeps<'_, C, E>, params: CreateChainFormsParams, payload: CreateChainFormsPayload) -> CreateChainFormsReturn<C::Output>`

Decision: a `match` on `params.concrete`, one arm per `ChainFormsConcrete` variant, exhaustive so a variant with no arm fails to compile.

| Branch | Condition | Decision | Dependency call | Outcome |
|---|---|---|---|---|
| unsupported identifier | the named concrete's `DECLARATION.identifier` is not `params.identifier` | equality, read before any construction | none | `Err(CreateChainFormsErrorReturn::UnsupportedChainFormsIdentifier)`; nothing is constructed and the consumer is not called |
| unsupported encoding identifier | the named concrete's `DECLARATION.identifier` is `params.identifier` and `E::DECLARATION.identifier` is not the named concrete's `DECLARATION.encoding_identifier` | equality, read before any construction and after the forms identifier check | none | `Err(CreateChainFormsErrorReturn::UnsupportedEncodingIdentifier)`; nothing is constructed and the consumer is not called |
| admitted | both identifiers are as the concrete requires | both checks pass | `EvmForms::try_new(EvmFormsConstructorParams { encoder: deps.encoder })`, exactly once, its success destructured irrefutably because its error arm is uninhabited; then `deps.consumer.consume_chain_forms(ConsumeChainFormsParams, ConsumeChainFormsPayload { forms })`, exactly once | `Ok(CreateChainFormsSuccessReturn { output })`, holding the consumer's output; the consumer receives the forms and not the encoder |

`Mock` arm, under `#[cfg(any(test, feature = "mocks"))]`: condition `params.concrete` is `Mock`; decision `MockIChainForms::DECLARATION.identifier` equals `params.identifier`, then `E::DECLARATION.identifier` equals `MockIChainForms::DECLARATION.encoding_identifier`, each read before any construction; dependency calls `build_mock_i_chain_forms(MockIChainFormsOverrides)`, which has no error arm and reads no encoder, then `deps.consumer.consume_chain_forms(ConsumeChainFormsParams, ConsumeChainFormsPayload { forms })`, exactly once; outcome `Ok(CreateChainFormsSuccessReturn { output })` holding the consumer's output; an unequal forms identifier is the unsupported-identifier outcome and an unequal encoding identifier the unsupported-encoding-identifier outcome.

`ChainFormsIdentifier` has the one variant the EVM forms concrete declares, so no input takes the unsupported-identifier branch until a further identifier exists; the branch has no unit test.

`CreateChainFormsErrorReturn::Evm` carries the EVM concrete's uninhabited constructor error type in the return union, so no branch produces it.

## Ordering and invariants

- Within an arm: the forms identifier check, then the encoding identifier check, then construction, then the consumer. `params.concrete` selects the concrete; `params.identifier` admits it.
- `payload` carries nothing and is not read. `deps.consumer` is invoked at most once per call, only on the admitted branch. `deps.encoder` is compared with the concrete's declaration and handed to the concrete's constructor and to no one else.
- The consumer receives the forms as `F: IChainForms` and reads `F::DECLARATION`; nothing in this module names a forms concrete other than in the selecting arm.

## The case runner — under `#[cfg(any(test, feature = "mocks"))]`

`create_chain_forms_case<K: ICreateChainFormsCaseConsumer>(deps: &CreateChainFormsCaseDeps<K>, params: CreateChainFormsCaseParams, payload: CreateChainFormsCasePayload) -> CreateChainFormsCaseReturn<K::Output>`: one branch; dependency call `create_encoding` with the case params' encoding selection and a private level that hands the case consumer the encoder it is handed; outcome `Ok(CreateChainFormsCaseSuccessReturn { output })` holding the case consumer's output, or `Err(CreateChainFormsCaseErrorReturn::Encoding(error))` carrying the encoding factory's refusal unchanged.

## Integration: private surface

The chain of real functions is `create_chain_forms_case`, `create_encoding` with the encoding concrete the case params select, `create_chain_forms`, the selected forms concrete's producer (`EvmForms::try_new` for `Evm`, `build_mock_i_chain_forms` for `Mock`), `consume_chain_forms`, and each form's `from_field`, `to_field`, and `try_new`, `derive_key_identifier`, and `signed_intent`; the outer-edge collaborators are the encoding family's concrete, the real ABI concrete or the mock concrete, which stands for no real concrete, and the `Mock` forms selection, which stands for no real concrete; the observable result is the declaration the consumer returns for the declaration entry, the refusal the call returns for the encoding-identifier entry, and the call's `Ok` return with the consumer's in-place assertions for each round-trip entry.

## Integration: public surface

An outside caller invokes `create_chain_forms_case` with its own `ICreateChainFormsCaseConsumer`, whose method calls `create_chain_forms` over the encoder it is lent with its own `IChainFormsConsumer`, a concrete from `CHAIN_FORMS_CONCRETES`, the identifier, and the encoding selection that concrete's declaration requires, taken from `DECLARED_ENCODING_SELECTIONS`; it observes the consumer's output in the return and, inside the consumer, the declaration and each form's results through `IChainForms`, `IIdentityForm`, and `ICanonicalField`; the entries proven are `chain_forms_handed_to_the_consumer_declare_the_required_identifier`, `chain_forms_identity_survives_its_field_round_trip`, `chain_forms_entitlement_survives_its_field_round_trip`, `chain_forms_interval_survives_its_field_round_trip`, `chain_forms_chain_identifier_survives_its_field_round_trip`, `chain_forms_key_identifier_survives_its_field_round_trip`, `chain_forms_signed_intent_survives_its_field_round_trip`, and `chain_forms_refuse_an_encoder_declaring_another_encoding_identifier`, each over `CHAIN_FORMS_CONCRETES`, along the route `create_chain_forms_case`, `create_encoding`, the real ABI concrete, `create_chain_forms`, the concrete's producer, `consume_chain_forms`, and each form's operations, with the encoding family's concrete as the outer-edge collaborator.
