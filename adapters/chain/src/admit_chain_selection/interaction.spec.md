# `admit_chain_selection` — interaction spec

Branch contract for the `admit_chain_selection` module of the `chain` crate: `admit_chain_selection` selects the chain member the configuration names, narrowing the selected member's untrusted settings document through that member's guard, reading that member's declaration through the declaration lookup its deps carry, and admitting the document against that declaration through the member's settings admission its deps carry — each refusal returning in a variant named by the member with the callee's error unchanged — producing the settings-carrying `ChainSelection`. Each branch states condition, decision, dependency call, and the exact return outcome.

## `admit_chain_selection`

`admit_chain_selection(deps: &AdmitChainSelectionDeps, params: AdmitChainSelectionParams, payload: serde_json::Value) -> AdmitChainSelectionReturn`, the validating form; `deps` supplies the declaration lookup and the Base member's settings admission as handles, each called only through its field; the decision is an exhaustive `match` on `params.identifier`, so a further member adds an arm.

| Branch | Condition | Decision | Dependency call | Outcome |
|---|---|---|---|---|
| Base, narrowing | `params.identifier` is `ChainMemberIdentifier::Base` | the guard `BaseChainSettingsDocument::try_from(payload)`, the first statement of the arm | `BaseChainSettingsDocument::try_from` | a refusal `Err(AdmitChainSelectionErrorReturn::BaseDocument(error))` with the error unchanged; else the document passes to the next row |
| Base, declaration read | the guard narrowed the payload | none | `(deps.lookup_chain_declaration)(&LookupChainDeclarationDeps, LookupChainDeclarationParams { identifier: params.identifier }, LookupChainDeclarationPayload)`, bound through the irrefutable pattern `let Ok(looked_up) = …;` because its error arm is `Infallible` | the member's declaration is `looked_up.declaration` |
| Base, admission | the declaration read | none | `(deps.admit_base_chain_settings)(&AdmitBaseChainSettingsDeps { declaration: &looked_up.declaration }, AdmitBaseChainSettingsParams, AdmitBaseChainSettingsPayload { document })` | a refusal `Err(AdmitChainSelectionErrorReturn::Base(error))` with the error unchanged; else `Ok(AdmitChainSelectionSuccessReturn { selection: ChainSelection::Base { settings: admitted.settings } })` |
| Mock — `#[cfg(any(test, feature = "mocks"))]` | `params.identifier` is `ChainMemberIdentifier::Mock` | none; `payload` is not read, the mock concrete holding no settings | none; neither handle is read | `Ok(AdmitChainSelectionSuccessReturn { selection: ChainSelection::Mock { failure_mode: MockIChainAdapterFailureMode::NoFailure } })` |

### Ordering

The guard, then the declaration read, then the admission; the first refusal returns and no later call is made; no side effect.

## Integration: own entries

- `a_value_the_document_supplies_replaces_its_declared_default_in_the_selected_settings`: condition `admit_chain_selection` is called over `ChainMemberIdentifier::Base` with a document supplying `endpoint`, `chain_identifier`, `entitlement_contract`, and `batch_page_limit`; outcome `Ok` whose selection holds those values; variation each supplied value differs from its declared default, so a selection that ignores the document, or that narrows it and then admits an empty one, fails; edge that must survive the composition: the supplied text reaches the settings through the guard's document and the admission, unchanged.
- `a_value_for_the_fixed_oracle_is_refused_by_the_admission_in_the_base_variant`: condition the call over `ChainMemberIdentifier::Base` with a document supplying `gas_price_oracle`; outcome `Err(AdmitChainSelectionErrorReturn::Base(AdmitBaseChainSettingsErrorReturn::FixedSetting { setting, supplied }))` naming the setting and the supplied text; variation a text the guard admits as a string and only the declaration's disposition refuses, so a refusal remapped into the document variant, or a fixed setting read from anywhere but the declaration, fails; edge that must survive the composition: the real admission, over the declaration the real lookup returns, refuses the fixed setting, and its error arrives whole.
- `an_endpoint_outside_its_declared_bounds_is_refused_by_the_admission_in_the_base_variant`: condition the call over `ChainMemberIdentifier::Base` with an `endpoint` beginning with none of the prefixes the declaration states; outcome `Err(AdmitChainSelectionErrorReturn::Base(AdmitBaseChainSettingsErrorReturn::OutOfBounds { setting, supplied }))`; variation a text the guard admits as a string and only the declaration's bounds refuse, so a bound read from anywhere but the declaration fails; edge that must survive the composition: the declaration the admission reads is the one the real lookup returns for the Base member.
- `the_guard_refuses_before_the_admission_reads_the_document`: condition the call over `ChainMemberIdentifier::Base` with a payload the guard refuses while the deps' admission handle refuses every document; outcome `Err(AdmitChainSelectionErrorReturn::BaseDocument(error))` with the guard's error; variation an admission handle that refuses, so an admission that runs first returns the `Base` variant and fails; edge: the order in which the guard and the admission run.
- `a_payload_that_is_not_a_table_is_refused_by_the_guard_in_the_document_variant`: condition the call over `ChainMemberIdentifier::Base` with a payload that is not an object; outcome `Err(AdmitChainSelectionErrorReturn::BaseDocument(BaseChainSettingsDocumentErrorReturn::NotATable { path }))` with the guard's error unchanged; variation a value of the wrong kind, so a payload narrowed by anything weaker than the guard fails; edge that must survive the composition: the guard's error arrives whole in the document variant.
- `an_unknown_key_is_refused_by_the_guard_in_the_document_variant`: condition the call over `ChainMemberIdentifier::Base` with an object holding a key outside the member's declared keys; outcome `Err(AdmitChainSelectionErrorReturn::BaseDocument(BaseChainSettingsDocumentErrorReturn::UnknownKey { path, key }))`; variation a key that differs from a declared key by one letter, so a prefix match fails; edge that must survive the composition: the path and key arrive unchanged.
- `a_value_that_is_not_text_is_refused_by_the_guard_in_the_document_variant`: condition the call over `ChainMemberIdentifier::Base` with a `batch_page_limit` that is a number; outcome `Err(AdmitChainSelectionErrorReturn::BaseDocument(BaseChainSettingsDocumentErrorReturn::NotText { path }))`; variation a present value of the wrong kind inside an otherwise valid table, so a guard that checks the table's shape alone fails; edge that must survive the composition: the refusal carries the path that held the value.
- `the_mock_member_is_selected_under_no_failure_whatever_the_payload`: condition `admit_chain_selection` is called over `ChainMemberIdentifier::Mock` with a payload the Base guard refuses; outcome `Ok` whose selection is `ChainSelection::Mock` under `MockIChainAdapterFailureMode::NoFailure`; variation a payload that is not a table, so a branch that narrows the payload through the Base guard first fails; edge that must survive the composition: the payload is not read for a member that holds no settings table.
- `an_admission_refusal_is_returned_whole_in_the_base_variant`: condition the call over `ChainMemberIdentifier::Base` with a payload the guard narrows while the deps' admission handle returns a refusal; outcome `Err(AdmitChainSelectionErrorReturn::Base(error))` holding that refusal unchanged; variation a refusal whose `setting` and `supplied` are stated as literals, so a refusal remapped, rebuilt, or carried in the document variant fails; edge: the admission's error arrives whole.
- `the_admitted_settings_are_carried_in_the_base_selection`: condition the call over `ChainMemberIdentifier::Base` with a payload the guard narrows while the deps' admission handle returns admitted settings; outcome `Ok` whose selection is `ChainSelection::Base` holding those settings; variation the Base variant against the Mock variant, so a selection built in another variant, or over settings other than the admission's, fails; edge: the settings the admission returned reach the selection unchanged.

## Integration: public surface
