# `create_chain` — interaction spec

Branch contract for the `factory` module of the `chain` crate: `create_chain` constructs the chain concrete the settings-carrying selection in its params names, calling the family's composition admission over the member identifier the selection names and the declaration of the forms it is generic over — before anything is constructed — and hands the constructed concrete to the consumer its deps hold, returning that consumer's output. Each branch states condition, decision, dependency call, and the exact return outcome.

## `create_chain<F: IChainForms, C: IChainConsumer>(deps: &CreateChainDeps<C>, params: CreateChainParams, payload: CreateChainPayload) -> CreateChainReturn<C::Output>`

The trusted form: `payload` is not read. The identifier is read from the selection by an exhaustive `match` on `&params.selection`, `Base { .. }` yielding `ChainMemberIdentifier::Base` and, under `#[cfg(any(test, feature = "mocks"))]`, `Mock { .. }` yielding `ChainMemberIdentifier::Mock`, so a variant with no arm fails to compile.

| Branch | Condition | Decision | Dependency call | Outcome |
|---|---|---|---|---|
| identifier read | every call | the exhaustive `match` above | none | the member identifier handed to the composition admission |
| incompatible composition | the identifier read | none of this function's | `(deps.admit_chain_composition)(&ADMIT_CHAIN_COMPOSITION_DEPS, AdmitChainCompositionParams { identifier }, AdmitChainCompositionPayload { forms: &F::DECLARATION })`, once, before any construction, the family's production deps holding the real `lookup_chain_declaration` | `Err` → `Err(CreateChainErrorReturn::Composition(error))` carrying the refusal unchanged, nothing constructed and the consumer not called; `Ok` → the function proceeds |
| base | the composition admits and the selection is `Base { settings }` | none | `BaseChain::<F>::try_new(BaseChainConstructorParams { settings: &settings })`, exactly once | a refusal → `Err(CreateChainErrorReturn::Base(error))` with the error unchanged and the consumer not called; success → `deps.consumer.consume_chain(ConsumeChainParams, ConsumeChainPayload { adapter })`, exactly once, and `Ok(CreateChainSuccessReturn { output })` holding the consumer's output |
| mock | the composition admits and the selection is `Mock { failure_mode }`, under `#[cfg(any(test, feature = "mocks"))]` | none | `build_mock_i_chain_adapter::<F>(MockIChainAdapterOverrides)` carrying the selection's failure mode, which has no error arm | `deps.consumer.consume_chain(ConsumeChainParams, ConsumeChainPayload { adapter })`, exactly once, and `Ok(CreateChainSuccessReturn { output })`, the adapter answering under the failure mode the selection names |

The incompatible arm's proof: the unit block `create_chain_returns_the_composition_refusal_whole_and_constructs_nothing` hands a handle that returns the refusal, since the handle is an input of the function; the real admission reaches no disagreement over the forms the family constructs, so the private integration test hands the real function and proves the admitted outcome.

### Ordering

The composition admission, then the construction, then the consumer; a refusal returns and no later call is made; no side effect before the admission. The factory reads no declaration itself and compares none: it passes `&ADMIT_CHAIN_COMPOSITION_DEPS` to the admission handle.

## Integration: own entries

- `every_declared_member_is_constructed_under_the_declaration_it_owns`: condition `create_chain` is called with the selection `build_chain_selection` returns for each member of `DECLARED_CHAIN_MEMBERS` and for the mock member, over forms declaring `ChainFormsIdentifier::EvmV1`, and the consumer returns the `K::DECLARATION` of the concrete it receives; outcome `Ok` whose output's `identifier` is the identifier of the member selected and whose `forms_identifier` is `ChainFormsIdentifier::EvmV1`; variation each member of the declared set and the mock member, whose identifiers differ, so a factory that constructs a concrete other than the one the selection names reports another identifier; edge that must survive the composition: the composition admission is reached for every member before its construction and the consumer receives the concrete the selection named.
- `a_value_the_selection_admission_returned_reaches_the_chain_the_factory_constructs`: condition `create_chain` is called with the selection `admit_chain_selection` returns over `ChainMemberIdentifier::Base` for a document supplying `endpoint` and `batch_page_limit`, and the consumer reads `endpoint` and `batch_page_limit` of the concrete it receives; outcome the endpoint text and the limit the document supplied; variation each supplied value differs from its declared default, so a factory that constructs over the declared defaults, or over settings it rebuilds, fails; edge that must survive the composition: the settings the admission returned reach the concrete unchanged.
- `the_failure_mode_a_mock_selection_names_is_the_failure_mode_of_the_chain_constructed`: condition `create_chain` is called with `ChainSelection::Mock` under each of `MockIChainAdapterFailureMode::NoFailure` and `MockIChainAdapterFailureMode::TransportRefused`, and the consumer calls `current_reference_at` for `SettlementTier::Soft` on the concrete it receives; outcome under `NoFailure` an `Ok` holding a reference whose ordinal is `30`, and under `TransportRefused` `Err(CurrentReferenceAtErrorReturn::Mock(MockIChainAdapterCurrentReferenceAtErrorReturn::TransportRefused))`; variation the two failure modes, so a factory that ignores the mode, or fixes one, fails; edge that must survive the composition: the failure mode the selection names is the failure mode of the concrete the factory constructs, and the concrete's own error arrives whole.

## Integration: private surface

The chain of real functions `create_chain_forms_case`, `create_encoding` with the mock encoding concrete, `create_chain_forms`, `create_chain`, `admit_chain_composition` over `ADMIT_CHAIN_COMPOSITION_DEPS`, `lookup_chain_declaration`, `BaseChain::try_new`, the mock concrete's producer, and the accessors the blocks call, and, in the second entry, `admit_chain_selection` over `ADMIT_CHAIN_SELECTION_DEPS`, the member's guard, the real declaration lookup, and the member's settings admission; no outer-edge collaborator is mocked, the Base concrete's providers being constructed and never called and the encoding concrete the family's mock; the observable results are the `CreateChainReturn`, the declaration, the endpoint text, the limit, and the reference or refusal the consumer returns. The entries proven are the own entries, the absorbed entries, and the carried entry that supplies values, each as stated above.

## Integration: public surface

The crate's `lib.rs` re-exports `factory::provides`, so `create_chain` is a public entry; an outside caller invokes `create_chain::<F, C>` inside the `consume_chain_forms` method of its own `IChainFormsConsumer`, reached through `create_chain_forms_case` over the `Evm` forms concrete and a member of `DECLARED_ENCODING_SELECTIONS` declaring `EncodingIdentifier::EthereumAbiV1`, with a selection from the public `admit_chain_selection` called with `&ADMIT_CHAIN_SELECTION_DEPS` or, under the `mocks` feature, from `build_chain_selection`.

It observes the `CreateChainReturn` and, through its consumer's `IChainAdapter` methods, the declaration, the endpoint text, the limit, and the reference or refusal. The entries proven are the own entries and both carried `chain/admit_chain_selection` entries, each over the route the entry states, with `create_chain_forms_case` supplying the forms. The route adds the public `admit_chain_selection` and the case runner to `create_chain`, with no outer-edge collaborator.
