# `create_random_source` — interaction spec

Branch contract for the `create_random_source` module of the `random` crate: the randomness family's factory — receives the selection `admit_random_selection` returns, constructs the source the selection names, hands it to the caller-supplied consumer held in its deps, and returns the consumer's output, the one surface every production draw passes through. Each branch states condition, decision, dependency call, and the exact return outcome.

## `create_random_source<C: IRandomSourceConsumer>(deps: &CreateRandomSourceDeps<C>, params: CreateRandomSourceParams, _payload: CreateRandomSourcePayload) -> CreateRandomSourceReturn<C::Output>`

Decision: an exhaustive `match` on `params.kind`, one arm per `RandomSourceKind` variant, so a further member adds an arm. Each arm constructs the source its selection names and calls `deps.consumer.consume_random_source` exactly once with `ConsumeRandomSourceParams` and a `ConsumeRandomSourcePayload` holding that source by value, returning `Ok(CreateRandomSourceSuccessReturn { output })` around the consumer's output, with no `Box::new` and no adapter field.

| Branch | Condition | Decision | Dependency call | Outcome |
|---|---|---|---|---|
| operating system | `params.kind` is `RandomSourceKind::OperatingSystem` | the discriminant | `OsRandomSource::try_new(OsRandomSourceConstructorParams)`, exactly once, then `deps.consumer.consume_random_source`, exactly once | `Ok(CreateRandomSourceSuccessReturn { output })` carrying the consumer's output |
| mock — `#[cfg(any(test, feature = "mocks"))]` | `params.kind` is `RandomSourceKind::Mock(mode)` | the discriminant | `MockIRandomSourceAdapter::try_new(MockIRandomSourceAdapterConstructorParams { failure_mode: mode })`, exactly once, then `deps.consumer.consume_random_source`, exactly once | `Ok(CreateRandomSourceSuccessReturn { output })` carrying the consumer's output; the source carries the failure mode `mode`, and its constructor error arm is uninhabited |

The operating-system constructor's error arm is uninhabited (`Result<_, Infallible>`), so its success is destructured irrefutably and that branch has no failure outcome; `CreateRandomSourceErrorReturn::OperatingSystem` carries its error type in the return union, so each concrete's constructor error has a variant.

## Ordering and invariants

- `params.kind` selects the concrete; `deps` supplies the consumer invoked exactly once on each arm; the factory payload carries nothing and is not read; the `match` is exhaustive over `RandomSourceKind`, so a kind with no branch fails to compile.
- The matched branch returns; no side effect — no clock, no environment variable, no network, no filesystem.
