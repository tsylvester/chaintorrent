# factory interactions

`create_key_derivation` is the key-derivation family's construction point: it constructs the member the admitted selection `params.selection` names and returns it behind `Box<dyn IKeyDerivationAdapter>`. It reads no hash-card and no configuration, admits no selection, and reads no declaration — the composition resolver passes the selection `kdf/admit_kdf_selection` returned as a typed `KdfConcrete`, and a declaration is read through `kdf/lookup_kdf_declaration` — and it does not derive; derivation is the concrete's.

## `create_key_derivation`

`create_key_derivation(deps: &CreateKeyDerivationDeps, params: CreateKeyDerivationParams, payload: CreateKeyDerivationPayload) -> CreateKeyDerivationReturn`

The decision is a `match` on `params.selection`, one arm per `KdfConcrete` variant, exhaustive so a variant with no arm fails to compile.

| Branch | Condition | Dependency call | Outcome |
|---|---|---|---|
| real member | `params.selection` is `KdfConcrete::Blake3Keyed` | the concrete's `try_new` with its fieldless constructor params, exactly once, its success destructured irrefutably because its error arm is uninhabited | `Ok(CreateKeyDerivationSuccessReturn { adapter: Box::new(kdf) })` |
| mock member, under `#[cfg(any(test, feature = "mocks"))]` | `params.selection` is `KdfConcrete::Mock(failure_mode)` | the mock concrete's `try_new` with `MockIKeyDerivationAdapterConstructorParams { failure_mode }`, the failure mode the selection carries, exactly once, its success destructured irrefutably because its error arm is uninhabited | `Ok(CreateKeyDerivationSuccessReturn { adapter: Box::new(mock) })`, whose adapter derives under the failure mode |

`CreateKeyDerivationErrorReturn::Blake3Keyed` and `CreateKeyDerivationErrorReturn::Mock` carry the constructors' uninhabited error type `Infallible` in the return union, so no branch produces them.

`params.selection` selects; `deps` and `payload` carry nothing and are not read.

## Integration: callee dispositions

The entries of `kdf/blake3_keyed` and `kdf/admit_kdf_selection` that this node's chains reach, each dispositioned as stated.

- `derive_key_leaves_the_borrowed_key_material_intact` (`kdf/blake3_keyed`): absorbed; proven by `every_concrete_leaves_the_borrowed_key_material_intact` in this module's private integration test `integration_test.rs`, which runs the entry through `create_key_derivation` over the declared set and the mock selection.
- `derive_key_returns_a_key_that_outlives_the_key_material` (`kdf/blake3_keyed`): absorbed; proven by `every_concrete_returns_a_key_that_outlives_the_key_material` in this module's private integration test `integration_test.rs`, which runs the entry through `create_key_derivation` over the declared set and the mock selection.
- `admit_kdf_selection_returns_the_selection_naming_each_declared_member_through_the_crate_surface` (`kdf/admit_kdf_selection`): carried; the route is `admit_kdf_selection`, then `create_key_derivation`, then the selected concrete's `try_new`, then `derive_key` on the returned adapter, ending at this node; the property that survives this node's boundary is that the concrete constructed for the `selection` that entry's call returns for a member of `KDF_CONCRETES` is the member it names, which the key of the public entry `every_declared_concrete_providing_the_blake3_keyed_identifier_derives_the_wrapping_key_over_the_reference_inputs` observes; the outer-edge collaborators are none.
- `admit_kdf_selection_carries_the_selected_mock_member_through_the_crate_surface` (`kdf/admit_kdf_selection`): absorbed; proven by `every_concrete_returns_its_own_error_when_the_key_material_length_cannot_be_framed` in this module's private integration test `integration_test.rs`, whose mock selection is the `selection` that entry's call returns for the failure mode `KeyMaterialLengthUnrepresentable`.

## Integration: own entries

- `every_concrete_derives_a_key_of_the_requested_length`: condition the adapter `create_key_derivation` returns for a selection `admit_kdf_selection` returned derives with a `params.length`; outcome `Ok(DeriveKeySuccessReturn { key })` with the key's byte length equal to `params.length`; variation each member of `KDF_CONCRETES` and the mock selection over `REFERENCE_LENGTH`, `REFERENCE_PREFIX_LENGTH`, and zero, so a concrete that returns the reference length whatever is requested, or a non-empty key for zero, fails; edge that must survive the composition: a `params.length` of zero returns an empty key and no refusal.
- `every_concrete_returns_its_own_error_when_the_key_material_length_cannot_be_framed`: condition the adapter `create_key_derivation` returns for the mock selection `admit_kdf_selection` returned under the failure mode `KeyMaterialLengthUnrepresentable` derives; outcome `Err(DeriveKeyErrorReturn::Mock(MockIKeyDerivationAdapterDeriveKeyErrorReturn::KeyMaterialLengthUnrepresentable { length }))` with `length` the key material's length; variation the mock selection under that failure mode, the case that reaches this arm, since a `usize` fits the 8-byte prefix on every supported target and no input takes it for a real concrete; edge that must survive the composition: the failure mode the selection carries through admission is the failure mode of the concrete the factory constructs, and the concrete's own error variant arrives whole in the family's error union.
- `every_declared_concrete_providing_the_blake3_keyed_identifier_derives_the_wrapping_key_over_the_reference_inputs`: condition `create_key_derivation` is called with the selection `admit_kdf_selection` returned for a member of `KDF_CONCRETES` whose declaration `lookup_kdf_declaration` returns carries `KdfIdentifier::Blake3KeyedV1`, and the adapter derives with `DerivationPurpose::WrappingKey` and `REFERENCE_LENGTH` over the reference key material and the reference context; outcome the key equals `expected_derived_key` over the wrapping-key purpose, the reference context, and `REFERENCE_LENGTH`; variation each member of `KDF_CONCRETES` whose declared identifier is that identifier; edge that must survive the composition: the concrete the factory constructs derives, through the family's trait object, the key the independent oracle states.
- `every_declared_concrete_providing_the_blake3_keyed_identifier_derives_the_wrapping_key_over_the_context_the_encoding_factory_encodes`: condition `create_key_derivation` is called with the selection `admit_kdf_selection` returned for a member of `KDF_CONCRETES` whose declaration `lookup_kdf_declaration` returns carries `KdfIdentifier::Blake3KeyedV1`, and the adapter derives with `DerivationPurpose::WrappingKey` and `REFERENCE_LENGTH` over the reference key material and the bytes `create_encoding` returns for a value of the family's mock description; outcome the key equals `expected_derived_key` over the wrapping-key purpose, those bytes, and `REFERENCE_LENGTH`; variation each such member over each case of `DECLARED_ENCODING_SELECTIONS`, whose encoded bytes differ in length and content from the reference context, so a derivation that frames the context by the reference context's shape fails; edge that must survive the composition: the bytes the encoding family produces are consumed by the derivation as returned.

Unit blocks select the family's mock concrete alone, through `build_create_key_derivation_params` at its defaults or with the failure mode override; the real member arm is reached by the private integration blocks over `KDF_CONCRETES` and by the public blocks.

## Integration: private surface

The chain of real functions is `admit_kdf_selection`, `create_key_derivation`, the selected concrete's `try_new`, and `derive_key` as called on the returned adapter, with `Secret::expose` and the `Secret` drop of `domain` running for real; the cases are the members of `KDF_CONCRETES` and the mock selection; no outer-edge collaborator is mocked — `blake3`, `zeroize`, and `domain` run as themselves; the observable result is the `Result` `create_key_derivation` returns, the key's bytes, and the key material's bytes before and after the call; the entries proven are `every_concrete_derives_a_key_of_the_requested_length`, `every_concrete_returns_its_own_error_when_the_key_material_length_cannot_be_framed`, and the absorbed entries `derive_key_leaves_the_borrowed_key_material_intact`, `derive_key_returns_a_key_that_outlives_the_key_material`, and `admit_kdf_selection_carries_the_selected_mock_member_through_the_crate_surface`.

## Integration: public surface

An outside caller invokes `admit_kdf_selection` and `lookup_kdf_declaration` over each member of `KDF_CONCRETES`, invokes `create_key_derivation` with `CreateKeyDerivationDeps`, a `CreateKeyDerivationParams` holding the selection `admit_kdf_selection` returned, and a `CreateKeyDerivationPayload`, calls `derive_key` on the returned adapter with `DeriveKeyParams` and `DeriveKeyPayload`, and obtains the context bytes from `create_encoding` over the official consumer mock carrying the official description mock, and observes the key's bytes, the key's length, the error the mock selection returns, and the key material's bytes before and after the call and after its drop; the entries proven are `every_concrete_derives_a_key_of_the_requested_length`, `every_concrete_returns_its_own_error_when_the_key_material_length_cannot_be_framed`, `every_concrete_leaves_the_borrowed_key_material_intact`, `every_concrete_returns_a_key_that_outlives_the_key_material`, `every_declared_concrete_providing_the_blake3_keyed_identifier_derives_the_wrapping_key_over_the_reference_inputs`, and `every_declared_concrete_providing_the_blake3_keyed_identifier_derives_the_wrapping_key_over_the_context_the_encoding_factory_encodes`.
