# factory interactions

`create_key_derivation` is the key-derivation family's construction point: it constructs the member the admitted selection `params.selection` names and hands the concrete and its declaration to a caller-supplied `IKeyDerivationConsumer`, returning the consumer's output. It reads no hash-card and no configuration and admits no selection — the composition resolver passes the selection `kdf/admit_kdf_selection` returned as a typed `KdfConcrete` — it reads the selected member's `KdfDeclaration` through the `LookupKdfDeclarationFn` its deps carry, before construction, and hands it to the consumer in the payload, and it does not derive; derivation is the concrete's.

## `create_key_derivation`

`create_key_derivation<C: IKeyDerivationConsumer>(deps: &CreateKeyDerivationDeps<C>, params: CreateKeyDerivationParams, payload: CreateKeyDerivationPayload) -> CreateKeyDerivationReturn<C::Output>`

The function first calls `(deps.lookup)` for `params.selection` before any construction, binding `declaration`, its `Ok` destructured irrefutably because the lookup's error arm is uninhabited. The decision is a `match` on `params.selection`, one arm per `KdfConcrete` variant, exhaustive so a variant with no arm fails to compile.

| Branch | Condition | Dependency call | Outcome |
|---|---|---|---|
| real member | `params.selection` is `KdfConcrete::Blake3Keyed` | `deps.lookup` for `params.selection`, exactly once, then the concrete's `try_new` with its fieldless constructor params, exactly once, its success destructured irrefutably because its error arm is uninhabited, then `deps.consumer.consume_key_derivation(ConsumeKeyDerivationParams, ConsumeKeyDerivationPayload { adapter, declaration })`, exactly once | `Ok(CreateKeyDerivationSuccessReturn { output })` carrying the consumer's output |
| mock member, under `#[cfg(any(test, feature = "mocks"))]` | `params.selection` is `KdfConcrete::Mock(failure_mode)` | `deps.lookup` for `params.selection`, exactly once, then the mock concrete's `try_new` with `MockIKeyDerivationAdapterConstructorParams { failure_mode }`, the failure mode the selection carries, exactly once, its success destructured irrefutably because its error arm is uninhabited, then `deps.consumer.consume_key_derivation(ConsumeKeyDerivationParams, ConsumeKeyDerivationPayload { adapter, declaration })`, exactly once | `Ok(CreateKeyDerivationSuccessReturn { output })` carrying the consumer's output, the adapter the consumer receives deriving under the failure mode |

`CreateKeyDerivationErrorReturn::Blake3Keyed` and `CreateKeyDerivationErrorReturn::Mock` carry the constructors' uninhabited error type `Infallible` in the return union, so no branch produces them.

`params.selection` selects; `deps` carry the consumer and the lookup handle the declaration is read through; `payload` carries nothing and is not read.

- `derive_key_returns_a_key_that_outlives_the_key_material` (`kdf/blake3_keyed`): absorbed; proven by `every_concrete_returns_a_key_that_outlives_the_key_material` in this module's private integration test `integration_test.rs`, which runs the entry through `create_key_derivation` over the declared set and the mock selection.

## Integration: own entries

- `every_concrete_derives_a_key_of_the_requested_length`: condition `create_key_derivation` is called with a selection `admit_kdf_selection` returned, deps holding the real `lookup_kdf_declaration`, and a consumer whose `consume_key_derivation` calls `derive_key` on the adapter it receives with a `params.length` and returns the `DeriveKeyReturn` it observes; outcome `Ok(CreateKeyDerivationSuccessReturn { output })` whose `output` observes `Ok(DeriveKeySuccessReturn { key })` with the key's byte length equal to `params.length`; variation each member of `KDF_CONCRETES` and the mock selection over `REFERENCE_LENGTH`, `REFERENCE_PREFIX_LENGTH`, and zero, so a concrete that returns the reference length whatever is requested, or a non-empty key for zero, fails; edge that must survive the composition: a `params.length` of zero returns an empty key and no refusal.
- `every_concrete_returns_its_own_error_when_the_key_material_length_cannot_be_framed`: condition `create_key_derivation` is called with the mock selection `admit_kdf_selection` returned under the failure mode `KeyMaterialLengthUnrepresentable` and a consumer whose `consume_key_derivation` calls `derive_key` on the adapter it receives and returns the `DeriveKeyReturn` it observes; outcome `Ok(CreateKeyDerivationSuccessReturn { output })` whose `output` observes `Err(DeriveKeyErrorReturn::Mock(MockIKeyDerivationAdapterDeriveKeyErrorReturn::KeyMaterialLengthUnrepresentable { length }))` with `length` the key material's length; variation the mock selection under that failure mode, the case that reaches this arm, since a `usize` fits the 8-byte prefix on every supported target and no input takes it for a real concrete; edge that must survive the composition: the failure mode the selection carries through admission is the failure mode of the concrete the factory constructs, and the concrete's own error variant arrives whole in the family's error union.
- `every_declared_concrete_providing_the_blake3_keyed_identifier_derives_the_wrapping_key_over_the_reference_inputs`: condition `create_key_derivation` is called with the selection `admit_kdf_selection` returned for a member of `KDF_CONCRETES` whose declaration `lookup_kdf_declaration` returns carries `KdfIdentifier::Blake3KeyedV1`, and a consumer whose `consume_key_derivation` calls `derive_key` on the adapter it receives with `DerivationPurpose::WrappingKey` and `REFERENCE_LENGTH` over the reference key material and the reference context and returns the `DeriveKeyReturn` it observes; outcome `Ok(CreateKeyDerivationSuccessReturn { output })` whose `output` observes a key equal to `expected_derived_key` over the wrapping-key purpose, the reference context, and `REFERENCE_LENGTH`; variation each member of `KDF_CONCRETES` whose declared identifier is that identifier; edge that must survive the composition: the concrete the factory hands the consumer derives, through the family's trait, the key the independent oracle states.
- `every_declared_concrete_providing_the_blake3_keyed_identifier_derives_the_wrapping_key_over_the_context_the_encoding_factory_encodes`: condition `create_key_derivation` is called with the selection `admit_kdf_selection` returned for a member of `KDF_CONCRETES` whose declaration `lookup_kdf_declaration` returns carries `KdfIdentifier::Blake3KeyedV1`, and a consumer whose `consume_key_derivation` calls `derive_key` on the adapter it receives with `DerivationPurpose::WrappingKey` and `REFERENCE_LENGTH` over the reference key material and the bytes `create_encoding` returns for a value of the family's mock description and returns the `DeriveKeyReturn` it observes; outcome `Ok(CreateKeyDerivationSuccessReturn { output })` whose `output` observes a key equal to `expected_derived_key` over the wrapping-key purpose, those bytes, and `REFERENCE_LENGTH`; variation each such member over each case of `DECLARED_ENCODING_SELECTIONS`, whose encoded bytes differ in length and content from the reference context, so a derivation that frames the context by the reference context's shape fails; edge that must survive the composition: the bytes the encoding family produces are consumed by the derivation as returned.

Unit blocks select the family's mock concrete alone, through `build_create_key_derivation_params` at its defaults or with the failure mode override; the real member arm is reached by the private integration blocks over `KDF_CONCRETES` and by the public blocks.

## Integration: private surface

The chain of real functions is `admit_kdf_selection`, `create_key_derivation`, `deps.lookup`, the selected concrete's `try_new`, and `IKeyDerivationConsumer::consume_key_derivation` calling `derive_key` on the adapter it receives, with `Secret::expose` and the `Secret` drop of `domain` running for real; the cases are the members of `KDF_CONCRETES` and the mock selection; no outer-edge collaborator is mocked — `blake3`, `zeroize`, and `domain` run as themselves; the observable result is the `Result` `create_key_derivation` returns carrying the consumer's `output`, the key's bytes the consumer observes, and the key material's bytes before and after the call; the entries proven are `every_concrete_derives_a_key_of_the_requested_length`, `every_concrete_returns_its_own_error_when_the_key_material_length_cannot_be_framed`, and the absorbed entries `derive_key_leaves_the_borrowed_key_material_intact`, `derive_key_returns_a_key_that_outlives_the_key_material`, and `admit_kdf_selection_carries_the_selected_mock_member_through_the_crate_surface`.

## Integration: public surface

An outside caller invokes `admit_kdf_selection` over each member of `KDF_CONCRETES` with a directly written `serde_json::Value` document, invokes `create_key_derivation` with a `CreateKeyDerivationDeps` holding a caller-supplied `IKeyDerivationConsumer` and the crate root's `lookup_kdf_declaration`, a `CreateKeyDerivationParams` holding the selection `admit_kdf_selection` returned, and a `CreateKeyDerivationPayload`, whose `consume_key_derivation` calls `derive_key` on the adapter it receives and the declaration the real lookup returned for `params.selection`, and obtains the context bytes from `create_encoding` over the official consumer mock carrying the official description mock, and observes through the consumer's `output` the key's bytes, the key's length, the error the mock selection returns, and the key material's bytes before and after the call and after its drop; the entries proven are `every_concrete_derives_a_key_of_the_requested_length`, `every_concrete_returns_its_own_error_when_the_key_material_length_cannot_be_framed`, `every_concrete_leaves_the_borrowed_key_material_intact`, `every_concrete_returns_a_key_that_outlives_the_key_material`, `every_declared_concrete_providing_the_blake3_keyed_identifier_derives_the_wrapping_key_over_the_reference_inputs`, and `every_declared_concrete_providing_the_blake3_keyed_identifier_derives_the_wrapping_key_over_the_context_the_encoding_factory_encodes`.
