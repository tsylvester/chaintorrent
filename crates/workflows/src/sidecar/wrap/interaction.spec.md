# wrap interactions

`wrap_piece_group_key` wraps a piece-group key under a parameter set's wrapping key: it encodes the derivation context through the injected encoder, derives the wrapping key through the injected key-derivation adapter under the `WrappingKey` purpose from the encapsulated value's key material over the encoded context, and returns the byte-wise XOR of the piece-group key and the wrapping key. It carries no tag — the sidecar's Bao root authenticates every entry — and it produces no variable-length wrapped value.

## `wrap_piece_group_key`

`wrap_piece_group_key<E: IEncoderAdapter>(deps: &WrapPieceGroupKeyDeps<'_, E>, params: WrapPieceGroupKeyParams, payload: WrapPieceGroupKeyPayload<'_>) -> WrapPieceGroupKeyReturn`

First, `DerivationContextDescription::try_new(DerivationContextDescriptionConstructorParams)` is unpacked irrefutably — its error arm is `Infallible` — then `deps.encoder.encode(EncodeParams { description: &description }, payload.context)` is called exactly once. Then the branches, in order:

| Branch | Condition | Decision | Dependency call | Outcome |
|---|---|---|---|---|
| encoding refused | the `encode` call returns `Err(error)` | none — the refusal is the branch | `encode` once; the KDF is never called | `Err(WrapPieceGroupKeyErrorReturn::Encoding(error))`, the refusal unchanged |
| key derivation refused | `deps.kdf.derive_key(DeriveKeyParams { purpose: DerivationPurpose::WrappingKey, length: PIECE_GROUP_KEY_LENGTH }, DeriveKeyPayload { key_material: payload.encapsulated.key_material(), context: &encoded })`, called once, returns `Err(error)` | none — the refusal is the branch | `derive_key` once | `Err(WrapPieceGroupKeyErrorReturn::KeyDerivation(error))`, the refusal unchanged |
| wrapping key of another length | the derivation succeeds and the derived key's exposed length is not the piece-group key's length | the length comparison, made before any byte is combined | none further | `Err(WrapPieceGroupKeyErrorReturn::WrappingKeyLength { expected, actual })`, `expected` the piece-group key's length and `actual` the derived key's |
| wrapped key refused | the derived length is `PIECE_GROUP_KEY_LENGTH` and `WrappedPieceGroupKey::try_new(WrappedPieceGroupKeyConstructorParams { bytes })`, called once with the byte-wise XOR of the admitted piece-group key and the wrapping key, returns `Err(error)` | none — the refusal is the branch | `WrappedPieceGroupKey::try_new` once | `Err(WrapPieceGroupKeyErrorReturn::WrappedKey(error))`, the refusal unchanged |
| wrapped | the derived length is `PIECE_GROUP_KEY_LENGTH` and `WrappedPieceGroupKey::try_new` returns `Ok(wrapped)` | the comparison above | `WrappedPieceGroupKey::try_new` once | `Ok(WrapPieceGroupKeySuccessReturn { wrapped })`, `wrapped` holding the byte-wise XOR of the admitted piece-group key with the wrapping key |

Ordering and lifecycle: encoding precedes derivation, the length check precedes the XOR, and the XOR precedes the admission of the wrapped bytes. The derived wrapping key is held in its returned `Secret`, which drops — and so zeroizes — when the function returns on every branch. The piece-group key, the encapsulated value, and the context are borrowed and unchanged; `params` carries no control and is not read; the same payload always yields the same outcome.

## Integration: own entries

Each entry is named and proven by the public integration block of the same name in `tests/wrap_integration_test.rs`.

- `wrapping_a_zero_piece_group_key_yields_the_wrapping_key_the_oracle_states`: condition `wrap_piece_group_key` is called with the encoder `create_encoding` hands the consumer for a case of `DECLARED_ENCODING_SELECTIONS`, the adapter `create_key_derivation` returns for a case of `DECLARED_KDF_SELECTIONS`, an encapsulated value whose key material is the bytes of `reference_key_material_bytes`, a derivation context, and a piece-group key of 32 zero bytes; outcome `Ok(WrapPieceGroupKeySuccessReturn { wrapped })` with `wrapped.as_bytes()` equal to the bytes `expected_derived_key` returns for `DerivationPurpose::WrappingKey`, the bytes `create_encoding` returns for that context, and the length `32`; variation each case of the declared encoding set and of the declared KDF set, over the reference derivation context and a context whose every component differs from the reference's, so a derivation that binds a fixed or partial context, or another purpose, length, or key material, fails; edge that must survive the composition: the derivation consumes the bytes the encoding family produces as returned, and a zero key wraps to the wrapping key itself.
- `wrapping_an_all_ones_piece_group_key_yields_the_complement_of_the_wrapping_key_the_oracle_states`: condition as the entry above with a piece-group key of 32 bytes each `0xFF`; outcome `Ok(WrapPieceGroupKeySuccessReturn { wrapped })` with `wrapped.as_bytes()` equal to the bitwise complement, byte by byte, of the bytes `expected_derived_key` returns for the same purpose, bytes, and length; variation as the entry above; edge that must survive the composition: the wrap combines the piece-group key with the wrapping key byte by byte, so a wrap that copies the wrapping key whatever the key fails.
- `a_key_derivation_refusal_reaches_the_caller_whole`: condition `wrap_piece_group_key` is called with the encoder `create_encoding` hands the consumer for a case of `DECLARED_ENCODING_SELECTIONS`, the adapter `create_key_derivation` returns for `KdfConcrete::Mock(MockIKeyDerivationAdapterFailureMode::KeyMaterialLengthUnrepresentable)`, and an encapsulated value whose key material is 48 bytes long; outcome `Err(WrapPieceGroupKeyErrorReturn::KeyDerivation(DeriveKeyErrorReturn::Mock(MockIKeyDerivationAdapterDeriveKeyErrorReturn::KeyMaterialLengthUnrepresentable { length: 48 })))`; variation each case of the declared encoding set, with key material whose length differs from the piece-group key's and from the encoded context's, so a derivation fed other material reports another length; edge that must survive the composition: the refusal arrives whole after the real encoder has run.
