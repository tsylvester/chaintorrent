# unwrap interactions

`unwrap_piece_group_key` recovers a piece-group key from a parameter set's sidecar entry: it encodes the derivation context through the injected encoder, derives the wrapping key through the injected key-derivation adapter under the `WrappingKey` purpose from the encapsulated value's key material over the encoded context, and returns the byte-wise XOR of the wrapped key and the wrapping key. It is the wrap's inverse under the same derivation.

## `unwrap_piece_group_key`

`unwrap_piece_group_key<E: IEncoderAdapter>(deps: &UnwrapPieceGroupKeyDeps<'_, E>, params: UnwrapPieceGroupKeyParams, payload: UnwrapPieceGroupKeyPayload<'_>) -> UnwrapPieceGroupKeyReturn`

First, `DerivationContextDescription::try_new(DerivationContextDescriptionConstructorParams)` is unpacked irrefutably — its error arm is `Infallible` — then `deps.encoder.encode(EncodeParams { description: &description }, payload.context)` is called exactly once. Then the branches, in order:

| Branch | Condition | Decision | Dependency call | Outcome |
|---|---|---|---|---|
| encoding refused | the `encode` call returns `Err(error)` | none — the refusal is the branch | `encode` once; the KDF is never called | `Err(UnwrapPieceGroupKeyErrorReturn::Encoding(error))`, the refusal unchanged |
| key derivation refused | `deps.kdf.derive_key(DeriveKeyParams { purpose: DerivationPurpose::WrappingKey, length: PIECE_GROUP_KEY_LENGTH }, DeriveKeyPayload { key_material: payload.encapsulated.key_material(), context: &encoded })`, called once, returns `Err(error)` | none — the refusal is the branch | `derive_key` once | `Err(UnwrapPieceGroupKeyErrorReturn::KeyDerivation(error))`, the refusal unchanged |
| wrapping key of another length | the derivation succeeds and the derived key's exposed length is not `PIECE_GROUP_KEY_LENGTH` | the length comparison, made before any byte is combined | none further | `Err(UnwrapPieceGroupKeyErrorReturn::WrappingKeyLength { expected, actual })`, `expected` is `PIECE_GROUP_KEY_LENGTH` and `actual` the derived key's |
| piece-group key refused | the derived length is `PIECE_GROUP_KEY_LENGTH` and `PieceGroupKey::try_new(PieceGroupKeyConstructorParams { secret })`, called once with a `Secret<Vec<u8>>` of the byte-wise XOR of `payload.wrapped.as_bytes()` and the wrapping key, returns `Err(error)` | none — the refusal is the branch | `PieceGroupKey::try_new` once | `Err(UnwrapPieceGroupKeyErrorReturn::PieceGroupKey(error))`, the refusal unchanged |
| unwrapped | the derived length is `PIECE_GROUP_KEY_LENGTH` and `PieceGroupKey::try_new` returns `Ok(piece_group_key)` | the comparison above | `PieceGroupKey::try_new` once | `Ok(UnwrapPieceGroupKeySuccessReturn { piece_group_key })`, `piece_group_key` holding the byte-wise XOR of `payload.wrapped.as_bytes()` with the wrapping key |

Ordering and lifecycle: encoding precedes derivation, the length check precedes the XOR, the XOR precedes the admission of the recovered key, and the buffer is moved into its `Secret<Vec<u8>>` as soon as it is filled. The derived wrapping key is held in its returned `Secret`, which drops — and so zeroizes — when the function returns on every branch. The encapsulated value, the context, and the wrapped key are borrowed and unchanged; `params` carries no control and is not read; the same payload always yields the same outcome.

Invariant: for any encapsulated value, context, and key, unwrapping the wrap's output returns the key.

## Integration: own entries

Each entry is named and proven by the public integration block of the same name in `tests/unwrap_integration_test.rs`.

- `unwrapping_a_wrapped_key_equal_to_the_wrapping_key_the_oracle_states_yields_a_zero_piece_group_key`: condition `unwrap_piece_group_key` is called with the encoder `create_encoding` hands the consumer for a case of `DECLARED_ENCODING_SELECTIONS`, the adapter `create_key_derivation` returns for a case of `DECLARED_KDF_SELECTIONS` that declares `KdfIdentifier::Blake3KeyedV1`, an encapsulated value whose key material is the bytes of `reference_key_material_bytes`, a derivation context, and a wrapped key of the 32 bytes `expected_derived_key` returns for `DerivationPurpose::WrappingKey`, the bytes `create_encoding` returns for that context, and the length `32`; outcome `Ok(UnwrapPieceGroupKeySuccessReturn { piece_group_key })` with `piece_group_key.expose()` equal to 32 zero bytes; variation each case of the declared encoding set and each case of the declared KDF set that declares `KdfIdentifier::Blake3KeyedV1`, over the reference derivation context and a context whose every component differs from the reference's, so a derivation that binds a fixed or partial context, or another purpose, length, or key material, fails; edge that must survive the composition: the derivation consumes the bytes the encoding family produces as returned, and a wrapped key equal to the wrapping key unwraps to zero.
- `unwrapping_an_all_ones_wrapped_key_yields_the_complement_of_the_wrapping_key_the_oracle_states`: condition as the entry above with a wrapped key of 32 bytes each `0xFF`; outcome `Ok(UnwrapPieceGroupKeySuccessReturn { piece_group_key })` with `piece_group_key.expose()` equal to the bitwise complement, byte by byte, of the bytes `expected_derived_key` returns for the same purpose, bytes, and length; variation as the entry above; edge that must survive the composition: the unwrap combines the wrapped key with the wrapping key byte by byte, so an unwrap that returns the wrapping key whatever the wrapped key fails.
- `unwrapping_returns_a_key_derivation_refusal_whole`: condition `unwrap_piece_group_key` is called with the encoder `create_encoding` hands the consumer for a case of `DECLARED_ENCODING_SELECTIONS`, the adapter `create_key_derivation` returns for `KdfConcrete::Mock(MockIKeyDerivationAdapterFailureMode::KeyMaterialLengthUnrepresentable)`, and an encapsulated value whose key material is 48 bytes long; outcome `Err(UnwrapPieceGroupKeyErrorReturn::KeyDerivation(DeriveKeyErrorReturn::Mock(MockIKeyDerivationAdapterDeriveKeyErrorReturn::KeyMaterialLengthUnrepresentable { length: 48 })))`; variation each case of the declared encoding set, with key material whose length differs from the wrapped key's and from the encoded context's, so a derivation fed other material reports another length; edge that must survive the composition: the refusal arrives whole after the real encoder has run.
