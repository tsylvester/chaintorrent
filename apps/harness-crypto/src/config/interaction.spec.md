# `configure` — interaction spec

Branch contract for the `config` module of `apps/harness-crypto`: `configure`, the function the harness's typed configuration is composed by — the shipped defaults' text and the command line handed to `layers`, the document it proves admitted table by table through the functions this module owns, the benchmark's iteration count admitted as a nonzero count, and the admitted values composed into the `HarnessConfiguration` every factory call and every write in the harness takes, the first refusal returned unchanged. Each branch states condition, decision, dependency call, and the exact return outcome.

## `configure`

`configure(deps: &ConfigureDeps, params: ConfigureParams, payload: ConfigurePayload<'_>) -> ConfigureReturn`, the trusted form: the command line and the texts arrive as payload and `layers`, the validating function, proves them; `deps` holds the collaborator functions each step below calls; `params` carries nothing and is not read. `document` below is the layers success's `document`; each admitted value below is the field of its step's success — `selections` the selections success's, `network` and `statements` the statements success's, `concrete` and `kinds` the generate success's, and `destinations` the output success's.

| Branch | Condition | Decision | Dependency call | Outcome |
|---|---|---|---|---|
| layers refused | `(deps.layers)` returns `Err(error)` | the `Err` arm | `(deps.layers)(&LayersDeps, LayersParams, LayersPayload { defaults: payload.defaults, arguments: payload.arguments })` | `Err(ConfigureErrorReturn::Layers(error))`, the refusal unchanged |
| selections refused | `(deps.admit_selections)` returns `Err(error)` | the `Err` arm | `(deps.admit_selections)(&AdmitSelectionsDeps, AdmitSelectionsParams, AdmitSelectionsPayload { random: &document.random, encoding: &document.encoding, hash_to_scalar: &document.hash_to_scalar, chain_forms: &document.chain_forms, kem: &document.kem, key_agreement: &document.key_agreement, delivery_proof: &document.delivery_proof, curves: &document.curves, benchmark_concretes: &document.benchmark.concretes, precompile_encodings: &document.network.precompile_encodings })` | `Err(ConfigureErrorReturn::Selections(error))`, the refusal unchanged |
| statements refused | `(deps.admit_statements)` returns `Err(error)` | the `Err` arm | `(deps.admit_statements)(&AdmitStatementsDeps, AdmitStatementsParams, AdmitStatementsPayload { network: &document.network, statements: &document.statements })` | `Err(ConfigureErrorReturn::Statements(error))`, the refusal unchanged |
| generate refused | `(deps.admit_generate)` returns `Err(error)` | the `Err` arm | `(deps.admit_generate)(&AdmitGenerateDeps, AdmitGenerateParams, AdmitGeneratePayload { generate: &document.generate })` | `Err(ConfigureErrorReturn::Generate(error))`, the refusal unchanged |
| output refused | `(deps.admit_output)` returns `Err(error)` | the `Err` arm | `(deps.admit_output)(&AdmitOutputDeps, AdmitOutputParams, AdmitOutputPayload { output: &document.output })` | `Err(ConfigureErrorReturn::Output(error))`, the refusal unchanged |
| zero iterations | `NonZeroU32::new(document.benchmark.iterations)` returns `None` | the `None` arm | `NonZeroU32::new` | `Err(ConfigureErrorReturn::ZeroBenchmarkIterations)` |
| computed | every step admitted | none | the calls stated | `Ok(ConfigureSuccessReturn { configuration: HarnessConfiguration { selections, network, statements, generate: concrete, generate_kinds: kinds, benchmark_iterations, output: destinations } })`, each the admitted value of its step, `concrete` and `kinds` the generate step's |

### Ordering

Layers, selections, statements, generate, output, then the benchmark's iteration count; the first refusal returns and nothing downstream of it is constructed; no side effect beyond the reads `layers` makes.
