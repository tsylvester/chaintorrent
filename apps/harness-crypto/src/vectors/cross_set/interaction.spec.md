# `cross_set` — interaction spec

Branch contract for the `cross_set` module of the `vectors` module of `apps/harness-crypto`: `cross_set` produces the cross-set agreement vector records, generic over the credential KEM and the encoder its caller hands it — per record a piece-group key drawn once, two parameter sets set up independently under the admitted identity's setup scope, and for each set the admitted identity's element, an issued credential, a capsule with the value it encapsulates, the drawn key wrapped under that value over the configured derivation context, the value the credential decapsulates, and the key unwrapped with it; and the uniforms it drew. Each branch states condition, decision, dependency call, and the exact return outcome. `S` below is `<K::Pairing as IPairingAdapter>::Scalar`.

## `cross_set`

`cross_set<'a, K: ICredentialKemAdapter, E: IEncoderAdapter>(deps: &CrossSetDeps<'a, K, E>, params: CrossSetParams, payload: CrossSetPayload<'_>) -> CrossSetReturn<K>`, the trusted form: every input is a typed value from the caller — a borrowed KEM, randomness source, key-derivation adapter, and encoder in `deps`, the count in `params`, the admitted identity and the configured derivation context in `payload`.

| Branch | Condition | Decision | Dependency call | Outcome |
|---|---|---|---|---|
| draw failed | `deps.random.fill_bytes(FillBytesParams, FillBytesPayload { length })` returns `Err(error)`, `length` `PIECE_GROUP_KEY_LENGTH` for the piece-group key's draw and `<S as ISampleUniformScalar>::UNIFORM_BYTES_LENGTH` for every other | the fill result | `deps.random.fill_bytes`, once per draw | `Err(CrossSetErrorReturn::FillBytes(error))`, the error unchanged |
| piece-group key refused | `PieceGroupKey::try_new` returns `Err(error)` — no input reaches this branch, the draw having the key's length | the admission result | `PieceGroupKey::try_new`, once per record | `Err(CrossSetErrorReturn::PieceGroupKey(error))`, the error unchanged |
| setup failed | `deps.kem.setup` returns `Err(error)` | the call result | `deps.kem.setup`, once per member | `Err(CrossSetErrorReturn::Setup(error))`, the error unchanged |
| derivation failed | `deps.kem.derive_identity` returns `Err(error)` | the call result | `deps.kem.derive_identity`, once per member | `Err(CrossSetErrorReturn::DeriveIdentity(error))`, the error unchanged |
| issuance failed | `deps.kem.issue` returns `Err(error)` — no input and no failure mode of the official mocks reaches this branch | the call result | `deps.kem.issue`, once per member | `Err(CrossSetErrorReturn::Issue(error))`, the error unchanged |
| encapsulation failed | `deps.kem.encapsulate` returns `Err(error)` — no input and no failure mode of the official mocks reaches this branch | the call result | `deps.kem.encapsulate`, once per member | `Err(CrossSetErrorReturn::Encapsulate(error))`, the error unchanged |
| wrap refused | `wrap_piece_group_key` returns `Err(error)` | the call result | `wrap_piece_group_key`, once per member | `Err(CrossSetErrorReturn::Wrap(error))`, the error unchanged |
| unwrap refused | `unwrap_piece_group_key` returns `Err(error)` — no input and no failure mode of the official mocks reaches this branch | the call result | `unwrap_piece_group_key`, once per member | `Err(CrossSetErrorReturn::Unwrap(error))`, the error unchanged |
| computed | every record's calls succeed | the records assembled in index order | the draws and adapter calls stated below | `Ok(CrossSetSuccessReturn { vectors })` |

### Draw

The piece-group key's draw is `deps.random.fill_bytes(FillBytesParams, FillBytesPayload { length: PIECE_GROUP_KEY_LENGTH })`; every other draw is `deps.random.fill_bytes(FillBytesParams, FillBytesPayload { length: <S as ISampleUniformScalar>::UNIFORM_BYTES_LENGTH })`; a failure takes the draw-failed branch. A copy of `success.bytes.expose()` is appended to the record's `draws` and `success.bytes` is handed on as the secret.

### Piece-group key

First in each record: the key's draw, then `PieceGroupKey::try_new(PieceGroupKeyConstructorParams { secret: success.bytes })`; a refusal takes the piece-group-key branch, which no input reaches, the draw having the key's length.

### Member

Run for the first set and then for the second, each over draws of its own: three draws held as `master_uniform`, `u0_uniform`, and `u1_uniform`; `deps.kem.setup(SetupParams { scope: payload.identity.setup_scope }, SetupPayload { master_uniform, u0_uniform, u1_uniform })`; `deps.kem.derive_identity(DeriveIdentityParams, DeriveIdentityPayload { parameter_set: &setup.parameter_set, identity: payload.identity.identity })`, the admitted identity copied into each call, `AdmittedKemIdentity` being `Copy`; a fourth draw and `deps.kem.issue(IssueParams, IssuePayload { parameter_set: &setup.parameter_set, master_scalar: &setup.master_scalar, identity_element: &derived.identity_element, uniform })`; a fifth draw and `deps.kem.encapsulate(EncapsulateParams, EncapsulatePayload { parameter_set: &setup.parameter_set, uniform })`; `wrap_piece_group_key(&WrapPieceGroupKeyDeps { kdf: deps.kdf, encoder: deps.encoder }, WrapPieceGroupKeyParams, WrapPieceGroupKeyPayload { encapsulated: &encapsulated.encapsulated, context: payload.context, piece_group_key: &piece_group_key })`; `deps.kem.decapsulate(DecapsulateParams, DecapsulatePayload { identity_element: &derived.identity_element, credential: &issued.credential, capsule: &encapsulated.capsule })`, returning `Result<_, Infallible>` and unpacked irrefutably; `unwrap_piece_group_key(&UnwrapPieceGroupKeyDeps { kdf: deps.kdf, encoder: deps.encoder }, UnwrapPieceGroupKeyParams, UnwrapPieceGroupKeyPayload { encapsulated: &decapsulated.encapsulated, context: payload.context, wrapped: &wrapped.wrapped })`. Each failure takes its branch, the callee error carried unchanged; the issuance randomness and the master scalar are dropped with the member's scope.

The member's outcome is a `CrossSetMember` with `setup.parameter_set` as `parameter_set`, `derived.identity_element` as `identity_element`, `issued.credential` as `credential`, `encapsulated.capsule` as `capsule`, `encapsulated.encapsulated` as `encapsulated`, `wrapped.wrapped` as `wrapped`, `decapsulated.encapsulated` as `decapsulated`, and `unwrapped.piece_group_key` as `unwrapped`.

### Unreached branches

- Issuance failure: no input and no failure mode of the official mocks reaches `Err(CrossSetErrorReturn::Issue(error))`, since the method's one flavor is `Sampling`, every draw is `UNIFORM_BYTES_LENGTH` long, and `MockIPairingAdapterFailureMode::SampleScalarWrongLength`, the one mode that refuses a sampling, refuses setup's master sampling before issuance is reached; the branch has no unit block.
- Encapsulation failure: no input and no failure mode of the official mocks reaches `Err(CrossSetErrorReturn::Encapsulate(error))`, for the same reason — the master sampling is refused first; the branch has no unit block.
- Unwrap failure: no input and no failure mode of the official mocks reaches `Err(CrossSetErrorReturn::Unwrap(error))`, since the unwrap encodes and derives over the same encoder, key-derivation adapter, and context as the member's wrap, over key material whose bytes equal those the wrap derived from, so an encoding, derivation, or wrapping-key-length refusal arrives first at the wrap as `Wrap`, and the key it recovers is the drawn key of `PIECE_GROUP_KEY_LENGTH` bytes, which `PieceGroupKey::try_new` admits; the branch has no unit block.

### Record

The record's outcome is a `CrossSetVector` with the `draws`, the admitted `piece_group_key`, and the first and second members.

### Ordering

The records in index order; within a record the piece-group key's draw and admission, then the first member, then the second; within a member its draws in the order master, `u0`, `u1`, issuance, and encapsulation, each draw immediately before its consuming call, then the wrap, the decapsulation, and the unwrap; the first failure returns; every uniform's and secret's `Secret` is cleared when it drops; no side effect beyond the draws and the adapters' own.
