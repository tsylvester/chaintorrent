# `statement_mutations` — interaction spec

Branch contract for the `statement_mutations` module of the `vectors` module of `apps/harness-crypto`: `statement_mutations` produces the statement-mutation vector records, generic over the selected pairing, the credential KEM, the key agreement, and the delivery proof with its chain forms — per record one mint delivery from `harness-crypto/delivery/mint` over the typed mint context and the admitted identity and the transfer delivery from `harness-crypto/delivery/transfer` that follows it over the typed transfer context and the mint delivery's recipient, each baseline statement verified against its proof, and for every statement field and every proof scalar of each relation that field or scalar mutated alone with the mutated statement, the proof, and the reference verifier's verdict; and the deliveries' uniforms followed by its own mutation-offset uniform. Each branch states condition, decision, dependency call, and the exact return outcome. `F` below is `D::Forms` and `S` is `P::Scalar`.

## `statement_mutations`

`statement_mutations<'a, P: IPairingArithmetic, K: ICredentialKemAdapter<Pairing = P>, A: IKeyAgreementAdapter<Pairing = P>, D: IDeliveryProofAdapter<Pairing = P>>(deps: &StatementMutationsDeps<'a, P, K, A, D>, params: StatementMutationsParams, payload: StatementMutationsPayload<'_, D::Forms>) -> StatementMutationsReturn<P, D>`, the trusted form: every input is a typed value from the caller — the borrowed pairing, KEM, key agreement, delivery proof, and randomness source in `deps`, the count in `params`, the typed contexts and the admitted identity in `payload`.

| Branch | Condition | Decision | Dependency call | Outcome |
|---|---|---|---|---|
| mint delivery failed | `mint(&MintDeps { kem: deps.kem, key_agreement: deps.key_agreement, delivery_proof: deps.delivery_proof, random: deps.random }, MintParams, MintPayload { context: payload.mint, identity: payload.identity })` returns `Err(error)` | the call result | `mint`, once per record | `Err(StatementMutationsErrorReturn::Mint(error))`, the error unchanged |
| transfer delivery failed | `transfer(&TransferDeps { kem: deps.kem, key_agreement: deps.key_agreement, delivery_proof: deps.delivery_proof, random: deps.random }, TransferParams, TransferPayload { context: payload.transfer, parameter_set: &minted.delivery.parameter_set, identity_element: &minted.delivery.identity_element, holder: &minted.delivery.recipient })` returns `Err(error)` | the call result | `transfer`, once per record after its mint delivery | `Err(StatementMutationsErrorReturn::Transfer(error))`, the error unchanged |
| draw failed | `deps.random.fill_bytes(FillBytesParams, FillBytesPayload { length })` returns `Err(error)`, `length` `<S as ISampleUniformScalar>::UNIFORM_BYTES_LENGTH` | the fill result | `deps.random.fill_bytes`, once per record after both deliveries | `Err(StatementMutationsErrorReturn::FillBytes(error))`, the error unchanged |
| verdict failed | `deps.delivery_proof.verify` returns `Err(error)` | the call result | `deps.delivery_proof.verify`, over each baseline and over each mutation's statement and proof | `Err(StatementMutationsErrorReturn::Verify { relation, error })`, the error unchanged |
| offset sampling refused | `<S as ISampleUniformScalar>::sample_from_uniform_bytes` returns `Err(error)` | the sampling result | `sample_from_uniform_bytes`, once per record | `Err(StatementMutationsErrorReturn::OffsetSampling(error))`, the error unchanged |
| mutated form refused | the same form's `from_field` over the mutated canonical value returns `Err(error)` | the rebuild result | `from_field`, per form-typed context field | `Err(StatementMutationsErrorReturn::MutatedChainIdentifier { relation, error })`, or `MutatedIdentity`, `MutatedEntitlement`, or `MutatedInterval` with the relation, the `DeliveryContextField` of the field, and the error, carried unchanged |
| mutated domain value refused | `SuiteIdentifier::try_new`, `Root::try_new`, or `ParameterSetIdentifier::try_new` over the mutated value returns `Err(error)` | the constructor result | the domain constructor, per domain-typed context field | `Err(StatementMutationsErrorReturn::MutatedSuiteIdentifier { relation, error })`, `MutatedAssetRoot { relation, error }`, or `MutatedParameterSetIdentifier { relation, error }`, the error unchanged |
| proof components mismatched | `proof_components` over a baseline proof returns components of the other relation | the components' relation | `deps.delivery_proof.proof_components`, per proof-scalar mutation | `Err(StatementMutationsErrorReturn::ProofComponents { relation })` |
| proof rebuild refused | `deps.delivery_proof.proof_from_components` returns `Err(error)` | the rebuild result | `deps.delivery_proof.proof_from_components`, per mutation | `Err(StatementMutationsErrorReturn::ProofFromComponents { relation, error })`, the error unchanged |
| computed | every record's calls succeed | the records assembled in index order | the calls stated below | `Ok(StatementMutationsSuccessReturn { vectors })` |

### Mint delivery

Per record: `mint(&MintDeps { kem: deps.kem, key_agreement: deps.key_agreement, delivery_proof: deps.delivery_proof, random: deps.random }, MintParams, MintPayload { context: payload.mint, identity: payload.identity })`, a failure taking the mint-delivery-failed branch, the admitted identity copied into each record's call, `AdmittedKemIdentity` being `Copy`. The record's baseline mint statement and proof are `minted.delivery.statement` and `minted.delivery.proof`.

### Transfer delivery

Per record after its mint delivery: `transfer(&TransferDeps { kem: deps.kem, key_agreement: deps.key_agreement, delivery_proof: deps.delivery_proof, random: deps.random }, TransferParams, TransferPayload { context: payload.transfer, parameter_set: &minted.delivery.parameter_set, identity_element: &minted.delivery.identity_element, holder: &minted.delivery.recipient })`, a failure taking the transfer-delivery-failed branch. The record's baseline transfer statement and proof are `transferred.delivery.statement` and `transferred.delivery.proof`.

### Draw

The record's own, after both deliveries: `deps.random.fill_bytes(FillBytesParams, FillBytesPayload { length: <S as ISampleUniformScalar>::UNIFORM_BYTES_LENGTH })`, a failure taking the draw-failed branch. The record's `draws` are a copy of the mint delivery's `draws`, followed by a copy of the transfer delivery's, followed by a copy of `success.bytes.expose()`; `success.bytes` is handed on as the offset uniform.

### Verdict

The shared step for a statement and a proof of one relation: `deps.delivery_proof.verify(VerifyParams, VerifyPayload { statement: AlgebraicStatement::Mint(&statement) or AlgebraicStatement::Transfer(&statement), proof: &proof })`, a failure taking the verdict-failed branch with the relation; otherwise `success.is_valid`. Run over each baseline, the mint's then the transfer's, before any mutation, and over each mutation's pair.

### Mutation offset

The record's own draw and `<S as ISampleUniformScalar>::sample_from_uniform_bytes(SampleUniformScalarParams, SampleUniformScalarPayload { uniform })`, a refusal taking the offset-sampling-refused branch; `delta` the exposed sampled scalar; `g1_offset` the `product` of `deps.pairing.mul_g1` over the `point` of `g1_generator` and a clone of `delta`, and `g2_offset` the `product` of `mul_g2` over the `point` of `g2_generator` and a clone of `delta`, each unpacked irrefutably.

### Point and scalar mutation

The shared steps: a first-group point `p` becomes the `sum` of `deps.pairing.add_g1(AddG1Params, AddG1Payload { left: p.clone(), right: g1_offset.clone() })` and a second-group point the `sum` of `add_g2` over it and `g2_offset.clone()`, each unpacked irrefutably; a scalar `z` becomes the `sum` of `add_scalar(AddScalarParams, AddScalarPayload { left: z.clone(), right: delta.clone() })`, unpacked irrefutably.

### Canonical value mutation

The shared step for a form-typed context field, an exhaustive `match` on the `CanonicalFieldValue` the form's `to_field(ToFieldParams, &form)` returns, unpacked irrefutably: `FixedBytes32`, `FixedBytes20`, and `Unsigned256` with the lowest bit of the last byte flipped by `^ 0x01`; `Unsigned16`, `Unsigned32`, and `Unsigned64` with the lowest bit flipped by `^ 1`; `Bytes` with one `0x00` byte appended; `Text` with the character `0` appended; then `from_field(FromFieldParams, mutated)` on the same form type, a refusal taking the mutated-form-refused branch with the relation, the `DeliveryContextField` of the field, and the error.

### Domain value mutation

The shared step for the domain-typed context fields: the suite identifier becomes `SuiteIdentifier::try_new(SuiteIdentifierConstructorParams { identifier, version })`, `identifier` a copy of `identifier()` with the lowest bit of its last byte flipped and `version` the `version()`; the asset root becomes `Root::try_new(RootConstructorParams { bytes })` over a copy of `as_bytes()` with the lowest bit of its last byte flipped; the parameter-set identifier becomes `ParameterSetIdentifier::try_new(ParameterSetIdentifierConstructorParams { bytes })` likewise; each refusal taking its mutated-domain-value-refused branch with the relation. The purpose becomes, by an exhaustive `match`, `MintPurpose::Replacement` for `Mint`, `MintPurpose::Mint` for `Replacement`, `TransferPurpose::Grant` for `Transfer`, and `TransferPurpose::Transfer` for `Grant`; the expiry becomes `expiry ^ 1`.

### Statement mutation

For each field of `MINT_MUTATION_FIELDS` before `Challenge`, then of `TRANSFER_MUTATION_FIELDS` before `Challenge`: a new statement of the relation built from clones of every field of the baseline statement and of its context, the keys' `pk1` and `pk2`, and the envelopes' `c1`, `c2`, `d1`, and `d2`, with the one field the variant names replaced by its mutation from the shared steps above — a form-typed context field through the canonical value mutation, a domain value, the purpose, or the expiry through the domain value mutation, and a point through the point mutation; then the verdict step over the new statement and the baseline proof. The outcome is a `MintMutation` or `TransferMutation` with the field, the new statement, the baseline proof rebuilt by `proof_from_components` over the `components` of `proof_components` over the baseline proof — `proof_components` unpacked irrefutably and a refusal of `proof_from_components` taking the proof-rebuild-refused branch — and the verdict.

### Proof-scalar mutation

For each field of `MINT_MUTATION_FIELDS` from `Challenge`, then of `TRANSFER_MUTATION_FIELDS` from `Challenge`: `deps.delivery_proof.proof_components(ProofComponentsParams, ProofComponentsPayload { proof: &baseline })`, unpacked irrefutably; an exhaustive `match` on the components — for a mint field, `MintBothGroups` or `MintFirstGroupOnly`, the challenge or the response the variant names replaced by its scalar mutation and every other component kept, a transfer arm taking the proof-components-mismatched branch with `DeliveryRelation::Mint`; for a transfer field, `TransferBothGroups` or `TransferFirstGroupOnly` likewise, a mint arm taking it with `DeliveryRelation::Transfer`; then `proof_from_components(ProofFromComponentsParams, ProofFromComponentsPayload { components })`, a refusal taking the proof-rebuild-refused branch; then a statement of the relation built from clones of every field of the baseline, and the verdict step over it and the rebuilt proof. The outcome is a `MintMutation` or `TransferMutation` with the field, that statement, the rebuilt proof, and the verdict.

### Unreached branches

No input and no failure mode of the official mocks reaches `Err(StatementMutationsErrorReturn::Transfer(error))`, since the mint delivery that precedes it calls every adapter and draws from the source the transfer delivery uses, and every mode that refuses a transfer-side call refuses the mint delivery's first; the branch has no unit block.

No input and no failure mode of the official mocks reaches `Err(StatementMutationsErrorReturn::FillBytes(error))`, since the offset is drawn from the source the deliveries draw from, after them, and `MockIRandomSourceAdapterFailureMode::FillBytesRefused`, the one mode that refuses a draw, refuses the mint delivery's first draw; the branch has no unit block.

No input and no failure mode of the official mocks reaches `Err(StatementMutationsErrorReturn::OffsetSampling(error))`, since the offset's draw is `UNIFORM_BYTES_LENGTH` long and the one mode that refuses a sampling refuses setup's master sampling inside the mint delivery first; the branch has no unit block.

No input and no failure mode of the official mocks reaches `Err(StatementMutationsErrorReturn::Verify { relation, error })`, since the verifier's challenge and weight refusals are hash-to-scalar refusals and `MockIHashToScalarAdapterFailureMode::SamplingRefused` refuses the KEM's identity mapping or the asset setup's hash inside the mint delivery first; the branch has no unit block.

No input reaches `MutatedChainIdentifier`, `MutatedIdentity`, `MutatedEntitlement`, or `MutatedInterval`, since the mutated value has the kind the form's `to_field` returned and `from_field` refuses only another kind; no input reaches `ProofComponents`, since a proof the mint prover returned carries mint components and a proof the transfer prover returned transfer components; and no input reaches `ProofFromComponents`, since the rebuilt components are the adapter's own form; the branches have no unit block.

No input and no failure mode of the official mocks reaches the `FixedBytes32`, `Unsigned16`, `Unsigned32`, `Bytes`, or `Text` arm of the canonical value mutation, since the value matched is the one a form's `to_field` returns and every chain-forms concrete and the family's mock declare `FixedBytes20` for the identity, `Unsigned256` for the entitlement and the chain identifier, and `Unsigned64` for the interval; the arms have no unit block.

### Record

The record's outcome is a `StatementMutationsVector` with the `draws`, the mint statement, the mint proof, its verdict as `mint_is_valid`, the mint mutations in `MINT_MUTATION_FIELDS` order, the transfer statement, the transfer proof, its verdict as `transfer_is_valid`, and the transfer mutations in `TRANSFER_MUTATION_FIELDS` order.

### Ordering

The records in index order; within a record its mint delivery, then its transfer delivery, then the baseline verdicts, the mint's then the transfer's, then its own draw and the mutation offset, then the mint mutations and then the transfer mutations, each in its constant's order; the deliveries draw in the order master, `u0`, `u1`, issue, recipient `x` and `y`, buyer `x` and `y`, and the rerandomization; the first failure returns; every delivery, with its witnesses and secrets, drops at the end of its record, each `Secret` cleared; no side effect beyond the draws and the adapters' own.
