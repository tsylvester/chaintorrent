# `vectors` — interaction spec

Branch contract for the `vectors` module of `apps/harness-crypto`: `vectors` is the composing function over the vector sets the harness's vectors own — it calls `cross_holder`, `rerandomization`, `non_convertibility`, `malformed_capsules`, `cross_set`, `statement_mutations`, and `replay`, in that order, each with its configured count, over the borrowed pairing, credential KEM, key agreement, delivery proof with its chain forms, randomness source, key-derivation adapter, and encoder its caller hands it, and over what each set takes of the admitted identity and other identity, the configured derivation context, and the typed mint, transfer, and next contexts, and returns every set's records. Each branch states condition, decision, dependency call, and the exact return outcome. `F` below is `D::Forms`.

## `vectors`

`vectors<'a, P: IPairingArithmetic, K: ICredentialKemAdapter<Pairing = P>, A: IKeyAgreementAdapter<Pairing = P>, D: IDeliveryProofAdapter<Pairing = P>, E: IEncoderAdapter>(deps: &VectorsDeps<'a, P, K, A, D, E>, params: VectorsParams, payload: VectorsPayload<'_, D::Forms>) -> VectorsReturn<P, K, D>`, the trusted form: every input is a typed value from the caller — the borrowed pairing, credential KEM, key agreement, delivery proof, randomness source, key-derivation adapter, and encoder in `deps`, the configured counts in `params`, the admitted identity and other identity, the configured derivation context, and the typed mint, transfer, and next contexts in `payload`. Each admitted identity is copied into each call it reaches, `AdmittedKemIdentity` being `Copy`.

### Cross-holder set

Dependency call `cross_holder::<K>(&CrossHolderDeps { kem: deps.kem, random: deps.random }, CrossHolderParams { count: params.cross_holder }, CrossHolderPayload { identity: payload.identity })`, a refusal returning `Err(VectorsErrorReturn::CrossHolder(error))` unchanged.

### Rerandomization set

Dependency call `rerandomization::<K>(&RerandomizationDeps { kem: deps.kem, random: deps.random }, RerandomizationParams { count: params.rerandomization }, RerandomizationPayload { identity: payload.identity })`, a refusal returning `Err(VectorsErrorReturn::Rerandomization(error))` unchanged.

### Non-convertibility set

Dependency call `non_convertibility::<K>(&NonConvertibilityDeps { kem: deps.kem, random: deps.random }, NonConvertibilityParams { count: params.non_convertibility }, NonConvertibilityPayload { identity: payload.identity, other_identity: payload.other_identity })`, a refusal returning `Err(VectorsErrorReturn::NonConvertibility(error))` unchanged.

### Malformed-capsule set

Dependency call `malformed_capsules::<K>(&MalformedCapsulesDeps { kem: deps.kem, random: deps.random }, MalformedCapsulesParams { count: params.malformed_capsules }, MalformedCapsulesPayload { identity: payload.identity })`, a refusal returning `Err(VectorsErrorReturn::MalformedCapsules(error))` unchanged.

### Cross-set set

Dependency call `cross_set::<K, E>(&CrossSetDeps { kem: deps.kem, random: deps.random, kdf: deps.kdf, encoder: deps.encoder }, CrossSetParams { count: params.cross_set }, CrossSetPayload { identity: payload.identity, context: payload.context })`, a refusal returning `Err(VectorsErrorReturn::CrossSet(error))` unchanged.

### Statement-mutation set

Dependency call `statement_mutations::<P, K, A, D>(&StatementMutationsDeps { pairing: deps.pairing, kem: deps.kem, key_agreement: deps.key_agreement, delivery_proof: deps.delivery_proof, random: deps.random }, StatementMutationsParams { count: params.statement_mutations }, StatementMutationsPayload { mint: payload.mint, transfer: payload.transfer, identity: payload.identity })`, a refusal returning `Err(VectorsErrorReturn::StatementMutations(error))` unchanged.

### Replay set

Dependency call `replay::<P, K, A, D>(&ReplayDeps { kem: deps.kem, key_agreement: deps.key_agreement, delivery_proof: deps.delivery_proof, random: deps.random }, ReplayParams { count: params.replay }, ReplayPayload { mint: payload.mint, transfer: payload.transfer, next: payload.next, identity: payload.identity })`, a refusal returning `Err(VectorsErrorReturn::Replay(error))` unchanged.

### Unreached branches

No input and no failure mode of the official mocks reaches `Err(VectorsErrorReturn::Rerandomization(error))`, `Err(VectorsErrorReturn::NonConvertibility(error))`, or `Err(VectorsErrorReturn::MalformedCapsules(error))`, since every refusal those functions return arises from the randomness source or a KEM method `cross_holder` calls first over the same identity, source, and KEM, and their other arms are unreached in their own nodes; the branches have no unit block.

Through this node `cross_set`'s refusals reach the caller only as its `Wrap` arm, a refusal of the key-derivation adapter no earlier set calls; `statement_mutations`'s only as its `Mint` arm carrying the mint delivery's `GenerateKeys`, `WrapTo`, or `ProveMint` refusal and as its mutated domain-value arms, refusals of the key agreement, the delivery proof, and the domain constructors no earlier set calls; and `replay`'s only as its `NotTheNextSettlement` arm, the comparison of the next context no earlier set reads; every other arm of those sets is taken first by `cross_holder` over the same identity, source, and KEM, by `statement_mutations`'s mint delivery over the same mint context, identity, key agreement, and delivery proof, or is unreached in its own node.

### Computed

Outcome `Ok(VectorsSuccessReturn { cross_holder, rerandomization, non_convertibility, malformed_capsules, cross_set, statement_mutations, replay })`, each field the set's success return unchanged.

### Ordering

`cross_holder`, `rerandomization`, `non_convertibility`, `malformed_capsules`, `cross_set`, `statement_mutations`, then `replay`, each set's draws following the previous set's on the one source; the first refusal returns and no later set is called; no side effect beyond the sets' and the adapters' own.
