# `malformed_capsules` — interaction spec

Branch contract for the `malformed_capsules` module of the `vectors` module of `apps/harness-crypto`: `malformed_capsules` produces the malformed-capsule vector records, generic over the credential KEM its caller hands it — per record a parameter set set up under the admitted scope, a capsule encapsulated under it, that capsule rebuilt from its components with its first-group component `v` displaced by the parameter set's first-group generator, each capsule's `is_well_formed` verdict under the record's parameter set, and the uniforms the record drew. Each branch states condition, decision, dependency call, and the exact return outcome. `S` below is `<K::Pairing as IPairingAdapter>::Scalar`.

## `malformed_capsules`

`malformed_capsules<'a, K: ICredentialKemAdapter>(deps: &MalformedCapsulesDeps<'a, K>, params: MalformedCapsulesParams, payload: MalformedCapsulesPayload<'_>) -> MalformedCapsulesReturn<K>`, the trusted form: every input is a typed value from the caller — a borrowed KEM and randomness source in `deps`, the count and the admitted scope in `params`, the configured identity bytes in `payload`.

| Branch | Condition | Decision | Dependency call | Outcome |
|---|---|---|---|---|
| identity not an asset identity hash's length | `params.scope` is `Asset` and `<[u8; ASSET_IDENTITY_HASH_LENGTH]>::try_from(payload.identity)` fails | an exhaustive `match` on `params.scope`, before any record | none | `Err(MalformedCapsulesErrorReturn::AssetIdentityLength { actual })`, `actual` the identity's length |
| asset identity refused | `AssetIdentityHash::try_new(AssetIdentityHashConstructorParams { bytes })` returns `Err(error)`, `bytes` the converted array | the same match's `Asset` arm | `AssetIdentityHash::try_new` | `Err(MalformedCapsulesErrorReturn::AssetIdentityHash(error))`, the error unchanged |
| draw failed | `deps.random.fill_bytes(FillBytesParams, FillBytesPayload { length })` returns `Err(error)`, `length` `<S as ISampleUniformScalar>::UNIFORM_BYTES_LENGTH` | the fill result | `deps.random.fill_bytes`, once per draw | `Err(MalformedCapsulesErrorReturn::FillBytes(error))`, the error unchanged |
| setup failed | `deps.kem.setup` returns `Err(error)` | the call result | `deps.kem.setup`, once per record | `Err(MalformedCapsulesErrorReturn::Setup(error))`, the error unchanged |
| encapsulation failed | `deps.kem.encapsulate` returns `Err(error)` | the call result | `deps.kem.encapsulate`, once per record | `Err(MalformedCapsulesErrorReturn::Encapsulate(error))`, the error unchanged |
| computed | the identity is admitted and every record's calls succeed | the records assembled in index order | the draws and adapter calls stated below | `Ok(MalformedCapsulesSuccessReturn { vectors })` |

### Scope

An exhaustive `match` on `params.scope`, before any record: `Entitlement` takes `SetupScope::Entitlement` as the setup scope and `payload.identity` is not read; `Asset` first applies `<[u8; ASSET_IDENTITY_HASH_LENGTH]>::try_from(payload.identity)`, the failure taking the identity-length branch, then `AssetIdentityHash::try_new(AssetIdentityHashConstructorParams { bytes })`, a refusal taking the asset-identity branch; the setup scope is `SetupScope::Asset { identity_hash: &hash }`.

### Draw

Every draw is `deps.random.fill_bytes(FillBytesParams, FillBytesPayload { length: <S as ISampleUniformScalar>::UNIFORM_BYTES_LENGTH })`; a failure takes the draw-failed branch. A copy of `success.bytes.expose()` is appended to the record's `draws` and `success.bytes` is handed on as the uniform.

### Record

For each index from `0` below `params.count.get()`: three draws held as `master_uniform`, `u0_uniform`, and `u1_uniform`; `deps.kem.setup(SetupParams { scope }, SetupPayload { master_uniform, u0_uniform, u1_uniform })`, `scope` the setup scope the match produced; a fourth draw and `deps.kem.encapsulate(EncapsulateParams, EncapsulatePayload { parameter_set: &setup.parameter_set, uniform })`; `deps.kem.parameter_set_components(ParameterSetComponentsParams, ParameterSetComponentsPayload { parameter_set: &setup.parameter_set })` and `deps.kem.capsule_components(CapsuleComponentsParams, CapsuleComponentsPayload { capsule: &encapsulated.capsule })`, each returning `Result<_, Infallible>` and unpacked irrefutably. Each failure takes its branch, the callee error carried unchanged; the master scalar, the encapsulated value, and the parameter set's other components are dropped with the record's scope.

No input and no failure mode of the official mocks reaches the encapsulation-failed branch, since the method's one flavor is `Sampling`, every draw is `UNIFORM_BYTES_LENGTH` long, and `MockIPairingAdapterFailureMode::SampleScalarWrongLength`, the one mode that refuses a sampling, refuses setup's master sampling before encapsulation is reached; the branch has no unit block. Likewise no input and no failure mode of the official mocks yields `false` for the encapsulated capsule's verdict, since every concrete of the KEM family and its mock concrete check a capsule `encapsulate` returned under the record's own parameter set, and no mode of the pairing family's mock concrete alters `pairing_product_is_one`; the verdict is `true`. `displaced_is_well_formed` is `false` whenever `g1` differs from the displaced `v`, `t·u0` under the entitlement scope and `t·F` under the asset scope for the encapsulation scalar `t`, the verdict being the one `is_well_formed` returns and never a constant.

### Displacement

An exhaustive `match` on the capsule's components: `CapsuleComponents::Entitlement { u, v: _, w }` yields `CapsuleComponents::Entitlement { u, v: g1, w }`; `CapsuleComponents::Asset { u, v: _ }` yields `CapsuleComponents::Asset { u, v: g1 }`; `g1` the parameter set's components' first-group generator, moved, the displaced `v` dropped. `deps.kem.capsule_from_components(CapsuleFromComponentsParams, CapsuleFromComponentsPayload { components })` returns `Result<_, Infallible>` and is unpacked irrefutably, its capsule held as `displaced`.

### Verdicts

`deps.kem.is_well_formed(IsWellFormedParams, IsWellFormedPayload { parameter_set: &setup.parameter_set, capsule })` with the encapsulated capsule and then with `displaced`, each returning `Result<_, Infallible>` and unpacked irrefutably.

The record's outcome is a `MalformedCapsulesVector` with the `draws`, `setup.parameter_set` as `parameter_set`, `encapsulated.capsule` as `capsule`, `displaced`, the first verdict's `is_well_formed` as `is_well_formed`, and the second's as `displaced_is_well_formed`.

### Ordering

The scope, then the records in index order; within a record its draws in the order master, `u0`, `u1`, and encapsulation, each draw immediately before its consuming call; then the parameter set's components, the capsule's components, the displacement and rebuild, the verdict for the encapsulated capsule, and the verdict for the displaced capsule; the first failure returns; every uniform's and secret's `Secret` is cleared when it drops; no side effect beyond the draws and the adapter's own.
