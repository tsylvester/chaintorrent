# `cross_holder` — interaction spec

Branch contract for the `cross_holder` module of the `vectors` module of `apps/harness-crypto`: `cross_holder` produces the cross-holder agreement vector records, generic over the credential KEM its caller hands it — per record a parameter set set up under the admitted scope, the configured identity's element, a credential issued and its rerandomized successor, a capsule encapsulated under the set with the value it encapsulates, the value each credential decapsulates, and the uniforms the record drew. Each branch states condition, decision, dependency call, and the exact return outcome. `S` below is `<K::Pairing as IPairingAdapter>::Scalar`.

## `cross_holder`

`cross_holder<'a, K: ICredentialKemAdapter>(deps: &CrossHolderDeps<'a, K>, params: CrossHolderParams, payload: CrossHolderPayload<'_>) -> CrossHolderReturn<K>`, the trusted form: every input is a typed value from the caller — a borrowed KEM and randomness source in `deps`, the count and the admitted scope in `params`, the configured identity bytes in `payload`.

| Branch | Condition | Decision | Dependency call | Outcome |
|---|---|---|---|---|
| identity not an asset identity hash's length | `params.scope` is `Asset` and `<[u8; ASSET_IDENTITY_HASH_LENGTH]>::try_from(payload.identity)` fails | an exhaustive `match` on `params.scope`, before any record | none | `Err(CrossHolderErrorReturn::AssetIdentityLength { actual })`, `actual` the identity's length |
| asset identity refused | `AssetIdentityHash::try_new(AssetIdentityHashConstructorParams { bytes })` returns `Err(error)`, `bytes` the converted array | the same match's `Asset` arm | `AssetIdentityHash::try_new` | `Err(CrossHolderErrorReturn::AssetIdentityHash(error))`, the error unchanged |
| draw failed | `deps.random.fill_bytes(FillBytesParams, FillBytesPayload { length })` returns `Err(error)`, `length` `<S as ISampleUniformScalar>::UNIFORM_BYTES_LENGTH` | the fill result | `deps.random.fill_bytes`, once per draw | `Err(CrossHolderErrorReturn::FillBytes(error))`, the error unchanged |
| setup failed | `deps.kem.setup` returns `Err(error)` | the call result | `deps.kem.setup`, once per record | `Err(CrossHolderErrorReturn::Setup(error))`, the error unchanged |
| derivation failed | `deps.kem.derive_identity` returns `Err(error)` | the call result | `deps.kem.derive_identity`, once per record | `Err(CrossHolderErrorReturn::DeriveIdentity(error))`, the error unchanged |
| issuance failed | `deps.kem.issue` returns `Err(error)` | the call result | `deps.kem.issue`, once per record | `Err(CrossHolderErrorReturn::Issue(error))`, the error unchanged |
| rerandomization failed | `deps.kem.rerandomize` returns `Err(error)` | the call result | `deps.kem.rerandomize`, once per record | `Err(CrossHolderErrorReturn::Rerandomize(error))`, the error unchanged |
| encapsulation failed | `deps.kem.encapsulate` returns `Err(error)` | the call result | `deps.kem.encapsulate`, once per record | `Err(CrossHolderErrorReturn::Encapsulate(error))`, the error unchanged |
| computed | the identity is admitted and every record's calls succeed | the records assembled in index order | the draws and adapter calls stated below | `Ok(CrossHolderSuccessReturn { vectors })` |

### Identity

An exhaustive `match` on `params.scope`, before any record: `Entitlement` takes `KemIdentity::Entitlement { canonical: payload.identity }` as the identity and `SetupScope::Entitlement` as the setup scope; `Asset` first applies `<[u8; ASSET_IDENTITY_HASH_LENGTH]>::try_from(payload.identity)`, the failure taking the identity-length branch, then `AssetIdentityHash::try_new(AssetIdentityHashConstructorParams { bytes })`, a refusal taking the asset-identity branch; the identity is `KemIdentity::Asset { identity_hash: &hash }` and the setup scope `SetupScope::Asset { identity_hash: &hash }`.

### Draw

Every draw is `deps.random.fill_bytes(FillBytesParams, FillBytesPayload { length: <S as ISampleUniformScalar>::UNIFORM_BYTES_LENGTH })`; a failure takes the draw-failed branch. A copy of `success.bytes.expose()` is appended to the record's `draws` and `success.bytes` is handed on as the uniform.

### Record

For each index from `0` below `params.count.get()`: three draws held as `master_uniform`, `u0_uniform`, and `u1_uniform`; `deps.kem.setup(SetupParams { scope }, SetupPayload { master_uniform, u0_uniform, u1_uniform })`, `scope` the setup scope the identity match produced; `deps.kem.derive_identity(DeriveIdentityParams, DeriveIdentityPayload { parameter_set: &setup.parameter_set, identity })`, `identity` the identity the match produced; a fourth draw and `deps.kem.issue(IssueParams, IssuePayload { parameter_set: &setup.parameter_set, master_scalar: &setup.master_scalar, identity_element: &derived.identity_element, uniform })`; a fifth draw and `deps.kem.rerandomize(RerandomizeParams, RerandomizePayload { parameter_set: &setup.parameter_set, identity_element: &derived.identity_element, credential: &issued.credential, uniform })`; a sixth draw and `deps.kem.encapsulate(EncapsulateParams, EncapsulatePayload { parameter_set: &setup.parameter_set, uniform })`; `deps.kem.decapsulate(DecapsulateParams, DecapsulatePayload { identity_element: &derived.identity_element, credential, capsule: &encapsulated.capsule })` with the issued credential and then with the successor, each returning `Result<_, Infallible>` and unpacked irrefutably. Each failure takes its branch, the callee error carried unchanged; the issuance randomness, the rerandomization offset, and the master scalar are dropped with the record's scope.

The record's outcome is a `CrossHolderVector` with the `draws`, `setup.parameter_set` as `parameter_set`, `derived.identity_element` as `identity_element`, `issued.credential` as `issued`, `rerandomized.credential` as `successor`, `encapsulated.capsule` as `capsule`, `encapsulated.encapsulated` as `encapsulated`, and the two decapsulated values as `issued_decapsulated` and `successor_decapsulated`.

### Ordering

The identity, then the records in index order; within a record its draws in the order master, `u0`, `u1`, issuance, rerandomization, and encapsulation, each draw immediately before its consuming call, then the decapsulations; the first failure returns; every uniform's and secret's `Secret` is cleared when it drops; no side effect beyond the draws and the adapter's own.
