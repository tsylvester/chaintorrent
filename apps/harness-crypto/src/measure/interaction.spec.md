# `measure` — interaction spec

Branch contract for the `measure` module of `apps/harness-crypto`: `measure` produces the delivery measurement, generic over the pairing, the credential KEM, the key agreement, the delivery proof with its chain forms, and the verifier concrete its caller hands it — for each configured iteration a fresh mint delivery and the transfer delivery that follows it, untimed, and a capsule encapsulated from a drawn uniform, untimed, then only the call measured timed: `prove_mint` over a copy of the mint witnesses, `prove_transfer` over a copy of the transfer witnesses, `verify` over each relation's statement and proof, and `decapsulate` over the mint delivery's credential and identity element and the capsule, each timing the mean over the iteration count; the capsule, envelope, and each relation's proof sized in bytes by the pairing's encoders over the objects of one further mint and transfer delivery, and that pair submitted through the verifier concrete, an accepted delivery's cost read as L2 execution gas and L1 data fee. Each branch states condition, decision, dependency call, and the exact return outcome. `F` below is `D::Forms` and `S` is `P::Scalar`.

## `measure`

`measure<'a, P: IPairingAdapter, K: ICredentialKemAdapter<Pairing = P>, A: IKeyAgreementAdapter<Pairing = P>, D: IDeliveryProofAdapter<Pairing = P>, V: IVerifierAdapter<DeliveryProof = D>>(deps: &MeasureDeps<'a, P, K, A, D, V>, params: MeasureParams, payload: MeasurePayload<'_, D::Forms>) -> MeasureReturn`, the trusted form: every input is a typed value from the caller — the borrowed pairing, KEM, key agreement, delivery proof, verifier, and randomness source in `deps`, the iteration count in `params`, and the typed mint and transfer contexts and the admitted identity in `payload`; the function composes no delivery step, admits no context or identity, and draws only the capsule's uniform.

| Branch | Condition | Decision | Dependency call | Outcome |
|---|---|---|---|---|
| mint delivery failed | `mint` returns `Err(error)` | the call result | `mint` as the Delivery pair states | `Err(MeasureErrorReturn::Mint(error))`, the error unchanged |
| transfer delivery failed | `transfer` returns `Err(error)` | the call result | `transfer` as the Delivery pair states | `Err(MeasureErrorReturn::Transfer(error))`, the error unchanged |
| draw failed | `deps.random.fill_bytes(FillBytesParams, FillBytesPayload { length: <S as ISampleUniformScalar>::UNIFORM_BYTES_LENGTH })` returns `Err(error)` | the call result | `deps.random.fill_bytes`, once per capsule | `Err(MeasureErrorReturn::FillBytes(error))`, the error unchanged |
| encapsulation failed | `deps.kem.encapsulate` returns `Err(error)` | the call result | `deps.kem.encapsulate` as the Capsule step states | `Err(MeasureErrorReturn::Encapsulate(error))`, the error unchanged |
| prove mint failed | `deps.delivery_proof.prove_mint` returns `Err(error)` | the call result, checked after the clock is read | `deps.delivery_proof.prove_mint` as the Prove mint step states | `Err(MeasureErrorReturn::ProveMint(error))`, the error unchanged |
| prove transfer failed | `deps.delivery_proof.prove_transfer` returns `Err(error)` | the call result, checked after the clock is read | `deps.delivery_proof.prove_transfer` as the Prove transfer step states | `Err(MeasureErrorReturn::ProveTransfer(error))`, the error unchanged |
| verification failed | `deps.delivery_proof.verify` returns `Err(error)` over either relation | the call result, checked after the clock is read | `deps.delivery_proof.verify` as the Verify steps state | `Err(MeasureErrorReturn::Verify { relation, error })`, `relation` the `DeliveryRelation` the call concerned, the error unchanged |
| chain read failed | `deps.verifier.verify_on_chain` returns `Err(error)` over either relation | the `Err` arm of the submission's return | `deps.verifier.verify_on_chain` as the Costed pair states | `Err(MeasureErrorReturn::OnChain { relation, error })`, `relation` the `DeliveryRelation` submitted, the error unchanged |
| delivery not accepted | `deps.verifier.verify_on_chain` returns `Ok(VerifyOnChainSuccessReturn::Rejected)` or `Ok(VerifyOnChainSuccessReturn::Reverted { data })` over either relation | the `Ok` arm's variant | `deps.verifier.verify_on_chain` as the Costed pair states | `Err(MeasureErrorReturn::NotAccepted { relation, verdict })`, `verdict` `RejectedDelivery::Rejected` or `RejectedDelivery::Reverted { data }`, `relation` the `DeliveryRelation` submitted |
| computed | every iteration and the costed pair complete | the measurement assembled | every call the steps state | `Ok(MeasureSuccessReturn { measurement })`, the measurement holding `params.iterations`, the means, the sizes, and the two costs |

### Delivery pair

The shared step for one mint delivery and the transfer delivery that follows it, run per iteration and once more for the costed pair: dependency call `mint(&MintDeps { kem: deps.kem, key_agreement: deps.key_agreement, delivery_proof: deps.delivery_proof, random: deps.random }, MintParams, MintPayload { context: payload.mint, identity: payload.identity })`, a failure taking the mint-delivery-failed branch, the admitted identity copied into each call, `AdmittedKemIdentity` being `Copy`; then dependency call `transfer` over the same deps, `TransferParams`, and `TransferPayload { context: payload.transfer, parameter_set: &minted.delivery.parameter_set, identity_element: &minted.delivery.identity_element, holder: &minted.delivery.recipient }`, a failure taking the transfer-delivery-failed branch.

### Capsule

The shared step per iteration and for the costed pair, after its delivery pair: dependency call `deps.random.fill_bytes(FillBytesParams, FillBytesPayload { length: <S as ISampleUniformScalar>::UNIFORM_BYTES_LENGTH })`, a failure taking the draw-failed branch; then dependency call `deps.kem.encapsulate(EncapsulateParams, EncapsulatePayload { parameter_set: &minted.delivery.parameter_set, uniform: draw.bytes })`, a failure taking the encapsulation-failed branch; the capsule is `encapsulated.capsule`.

### Measured call

The shared step for a timed operation: every input is built before the clock is read; `Instant::now()` is read; the one dependency call runs; `elapsed()` is read immediately after it; the elapsed time is added to the operation's total by `Duration::saturating_add`; the call's result is checked after the clock is read, so a failure returns after its time was read and the total is discarded with the return.

### Prove mint

Per iteration, after its capsule: the payload `ProveMintPayload { master_scalar, credential_randomness, coins, statement: &minted.delivery.statement }` with each secret a copy, the master scalar as `MasterScalarComponents { value }` over `Secret::try_new` of a clone of `witnesses.master_scalar.value.expose()`, the credential randomness likewise, and the coins as `EnvelopeCoins { rho, sigma }` each copied likewise; measured call `deps.delivery_proof.prove_mint(ProveMintParams, payload)`; a failure taking the prove-mint-failed branch; the proof is dropped.

### Prove transfer

Per iteration after prove mint: the payload `ProveTransferPayload { seller_secrets, offset, coins, statement: &transferred.delivery.statement }` with `seller_secrets` as `KeyPairComponents { x, y }` and `offset` and `coins` each a copy as prove mint copies; measured call `deps.delivery_proof.prove_transfer(ProveTransferParams, payload)`; a failure taking the prove-transfer-failed branch; the proof is dropped.

### Verify mint

Per iteration after prove transfer: measured call `deps.delivery_proof.verify(VerifyParams, VerifyPayload { statement: AlgebraicStatement::Mint(&minted.delivery.statement), proof: &minted.delivery.proof })`; a failure taking the verification-failed branch with `DeliveryRelation::Mint`; the verdict `is_valid` is read by nothing.

### Verify transfer

Per iteration after verify mint: measured call `deps.delivery_proof.verify` over `AlgebraicStatement::Transfer(&transferred.delivery.statement)` and `&transferred.delivery.proof`; a failure taking the verification-failed branch with `DeliveryRelation::Transfer`.

### Decapsulate

Per iteration after verify transfer: measured call `deps.kem.decapsulate(DecapsulateParams, DecapsulatePayload { identity_element: &minted.delivery.identity_element, credential: &minted.delivery.credential, capsule: &encapsulated.capsule })`, its success unpacked irrefutably; the decapsulated value is read by nothing.

### Means

After the last iteration each total is divided by `params.iterations.get()`, the result the operation's timing in `DeliveryOperationTimings`.

### Costed pair

After the means: a delivery pair and a capsule as the shared steps state them, then dependency call `deps.verifier.verify_on_chain(VerifyOnChainParams, VerifyPayload { statement: AlgebraicStatement::Mint(&minted.delivery.statement), proof: &minted.delivery.proof })`; `Ok(VerifyOnChainSuccessReturn::Accepted { cost })` yields the mint cost; `Ok(VerifyOnChainSuccessReturn::Rejected)` takes the delivery-not-accepted branch with `DeliveryRelation::Mint` and `RejectedDelivery::Rejected`; `Ok(VerifyOnChainSuccessReturn::Reverted { data })` takes it with `RejectedDelivery::Reverted { data }`; `Err(error)` takes the chain-read-failed branch with `DeliveryRelation::Mint`; then the same call over `AlgebraicStatement::Transfer(&transferred.delivery.statement)` and `&transferred.delivery.proof` with `DeliveryRelation::Transfer`; the transfer is submitted only after the mint was accepted.

### Sizes

After the costed pair's submissions: the capsule's bytes the sum of the encoded lengths of the elements `capsule_components` returns, `u` through `encode_g2` and `v` and, under the entitlement variant, `w` through `encode_g1`, each by an exhaustive `match` on `CapsuleComponents`; the envelope's bytes the sum of `c1` and `c2` through `encode_g1` and `d1` and `d2` through `encode_g2`, from `deps.key_agreement.envelope_components` over `&minted.delivery.recipient.envelope`; each proof's bytes the sum of the encoded lengths of its `challenge` and every response through `encode_scalar`, read as `bytes.expose().as_ref().len()`, and, under a `FirstGroupOnly` variant, of its three second-group first messages through `encode_g2`, from `deps.delivery_proof.proof_components` over the delivery's proof, by an exhaustive `match` on `DeliveryProofComponents`; every adapter call returns `Result<_, Infallible>` and is unpacked irrefutably.

### Unreached branches

- Transfer, encapsulation, prove, and verification failures: no input and no failure mode of the official mocks reaches `Err(MeasureErrorReturn::Transfer(..))`, `Err(MeasureErrorReturn::Encapsulate(..))`, `Err(MeasureErrorReturn::ProveMint(..))`, `Err(MeasureErrorReturn::ProveTransfer(..))`, or `Err(MeasureErrorReturn::Verify { .. })`, since the first delivery pair of the first iteration calls every adapter each of them calls, draws from the source each uses, and every mode that refuses one of those calls refuses an earlier call of the mint delivery first; the branches have no unit block.
- Rejected and reverted deliveries: no input and no failure mode of the official mocks reaches `Err(MeasureErrorReturn::NotAccepted { .. })`, since the verifier family's mock concrete returns `Accepted` or its own error; the branches have no unit block.

### Computed

`Ok(MeasureSuccessReturn { measurement })`, the measurement holding `params.iterations`, the means, the sizes, and the two costs.

### Ordering

Every iteration in order, each running its delivery pair, its capsule, prove mint, prove transfer, verify mint, verify transfer, and decapsulate; then the means; then the costed pair, its capsule, the mint's submission, the transfer's submission, and the sizes; the first failure returns; every delivery, witness copy, and secret drops at the end of its iteration or of the costed pair, each `Secret` cleared; the clock is read only around a measured call; no side effect beyond the deliveries' draws, the capsules' draws, and the adapters' own.
