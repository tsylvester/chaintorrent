# `admit_generate_selection` — interaction spec

Branch contract for the `admit_generate_selection` module of the `generate` module of `apps/harness-crypto`: `admit_generate_selection` selects the generate concrete the configuration names, narrowing the selected member's untrusted settings document through that member's guard, reading that member's declaration through the declaration lookup its deps carry, and admitting the document against that declaration through the member's settings admission its deps carry — each refusal returning in the member's variant with the callee's error unchanged — producing the settings-carrying `GenerateConcrete`. Each function's branches state condition, decision, dependency call, and the exact return outcome.

## `admit_generate_selection`

`admit_generate_selection(deps: &AdmitGenerateSelectionDeps, params: AdmitGenerateSelectionParams, payload: serde_json::Value) -> AdmitGenerateSelectionReturn`, the validating form; `deps` carries the declaration lookup and the Solidity member's settings admission as handles, each called only through its field; the decision is an exhaustive `match` on `params.identifier`, so a further member adds an arm.

| Branch | Condition | Decision | Dependency call | Outcome |
|---|---|---|---|---|
| Solidity, narrowing | `params.identifier` is `GenerateConcreteKind::Solidity` | the guard `SolidityGenerateSettingsDocument::try_from(payload)`, the first statement of the arm | `SolidityGenerateSettingsDocument::try_from` | a refusal `Err(AdmitGenerateSelectionErrorReturn::Solidity(AdmitGenerateSelectionSolidityErrorReturn::Document(error)))` with the error unchanged; else the document passes to the next row |
| Solidity, declaration | the guard narrowed the payload | none | `(deps.lookup_declaration)(&LookupGenerateDeclarationDeps, LookupGenerateDeclarationParams { identifier: params.identifier }, LookupGenerateDeclarationPayload)`, its success unpacked irrefutably because its error arm is `Infallible` | the returned declaration is held for the admission |
| Solidity, admission | the declaration was read | none | `(deps.admit_solidity_settings)(&AdmitSolidityGenerateSettingsDeps { declaration: &declaration }, AdmitSolidityGenerateSettingsParams, AdmitSolidityGenerateSettingsPayload { document })` | a refusal `Err(AdmitGenerateSelectionErrorReturn::Solidity(AdmitGenerateSelectionSolidityErrorReturn::Settings(error)))` with the error unchanged; else `Ok(AdmitGenerateSelectionSuccessReturn { selection: GenerateConcrete::Solidity { settings: Box::new(admitted.settings) } })` |
| Mock, under `#[cfg(any(test, feature = "mocks"))]` | `params.identifier` is `GenerateConcreteKind::Mock` | none; `payload` is not read, the mock concrete holding no settings | none; neither handle is read | `Ok(AdmitGenerateSelectionSuccessReturn { selection: GenerateConcrete::Mock(MockIGenerateAdapterFailureMode::NoFailure) })` |

### Ordering

The guard, then the lookup, then the admission; the first refusal returns and no later call is made; no side effect.
