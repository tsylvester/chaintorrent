# `mint` — interaction spec

Branch contract for the `mint` module of the `delivery` module of `apps/harness-crypto`: `mint` produces the mint delivery, generic over the credential KEM, the key agreement, and the delivery proof with its chain forms its caller hands it — over a typed mint context and an admitted identity, a parameter set set up under the identity's setup scope, the identity's element, a credential issued under the master scalar, the recipient's key pair generated and its public keys admitted with their proof of possession, the credential wrapped to them, and the mint statement proved; it returns the statement and proof, the parameter set, identity element, and credential, the witnesses the prover took, the recipient as a holder, and the uniforms it drew. Each branch states condition, decision, dependency call, and the exact return outcome. `S` below is `P::Scalar`.

## `mint`

`mint<'a, P: IPairingAdapter, K: ICredentialKemAdapter<Pairing = P>, A: IKeyAgreementAdapter<Pairing = P>, D: IDeliveryProofAdapter<Pairing = P>>(deps: &MintDeps<'a, K, A, D>, params: MintParams, payload: MintPayload<'_, D::Forms>) -> MintReturn<P, K, A, D>`, the trusted form: every input is a typed value from the caller — a borrowed KEM, key agreement, delivery proof, and randomness source in `deps`, and the mint context and admitted identity in `payload`.

| Branch | Condition | Decision | Dependency call | Outcome |
|---|---|---|---|---|
| draw failed | `deps.random.fill_bytes(FillBytesParams, FillBytesPayload { length })` returns `Err(error)`, `length` `<S as ISampleUniformScalar>::UNIFORM_BYTES_LENGTH` | the call result | `deps.random.fill_bytes`, once per uniform | `Err(MintErrorReturn::FillBytes(error))`, the error unchanged |
| setup failed | `deps.kem.setup` returns `Err(error)` | the call result | `deps.kem.setup` | `Err(MintErrorReturn::Setup(error))`, the error unchanged |
| derivation failed | `deps.kem.derive_identity` returns `Err(error)` | the call result | `deps.kem.derive_identity` | `Err(MintErrorReturn::DeriveIdentity(error))`, the error unchanged |
| issuance failed | `deps.kem.issue` returns `Err(error)` | the call result | `deps.kem.issue` | `Err(MintErrorReturn::Issue(error))`, the error unchanged |
| key generation failed | `deps.key_agreement.generate_keys` returns `Err(error)` | the call result | `deps.key_agreement.generate_keys` | `Err(MintErrorReturn::GenerateKeys(error))`, the error unchanged |
| key admission failed | `deps.key_agreement.public_keys_from_components` returns `Err(error)` | the call result | `deps.key_agreement.public_keys_from_components` | `Err(MintErrorReturn::PublicKeysFromComponents(error))`, the error unchanged |
| wrap failed | `deps.key_agreement.wrap_to` returns `Err(error)` | the call result | `deps.key_agreement.wrap_to` | `Err(MintErrorReturn::WrapTo(error))`, the error unchanged |
| proof failed | `deps.delivery_proof.prove_mint` returns `Err(error)` | the call result | `deps.delivery_proof.prove_mint` | `Err(MintErrorReturn::ProveMint(error))`, the error unchanged |
| computed | every call succeeds | the delivery assembled | the draws and adapter calls stated below | `Ok(MintSuccessReturn { delivery })` |

### Draw

Every draw is `deps.random.fill_bytes(FillBytesParams, FillBytesPayload { length: <S as ISampleUniformScalar>::UNIFORM_BYTES_LENGTH })`; a failure takes the draw-failed branch. A copy of `success.bytes.expose()` is appended to the delivery's `draws` and `success.bytes` is handed on as the uniform.

### Copy of a secret

A copy of a `Secret` is `Secret::try_new(SecretConstructorParams { value: secret.expose().clone() })`, `Result<_, Infallible>` unpacked irrefutably, the scalar being `Clone`; the copy is kept and the original handed on.

### Setup

Three draws held as `master_uniform`, `u0_uniform`, and `u1_uniform`; `deps.kem.setup(SetupParams { scope: payload.identity.setup_scope }, SetupPayload { master_uniform, u0_uniform, u1_uniform })`, a failure taking the setup-failed branch.

### Derivation

`deps.kem.derive_identity(DeriveIdentityParams, DeriveIdentityPayload { parameter_set: &setup.parameter_set, identity: payload.identity.identity })`, a failure taking the derivation-failed branch.

### Issuance

A fourth draw; `deps.kem.issue(IssueParams, IssuePayload { parameter_set: &setup.parameter_set, master_scalar: &setup.master_scalar, identity_element: &derived.identity_element, uniform })`, a failure taking the issuance-failed branch. No input and no failure mode of the official mocks reaches this arm, since every mode that refuses issuance's sampling refuses `setup`'s sampling first and the draw is of the length the sampling bound declares.

### Recipient

A fifth and a sixth draw as `x_uniform` and `y_uniform`; `deps.key_agreement.generate_keys(GenerateKeysParams, GenerateKeysPayload { x_uniform, y_uniform })`, a failure taking the key-generation-failed branch; `deps.key_agreement.key_pair_public_keys` over the key pair, `Result<_, Infallible>` unpacked irrefutably; `deps.key_agreement.public_keys_from_components(PublicKeysFromComponentsParams, PublicKeysFromComponentsPayload { components, possession: &generated.possession })`, `components` the public keys just read, a failure taking the key-admission-failed branch. No input and no failure mode of the official mocks reaches this arm, since the keys admitted are the ones `generate_keys` has just formed, with their own proof of possession.

### Wrap

`deps.kem.credential_components` over the issued credential, `Result<_, Infallible>` unpacked irrefutably; `deps.key_agreement.wrap_to(WrapToParams, WrapToPayload { public_keys: &admitted.public_keys, credential: components })`, a failure taking the wrap-failed branch.

### Statement

`deps.kem.parameter_set_components` over the parameter set, `deps.kem.identity_element_components` over the identity element, `deps.key_agreement.key_pair_public_keys` over the recipient's key pair, and `deps.key_agreement.envelope_components` over the envelope, each `Result<_, Infallible>` unpacked irrefutably; `AlgebraicMintStatement { context: payload.context.clone(), hpub, identity_element: element, buyer_keys: the recipient's public-key components, envelope: the envelope's components }`.

### Witnesses

`deps.kem.master_scalar_components` over the master scalar, `Result<_, Infallible>` unpacked irrefutably, called twice, once for the prover and once for the witnesses; the issuance randomness and each of the wrap's coins copied as above, the copy kept for the witnesses and the original handed to the prover.

### Proof

`deps.delivery_proof.prove_mint(ProveMintParams, ProveMintPayload { master_scalar, credential_randomness: issued.randomness, coins: wrap.coins, statement: &statement })`, a failure taking the proof-failed branch.

### Computed

`Ok(MintSuccessReturn { delivery })`, a `MintDelivery` with `statement`, `proof`, `setup.parameter_set` as `parameter_set`, `derived.identity_element` as `identity_element`, `issued.credential` as `credential`, the `witnesses`, `DeliveryHolder { key_pair, public_keys, envelope }` as `recipient`, and the `draws`.

### Ordering

The draws in the order master, `u0`, `u1`, issuance, recipient `x`, recipient `y`, each immediately before its consuming call; then the wrap, the statement, the witnesses, and the proof; the first failure returns; the master scalar is dropped with the call's scope; every uniform's and secret's `Secret` is cleared when it drops; no side effect beyond the draws and the adapters' own.

## Integration: own entries

Each entry is proven by the public integration block of the same name in `tests/mint_integration_test.rs`, the private integration test element proving no own entry.

- `every_mint_delivery_is_a_statement_and_proof_the_delivery_proof_verifies`: condition `mint` over a case, every adapter real and the operating-system source real; outcome `verify` over `AlgebraicStatement::Mint(&delivery.statement)` and `&delivery.proof` returns `is_valid` true; variation every case, each member of `PAIRING_CONCRETES` crossed with the selections the other families declare and each scope of `DECLARED_KEM_SELECTIONS`, so both curves, both verifier forms, and both scopes run; edge the statement is built from the delivery's own objects, so a statement over another envelope or other keys reports otherwise.
- `the_witnesses_prove_the_statement_again`: condition `mint` over a case, then `prove_mint` called on the case's delivery proof over the delivery's witnesses and statement; outcome the second proof verifies against the statement; variation every case; edge the witnesses are copies independent of the values the delivery's own proof consumed.
- `the_recipient_opens_its_envelope_to_a_credential_valid_for_the_identity`: condition `mint` over a case, then `unwrap` of `delivery.recipient.envelope` under `delivery.recipient.key_pair`, `credential_from_components` over the result, and `is_valid` under the delivery's parameter set and identity element; outcome `is_valid` true, and the opened credential's components equal those of `delivery.credential`; variation every case; edge the envelope is the one the statement names.
- `every_draw_replays_to_the_objects_it_produced`: condition `mint` over a case, the draws split at `UNIFORM_BYTES_LENGTH` into the uniforms of its calls in draw order, and `setup`, `derive_identity`, and `generate_keys` run on the case's adapters over those uniforms and the admitted identity; outcome the replayed parameter set's `hpub`, the replayed identity element's `element`, and the replayed key pair's `pk1` and `pk2`, each encoded through the case's pairing, equal those the delivery's statement holds, and the draws are six uniforms long; variation every case under two identities of its scope; edge draws in another order replay to other objects.
- `a_refused_draw_reaches_the_caller_whole`: condition `mint` over a case whose source is the randomness family's mock concrete under `MockIRandomSourceAdapterFailureMode::FillBytesRefused`, selected by configuration through `create_random_source`; outcome `Err(MintErrorReturn::FillBytes(FillBytesErrorReturn::MockIRandomSourceAdapter))`; variation every member of `PAIRING_CONCRETES` with each scope of `DECLARED_KEM_SELECTIONS`; edge the refusal of the first draw reaches the caller through the function's own variant before any adapter is called.

## Integration: public surface

An outside caller invokes `mint` through the crate root with `MintDeps` borrowing the adapters the KEM, key-agreement, and delivery-proof factories hand their consumers and a source from `create_random_source`, `MintParams`, and a `MintPayload` over a context and an `AdmittedKemIdentity`, and observes the `MintReturn` and each adapter method it calls over the delivery; every outcome `mint` returns is observable there, so the entries proven are every own entry above and the carried `every_concrete_declaring_the_keccak256_identifier_hashes_the_context_the_encoding_factory_encodes_to_the_oracle`, each by one block of its name, the absorbed entries being proven by the private integration test element and not here; the cases cross `PAIRING_CONCRETES` with the selections `DECLARED_HASH_TO_SCALAR_SELECTIONS`, `DECLARED_ENCODING_SELECTIONS`, `CHAIN_FORMS_CONCRETES`, `DECLARED_KEM_SELECTIONS` with each scope, `DECLARED_KEY_AGREEMENT_SELECTIONS`, and `DELIVERY_PROOF_CONCRETES` hold, each context built by `build_delivery_context` over the case's forms with `MintPurpose::Mint`, the identity `b"pkg@1.0.0#1"` under the entitlement scope and `vec![0x44; 32]` admitted as a `Root` under the asset scope, unless an entry names others; the outer-edge collaborator is the operating system's generator behind `create_random_source`, running real; a family's mock concrete under a failure mode is a selection by the public configuration under each crate's `mocks` feature in the block of the entry that names it.
