# `generate_consumer` — interaction spec

Branch contract for the `generate_consumer` module of the `run` module of `apps/harness-crypto`: `GenerateConsumer` is the run's consumer of the generate family's factory — an `IGenerateConsumer<F>` generic over the delivery proof's forms, constructed from the typed mint and transfer contexts, the admitted mapping identities, and the admitted proof identity, which on receiving the concrete the factory admitted calls its `emit` with those values and returns the concrete's `EmitReturn` whole. It names no concrete, calls no factory, and admits nothing. Each branch states condition, decision, dependency call, and the exact return outcome.

## `GenerateConsumer::try_new`

`GenerateConsumer::try_new(params: GenerateConsumerConstructorParams<'a, F>) -> GenerateConsumerTryNewReturn<'a, F>`: the one producer of the consumer; the typed contexts and the admitted identities are required at creation, and no partially constructed consumer exists.

### Constructed

Outcome `Ok(GenerateConsumer)` holding the params' mint context, transfer context, identities, and proof identity; the error arm is `Infallible` and has no branch.

## `consume_generate`

`consume_generate<G: IGenerateAdapter<Forms = F>>(&self, _params: ConsumeGenerateParams, payload: ConsumeGeneratePayload<G>) -> GenerateConsumerReturn`, the trait method of `IGenerateConsumer<F> for GenerateConsumer<'a, F>`, `type Output = GenerateConsumerReturn`; the params carry nothing and are not read.

### Emitted

Dependency call `payload.adapter.emit(EmitParams, EmitPayload { mint: &self.mint, transfer: &self.transfer, identities: &self.identities, proof_identity: self.proof_identity })`, once; outcome the call's `EmitReturn` returned whole, `Ok(EmitSuccessReturn { files })` with the files in the order the concrete wrote them, or `Err(EmitErrorReturn)` with the concrete's error unchanged; the method compares, converts, and summarizes nothing.

### Ordering

`emit` is the method's only call and its result its only return; the held values are borrowed for the call and not altered.
