# `chain_forms_consumer` — interaction spec

Branch contract for the `chain_forms_consumer` module of the `run` module of `apps/harness-crypto`: `ChainFormsConsumer` is the run's consumer of the chain family's forms function — an `IChainFormsConsumer` generic over the pairing and the encoder, constructed from the borrowed pairing, hash-to-scalar adapter, encoder, and randomness source, the borrowed `AdmittedStatements` and `AdmittedIdentities`, the admitted KEM, key agreement, and delivery proof selections, the generate selection with its per-kind configuration, the verifier concrete of the curve the consumer composes, the statement version, and the iteration count, which on receiving the forms the function constructed admits the mint and the transfer canonical contexts into those forms through `admit_contexts`, constructs a `KemConsumer` over the typed contexts, calls `create_kem` with the held KEM selection, and returns the files written and the measurement, or the first refusal whole. It names no concrete, reads no configuration, and admits no selection or identity. Each branch states condition, decision, dependency call, and the exact return outcome.

## `ChainFormsConsumer::try_new`

`ChainFormsConsumer::try_new(params: ChainFormsConsumerConstructorParams<'a, P, E>) -> ChainFormsConsumerTryNewReturn<'a, P, E>`: the one producer of the consumer; the adapters, the admitted statements, the admitted identities, and the configured values are required at creation, and no partially constructed consumer exists.

### Constructed

Outcome `Ok(ChainFormsConsumer)` holding the params' adapters, statements, identities, and configured values; the error arm is `Infallible` and has no branch.

## `consume_chain_forms`

`consume_chain_forms<F: IChainForms>(&self, _params: ConsumeChainFormsParams, _payload: ConsumeChainFormsPayload<F>) -> ChainFormsConsumerReturn`, the trait method of `IChainFormsConsumer for ChainFormsConsumer<'a, P, E>`, `type Output = ChainFormsConsumerReturn`; the params carry nothing and are not read, and the payload's forms are the type `F` the contexts are admitted into and are not read.

### Mint admission

Dependency call `admit_contexts::<F, MintPurpose>(&AdmitContextsDeps, AdmitContextsParams, AdmitContextsPayload { context: &self.statements.mint, purpose: self.statements.mint_purpose })`, the deps and params the fieldless values; condition the call returns `Err(error)`; outcome `Err(ChainFormsConsumerErrorReturn::AdmitMint(error))`, `error` unchanged; condition `Ok(AdmitContextsSuccessReturn { context })`; outcome the typed mint context continues.

### Transfer admission

Dependency call `admit_contexts::<F, TransferPurpose>(&AdmitContextsDeps, AdmitContextsParams, AdmitContextsPayload { context: &self.statements.transfer, purpose: self.statements.transfer_purpose })`, after the mint admission succeeded; condition the call returns `Err(error)`; outcome `Err(ChainFormsConsumerErrorReturn::AdmitTransfer(error))`, `error` unchanged; condition `Ok(AdmitContextsSuccessReturn { context })`; outcome the typed transfer context continues.

### KEM refused at construction

Dependency call `create_kem(&CreateKemDeps { pairing: self.pairing, hash_to_scalar: self.hash_to_scalar, consumer }, CreateKemParams { concrete: self.kem.concrete, identifier: self.kem.identifier, scope: self.kem.scope }, CreateKemPayload)`, once, `consumer` the `KemConsumer` built by `KemConsumer::try_new(KemConsumerConstructorParams { pairing: self.pairing, hash_to_scalar: self.hash_to_scalar, encoder: self.encoder, random: self.random, mint, transfer, identities: self.identities, key_agreement: self.key_agreement, delivery_proof: self.delivery_proof, generate: self.generate.clone(), kinds: self.kinds.clone(), verifier: self.verifier.clone(), statement_version: self.statement_version, iterations: self.iterations })` through the irrefutable pattern `let Ok(consumer) = …;`, `mint` and `transfer` the typed contexts of the admission branches; condition the call returns `Err(error)`; outcome `Err(ChainFormsConsumerErrorReturn::CreateKem(error))`, `error` unchanged.

### KEM consumer refused

Condition the call returns `Ok(CreateKemSuccessReturn { output })` and `output` is `Err(error)`; outcome `Err(ChainFormsConsumerErrorReturn::Kem(error))`, `error` unchanged.

### Consumed

Condition `output` is `Ok(success)`; outcome `Ok(success)`, the `DeliveryProofConsumerSuccessReturn` as the delivery proof consumer returned it through the key agreement consumer and the KEM consumer; the method compares, converts, and summarizes nothing.

### Ordering

The mint admission precedes the transfer admission, both precede the construction of the KEM consumer, and `create_kem` is called once, after the consumer it receives is built; the first refusal returns and nothing after it runs, so a refused mint context is returned before the transfer context is read and before `create_kem` is called; the held values are borrowed or cloned for the call and not altered.
