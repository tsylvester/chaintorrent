# `key_agreement_consumer` — interaction spec

Branch contract for the `key_agreement_consumer` module of the `run` module of `apps/harness-crypto`: `KeyAgreementConsumer` is the run's consumer of the envelope family's factory — an `IKeyAgreementConsumer<P>` generic over the pairing and the chain forms its contexts are typed in, constructed from the borrowed pairing, hash-to-scalar adapter, encoder, randomness source, and credential KEM, the typed mint and transfer contexts, the admitted identities, the admitted proof identity, the configured delivery proof selection, the configured generate selection with its per-kind configuration, the configured verifier selection, the configured statement version, and the configured iteration count, which on receiving the key agreement concrete the factory admitted constructs a `DeliveryProofConsumer` over it and calls `create_delivery_proof` with the held delivery proof selection, the algebra the received concrete declares, and the held statement version, and returns the files written and the measurement, or the first refusal whole. It names no concrete, reads no configuration, and admits nothing. Each branch states condition, decision, dependency call, and the exact return outcome.

## `KeyAgreementConsumer::try_new`

`KeyAgreementConsumer::try_new(params: KeyAgreementConsumerConstructorParams<'a, P, E, K, F>) -> KeyAgreementConsumerTryNewReturn<'a, P, E, K, F>`: the one producer of the consumer; the adapters, the typed contexts, the admitted identities, and the configured values are required at creation, and no partially constructed consumer exists.

### Constructed

Outcome `Ok(KeyAgreementConsumer)` holding the params' adapters, contexts, identities, and configured values; the error arm is `Infallible` and has no branch.

## `consume_key_agreement`

`consume_key_agreement<A: IKeyAgreementAdapter<Pairing = P>>(&self, _params: ConsumeKeyAgreementParams, payload: ConsumeKeyAgreementPayload<A>) -> KeyAgreementConsumerReturn`, the trait method of `IKeyAgreementConsumer<P> for KeyAgreementConsumer<'a, P, E, K, F>`, `type Output = KeyAgreementConsumerReturn`; the params carry nothing and are not read.

### Delivery proof refused at construction

Dependency call `create_delivery_proof(&CreateDeliveryProofDeps { pairing: self.pairing, hash_to_scalar: self.hash_to_scalar, encoder: self.encoder, random: self.random, consumer }, CreateDeliveryProofParams { concrete: self.delivery_proof, algebra: A::DECLARATION.algebra, statement_version: self.statement_version }, CreateDeliveryProofPayload)`, once, `consumer` the `DeliveryProofConsumer` built by `DeliveryProofConsumer::try_new(DeliveryProofConsumerConstructorParams { pairing: self.pairing, hash_to_scalar: self.hash_to_scalar, encoder: self.encoder, random: self.random, kem: self.kem, key_agreement: &payload.adapter, mint: self.mint.clone(), transfer: self.transfer.clone(), identities: self.identities.clone(), proof_identity: self.proof_identity, generate: self.generate.clone(), kinds: self.kinds.clone(), verifier: self.verifier.clone(), statement_version: self.statement_version, iterations: self.iterations })` through the irrefutable pattern `let Ok(consumer) = …;`; condition the call returns `Err(error)`; outcome `Err(KeyAgreementConsumerErrorReturn::CreateDeliveryProof(error))`, `error` unchanged.

### Delivery proof consumer refused

Condition the call returns `Ok(CreateDeliveryProofSuccessReturn { output })` and `output` is `Err(error)`; outcome `Err(KeyAgreementConsumerErrorReturn::DeliveryProof(error))`, `error` unchanged.

### Consumed

Condition `output` is `Ok(success)`; outcome `Ok(success)`, the `DeliveryProofConsumerSuccessReturn` as the delivery proof consumer returned it; the method compares, converts, and summarizes nothing.

### Ordering

`create_delivery_proof` is called once, after the consumer it receives is built; the first refusal returns and nothing after it runs; the held values are borrowed or cloned for the call and not altered.
