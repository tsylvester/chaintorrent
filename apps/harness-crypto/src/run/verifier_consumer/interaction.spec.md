# `verifier_consumer` — interaction spec

Branch contract for the `verifier_consumer` module of the `run` module of `apps/harness-crypto`: `VerifierConsumer` is the run's consumer of the verifier family's factory — an `IVerifierConsumer<D>` generic over the delivery proof adapter, constructed from the borrowed pairing, credential KEM, key agreement, delivery proof, and randomness source, the typed mint and transfer contexts, the admitted proof identity, and the configured iteration count, which on receiving the concrete the factory admitted calls `measure` over it and returns the `MeasureReturn` whole. It names no concrete, calls no factory, and admits nothing. Each branch states condition, decision, dependency call, and the exact return outcome.

## `VerifierConsumer::try_new`

`VerifierConsumer::try_new(params: VerifierConsumerConstructorParams<'a, P, K, A, D>) -> VerifierConsumerTryNewReturn<'a, P, K, A, D>`: the one producer of the consumer; the adapters, the typed contexts, the admitted identity, and the iteration count are required at creation, and no partially constructed consumer exists.

### Constructed

Outcome `Ok(VerifierConsumer)` holding the params' adapters, contexts, identity, and iteration count; the error arm is `Infallible` and has no branch.

## `consume_verifier`

`consume_verifier<V: IVerifierAdapter<DeliveryProof = D>>(&self, _params: ConsumeVerifierParams, payload: ConsumeVerifierPayload<V>) -> VerifierConsumerReturn`, the trait method of `IVerifierConsumer<D> for VerifierConsumer<'a, P, K, A, D>`, `type Output = VerifierConsumerReturn`; the params carry nothing and are not read.

### Measured

Dependency call `measure(&MeasureDeps { pairing: self.pairing, kem: self.kem, key_agreement: self.key_agreement, delivery_proof: self.delivery_proof, verifier: &payload.adapter, random: self.random }, MeasureParams { iterations: self.iterations }, MeasurePayload { mint: &self.mint, transfer: &self.transfer, identity: self.identity })`, once; outcome the call's `MeasureReturn` returned whole, `Ok(MeasureSuccessReturn { measurement })` or `Err(MeasureErrorReturn)` with the callee's error unchanged; the method compares, converts, and summarizes nothing.

### Ordering

`measure` is the method's only call and its result its only return; the held values are borrowed for the call and not altered.

- `the_measurement_measure_returns_reaches_the_caller_of_create_verifier_whole`: condition `create_verifier` over the verifier family's mock concrete under `NoFailure` and a consumer constructed as above with an iteration count of one; outcome `Ok` whose output is `Ok(MeasureSuccessReturn)` whose `measurement.timings` for `prove_mint`, `prove_transfer`, `verify_mint`, `verify_transfer`, and `decapsulate` are each greater than `Duration::ZERO`, whose `measurement.sizes` equal the lengths computed in Arrange through the received pairing's encoders as `every_object_is_sized_by_the_encodings_of_its_elements` of `harness-crypto/measure` states, and whose `measurement.costs.mint` and `measurement.costs.transfer` each equal the literal cost the verifier family's mock concrete returns; variation every member of `PAIRING_CONCRETES` crossed with both identity scopes and the verifier form each pairing declares; edge the measurement is `measure`'s own, relayed through the consumer, so a timing left at its zero default, a size read from the wrong group's encoder, or a cost taken from another verifier differs.
