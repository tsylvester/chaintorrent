# `kem_consumer` — interaction spec

Branch contract for the `kem_consumer` module of the `run` module of `apps/harness-crypto`: `KemConsumer` is the run's consumer of the credential KEM family's factory — an `IKemConsumer<P>` generic over the pairing, the encoder, and the chain forms its contexts are typed in, constructed from the borrowed pairing, hash-to-scalar adapter, encoder, and randomness source, the typed mint and transfer contexts, the borrowed `AdmittedIdentities`, the admitted key agreement selection, the delivery proof selection, the generate selection with its per-kind configuration, the verifier selection, the statement version, and the iteration count, which on receiving the KEM concrete the factory admitted pairs the proof identity and each mapping identity with its setup scope as `AdmittedKemIdentity` values, constructs a `KeyAgreementConsumer` over the concrete and those identities, calls `create_key_agreement` with the held key agreement selection, and returns the files written and the measurement, or the first refusal whole. It names no concrete, reads no configuration, and admits no context, selection, or identity. Each branch states condition, decision, dependency call, and the exact return outcome.

## `KemConsumer::try_new`

`KemConsumer::try_new(params: KemConsumerConstructorParams<'a, P, E, F>) -> KemConsumerTryNewReturn<'a, P, E, F>`: the one producer of the consumer; the adapters, the typed contexts, the admitted identities, and the configured values are required at creation, and no partially constructed consumer exists.

### Constructed

Outcome `Ok(KemConsumer)` holding the params' adapters, contexts, identities, and configured values; the error arm is `Infallible` and has no branch.

## `consume_kem`

`consume_kem<K: ICredentialKemAdapter<Pairing = P>>(&self, _params: ConsumeKemParams, payload: ConsumeKemPayload<K>) -> KemConsumerReturn`, the trait method of `IKemConsumer<P> for KemConsumer<'a, P, E, F>`, `type Output = KemConsumerReturn`; the params carry nothing and are not read, and the payload's `scope()` is not called.

### Pairing

Condition always; decision each `AdmittedIdentity` of `self.identities.proof`, then of `self.identities.mapping` in the order held, by its variant; `Entitlement { canonical }` pairs `SetupScope::Entitlement` with `KemIdentity::Entitlement { canonical: canonical.as_slice() }`, and `Asset { root }` pairs `SetupScope::Asset { root: &root }` with `KemIdentity::Asset { root: &root }`; outcome one `AdmittedKemIdentity { setup_scope, identity }` for the proof identity and a `Vec<AdmittedKemIdentity>` holding one for each mapping identity in the order held, each borrowing from `self.identities`; an identity whose variant is not the scope the KEM concrete admitted is paired as its variant states and is refused by `mint`, not by this consumer.

### Key agreement refused at construction

Dependency call `create_key_agreement(&CreateKeyAgreementDeps { pairing: self.pairing, hash_to_scalar: self.hash_to_scalar, encoder: self.encoder, random: self.random, consumer }, CreateKeyAgreementParams { concrete: self.key_agreement.concrete, identifier: self.key_agreement.identifier, algebra: self.key_agreement.algebra }, CreateKeyAgreementPayload)`, once, `consumer` the `KeyAgreementConsumer` built by `KeyAgreementConsumer::try_new(KeyAgreementConsumerConstructorParams { pairing: self.pairing, hash_to_scalar: self.hash_to_scalar, encoder: self.encoder, random: self.random, kem: &payload.adapter, mint: self.mint.clone(), transfer: self.transfer.clone(), identities, proof_identity, delivery_proof: self.delivery_proof, generate: self.generate.clone(), kinds: self.kinds.clone(), verifier: self.verifier.clone(), statement_version: self.statement_version, iterations: self.iterations })` through the irrefutable pattern `let Ok(consumer) = …;`, `identities` and `proof_identity` the values of the pairing branch; condition the call returns `Err(error)`; outcome `Err(KemConsumerErrorReturn::CreateKeyAgreement(error))`, `error` unchanged.

### Key agreement consumer refused

Condition the call returns `Ok(CreateKeyAgreementSuccessReturn { output })` and `output` is `Err(error)`; outcome `Err(KemConsumerErrorReturn::KeyAgreement(error))`, `error` unchanged.

### Consumed

Condition `output` is `Ok(success)`; outcome `Ok(success)`, the `DeliveryProofConsumerSuccessReturn` as the delivery proof consumer returned it through the key agreement consumer; the method compares, converts, and summarizes nothing.

### Ordering

The pairing precedes the construction of the consumer, and `create_key_agreement` is called once, after the consumer it receives is built; the first refusal returns and nothing after it runs; the held values are borrowed or cloned for the call and not altered.
