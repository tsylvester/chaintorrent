# `delivery_proof_consumer` — interaction spec

Branch contract for the `delivery_proof_consumer` module of the `run` module of `apps/harness-crypto`: `DeliveryProofConsumer` is the run's consumer of the delivery proof family's factory — an `IDeliveryProofConsumer<P, F>` generic over the pairing and the delivery proof's forms, constructed from the borrowed pairing, hash-to-scalar adapter, encoder, randomness source, credential KEM, and key agreement, the typed mint and transfer contexts, the admitted identities, the admitted proof identity, the configured generate selection with its per-kind configuration, the configured verifier selection, the configured statement version, and the configured iteration count, which on receiving the concrete the factory admitted calls `create_generate` with a `GenerateConsumer` it constructs and then `create_verifier` with a `VerifierConsumer` it constructs, and returns the files written and the measurement, or the first refusal whole. It names no concrete, reads no configuration, and admits nothing. Each branch states condition, decision, dependency call, and the exact return outcome.

## `DeliveryProofConsumer::try_new`

`DeliveryProofConsumer::try_new(params: DeliveryProofConsumerConstructorParams<'a, P, E, K, A, F>) -> DeliveryProofConsumerTryNewReturn<'a, P, E, K, A, F>`: the one producer of the consumer; the adapters, the typed contexts, the admitted identities, and the configured values are required at creation, and no partially constructed consumer exists.

### Constructed

Outcome `Ok(DeliveryProofConsumer)` holding the params' adapters, contexts, identities, and configured values; the error arm is `Infallible` and has no branch.

## `consume_delivery_proof`

`consume_delivery_proof<D: IDeliveryProofAdapter<Pairing = P, Forms = F>>(&self, _params: ConsumeDeliveryProofParams, payload: ConsumeDeliveryProofPayload<D>) -> DeliveryProofConsumerReturn`, the trait method of `IDeliveryProofConsumer<P, F> for DeliveryProofConsumer<'a, P, E, K, A, F>`, `type Output = DeliveryProofConsumerReturn`; the params carry nothing and are not read.

### Generate refused at construction

Dependency call `create_generate(&CreateGenerateDeps { pairing: self.pairing, hash_to_scalar: self.hash_to_scalar, encoder: self.encoder, random: self.random, kem: self.kem, key_agreement: self.key_agreement, delivery_proof: &payload.adapter, consumer }, CreateGenerateParams { concrete: self.generate.clone(), kinds: self.kinds.clone(), statement_version: self.statement_version }, CreateGeneratePayload)`, once, `consumer` the `GenerateConsumer` built by `GenerateConsumer::try_new(GenerateConsumerConstructorParams { mint: self.mint.clone(), transfer: self.transfer.clone(), identities: self.identities.clone(), proof_identity: self.proof_identity })` through the irrefutable pattern `let Ok(consumer) = …;`; condition the call returns `Err(error)`; outcome `Err(DeliveryProofConsumerErrorReturn::CreateGenerate(error))`, `error` unchanged, with the verifier factory not called.

### Emission refused

Condition the call returns `Ok(CreateGenerateSuccessReturn { output })` and `output` is `Err(error)`; outcome `Err(DeliveryProofConsumerErrorReturn::Emit(error))`, `error` unchanged, with the verifier factory not called.

### Verifier refused at construction

Condition the emission returned `Ok(EmitSuccessReturn { files })`; dependency call `create_verifier(&CreateVerifierDeps { pairing: self.pairing, delivery_proof: &payload.adapter, consumer }, CreateVerifierParams { concrete: self.verifier.clone(), statement_version: self.statement_version }, CreateVerifierPayload)`, once, `consumer` the `VerifierConsumer` built by `VerifierConsumer::try_new(VerifierConsumerConstructorParams { pairing: self.pairing, kem: self.kem, key_agreement: self.key_agreement, delivery_proof: &payload.adapter, random: self.random, mint: self.mint.clone(), transfer: self.transfer.clone(), identity: self.proof_identity, iterations: self.iterations })` through the irrefutable pattern `let Ok(consumer) = …;`; condition the call returns `Err(error)`; outcome `Err(DeliveryProofConsumerErrorReturn::CreateVerifier(error))`, `error` unchanged.

### Measurement refused

Condition the call returns `Ok(CreateVerifierSuccessReturn { output })` and `output` is `Err(error)`; outcome `Err(DeliveryProofConsumerErrorReturn::Measure(error))`, `error` unchanged.

### Measured

Condition `output` is `Ok(MeasureSuccessReturn { measurement })`; outcome `Ok(DeliveryProofConsumerSuccessReturn { files, measurement })`, the files in the order the concrete wrote them and the measurement as `measure` returned it; the method compares, converts, and summarizes nothing.

### Ordering

The generate factory is called first and its result is read before the verifier factory is called; the first refusal returns and nothing after it runs; the held values are borrowed or cloned for each call and not altered.
