ChainTorrent is a decentralized, distributed, encrypted content protocol. Anyone can publish content to the swarm, anyone can share content, but only parties that purchase an access token can decrypt the content. 

The publisher of a content object mints all access tokens, as few or as many as they want, and sells the access tokens for a price they choose. 

Anyone who purchases an access token can sell it to another party for whatever price both parties agree to, creators cannot withdraw, reclaim, invalidate, or refuse any minted access token. 

This provides distributed, decentralized, encrypted content distribution, while ensuring creators get paid for their contributions.  

The first use case is a mirror and resiliency layer for NPM, so that free NPM packages can be taken from the swarm if/when NPM is unavailable. 

Because publishers can attach pricing to their content, this means that open source contributors can publish packages directly to the swarm, skipping NPM, to get paid for their open source repos. 

The next use case we'll build is a Git layer so that creators can push their Git repos directly to the swarm, in addition to, or in lieu of, Github, so that repos can be accessed even when Github is down. 

After that we'll probably build extensions for other popular package managers and repo hosts so that the development environment can provide swarm package and repo management broadly while ensuring all packages and repos are securely encrypted against spoofing or tampering, while creators can set a price that ensures they're compensated for their contributions. 

Eventually we expect this method will act as an underlying protocol layer for most forms of digital content, far beyond packages and repos, like for example distribution of compiled software applications, games, videos, music, and so on.
